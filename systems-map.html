玩家扮演尚未完全苏醒的邪神，用有限的低语回应凡人的祈求，通过人物、教团与圣物在现实中建立立足点，在文明的察觉与抵抗中争取完全苏醒。回合制、卡牌承载、单人离线买断制。

一局约 60–120 轮（估计，非倒计时）；胜利是「归于混沌」，失败是「寂灭」，两者都结束本局并保留编年史。

主循环：一轮六阶段（一切系统的挂靠骨架）

阶段一 · 轮初整理
处理上一轮到期的不可逆事实（死亡优先于恢复与迁移）→ 记录本轮收入资格起点 → 刷新本轮低语 → 展示到期计划与供奉预计。
阶段二 · 事件处理
筛出 0–2 张主要事件，允许整轮零张。强制事件必有 0 信仰 0 低语的承受/放弃分支，不可因贫困卡死。
阶段三 · 自由行动
唯一玩家操作窗。看至多 3 张祈求、最多回应 1 张；使用权能；免费调整策略与供奉优先序；可选整轮敛息。
阶段四 · 锁定并演化
锁定快照 → 先付传教费、再按优先序付锚点供奉 → 在同一快照上跑人物/文明/经济 → 合批裁界 → 刷新苏醒与信仰容量。
阶段五 · 收入与期限
结算供奉收入（基数只算轮初已存在且轮末存续的信众）→ 处理未回应祈求的到期后果。
阶段六 · 苏醒与终局
重算苏醒与断联，处理持续降临，先查寂灭再查降临；无终局才进下一轮。
能预支 vs 到期必发生
本轮未到账的信仰收入不能用于本轮支出；已预告的到期后果不能因本轮预算用尽而推迟，必须结完再判终局。

知情不随因果反推

你或某个 NPC 知道一个结果，不代表知道它是怎么来的——知道结果的人只知道他该知道的那一段。

  • 玩家编年史只显示已知部分，理由写「尚未知晓原因」，不显示假数字；调试日志可以有完整关联，但那是内部视图。
  • 不得从标题、筛选、对象计数、报错文案、候选理由里旁路泄漏未知信息。
  • 多因确认时保留全部实际证言；插入一条无关事件不会改变已有前因。
  • 条件没满足要列「实际缺什么」，不能把「不合法」和「风险很高」混成一句。
例子 · 某人死于一次仪式反噬。你知道他死了，但除非当时有人见证并记录，你不会自动知道是谁执行、用了什么媒介。
为什么这样 · 未知本身是玩法资源——「世界记得玩家」要求信息有来源，不能因为系统内部有关联就让玩家全知。
原术语与出处：SET-VIEW · SET-HISTORY；要求知情必须由事实授予，不得由因果连线反推。

内部令牌不投影

系统内部用于排队、准入、采样证明的令牌和知识字段，一律不出现在玩家能看到的任何数据里。

  • 公开数据里隐藏内部 call、knowledge、record_knowledge、admission_token 及采样/授权依据，包括嵌套事件请求、选择器、预览、结果、幂等缓存、历史与局部续存重建。
  • 准入令牌引用注意力的持久预留（owner=prayers，claim_key 按卡 ID，people 是固定 actors，members 是原政策提名者，持久为真），按既有 ID 并集计数，同一个人不重复占名额。
  • 不允许「删掉令牌就把已承诺的成员名额当成空闲」，关闭时必须释放，也不留残留。
  • 终局内部的未来联系预测不公开；未固定或未到可见轮的请求不给线索；请求本身不授予重点域名额。
例子 · 你看到一张祈求卡，看不到它背后占用了哪些人物名额、从哪条来源采样——只看到卡面本身与它需要你付出的代价。
为什么这样 · 名额和采样是模拟内部账本，一旦外泄就变成可刷的元游戏信息。
原术语与出处：SET-VIEW · SET-ATTENTION；投影层与模拟层严格隔离。
关联契约：SET-VIEW · SET-ATTENTION

四档分布不重叠

一次检定的四种结果（深成／成功／失败／灾变）是按同一颗骰子划分的四个互不重叠区间，加起来刚好 100%。

  • 区间由 P 决定：深成 1…floor(P/5)，成功到 P，失败到 100−ceil((100−P)/5)，灾变是最后一段；长度为 0 就显示 0%。
  • 以 P=60 为例：12% / 48% / 32% / 8%。**不能把「深成+成功」的 60% 当成「成功一档」**——那是两套不同的代价。
  • 确定性事件、聆听、任命显示「确定结算／不投骰」，不伪造 100% 的四档分布。
  • 降临前两轮只显示已付与持续条件，第三轮预览才给准确四档，提交后标「概率已锁定」，并注明轮末仍可能因主体、锚点、苏醒或供奉失效而中断。
例子 · 界面写「成功 60%」是错的写法；正确写法是四行：深成 12%、成功 48%、失败 32%、灾变 8%。
为什么这样 · 灾变是玩家必须提前看见的风险，藏进「成功」里等于骗人去送死。
原术语与出处：SET-CHECK · SET-VIEW；四档互斥且完整覆盖 1…100。
关联契约：SET-CHECK · SET-VIEW

A · 身份与名额

具名身份与名额的完整生命周期

一个人从「无名群众里的一个数字」变成「被逐人模拟的角色」，再退化回「有记录但不再细算的人」——这条路径是双向的。

  • 名额四类名额：临时主体 12、绑定成员 12、重点域 3（开局 1）、本地辅助 6/每重点域；全局活具名身份 144。**都不是货币，信仰买不到。**
  • 提名发生在固定那一刻：先扣人口 → 建求告 → 组情境 → 固定，原子完成。
  • 入团时先取得成员名额再释放同一人的临时名额，中间不存在「既不是成员也不是临时主体」的空档。
  • 释放发生在轮初；释放后身份、历史、关系全部保留，仍可被事件回调、被抵抗当成目标——只是不再每轮逐人推演。
  • 容量不足就根本不产生这个人和这张卡，只记一句原因，不会保留一个指向「还没出生的人」的求告。
例子 · 某人因祈求被提名，占 1 个临时名额；入团后转成员名额；退团但还有未结关系 → 进退役保护，仍占成员名额；关系结清后轮初释放，他仍是具名人物。
为什么这样 · 「世界记得他，但不为他付费」——这是分层模拟能压住成本的关键。
原术语与出处：SET-POPULATION · SET-IDENTITY · SET-ATTENTION · SET-FIDELITY。

一张祈求的跨轮生命周期

一张祈求卡不是当场生成的：它先在世界上发生，下一轮才成形，再下一轮你才看见。

  • 处境在第 T 轮发布 → T+1 产生求告并固化 → 通常 T+2 展示；开局引导例外，首轮就可见。
  • 展示窗口基线 3 轮（少数祈求为 2 轮）；进入候选的那一轮算第一轮。
  • 到期时间取「窗口到期」与「原危机到期」的**较小者**；原危机必须至少留一次合法行动机会才到期。
  • 回应则原子结算一次四档检定，卡随即成为事实；**失败也消耗这张卡和本轮回响机会**，但不解除原危机。
  • 不回应则到期执行一次：原信徒忠诚 −5、留下「向外求援」的暴露（察觉 +1）；病危或追捕按原预告执行，不叠加第二笔惩罚。
例子 · 第 3 轮发生事故 → 第 4 轮固化 → 第 5 轮你看到这张卡 → 第 5、6、7 轮可回应，第 7 轮末到期。
为什么这样 · 跨轮结构让「机会」有时间维度：你可以等、可以错过，也可以被逼着在窗口内决定。
原术语与出处：SET-EVENT · SET-CHECK · SET-PRAYER-KNOWLEDGE。
关联契约：SET-EVENT · SET-CHECK · SET-PRAYER-KNOWLEDGE

身份知晓：只有四种生产途径

「他认出你是谁」这件事非常严格——只有四种情况能产生，别的成功都不算。

  • 四种途径：成功的指认梦境、成功的指认谕言、献身被感知（特定祈求成功）、已认知者的一次指定告知。
  • 知晓不等于忠诚、不等于信仰、不等于机构察觉、也不等于他现在愿意定向求告；知情者也可以无指向求告。
  • 撤掉关注**不会**让他遗忘；暂时失能或失去处境会影响当前资格，但不从撤关注推断遗忘。
  • 无指向的献身祈求任何人可用，不能伪称已经认识邪神。
例子 · 你回应了一个陌生人的呼救并成功——他不认识你，下次仍是无指向求告。
为什么这样 · 把「被帮助」和「被认识」分开，身份知晓才成为一条需要经营的资源线。
原术语与出处：SET-PRAYER-KNOWLEDGE。

B · 时间与节奏

后台游标：为什么「不补账」

后台域每四轮才演化一次，而且**不会补上前几轮欠下的**——它不是慢放，是抽样。

  • 游标 = 当前轮 + 4；相位由版本化域 ID 派生，保证可复现。
  • 到期只算一次日常：不叠加、不补漏过的轮数、不补领跳过的机会。
  • 每次到期至多 1 次候选尝试，35% 环境门；候选池 8，每候选 ≤4 人。
  • 但**风险、证据、期限每轮照算**——后台不等于暂停。
例子 · 某后台域第 4 轮演化一次，你第 10 轮才去看它：它只演化过第 4、8 两轮，第 6 轮那次不会补。
为什么这样 · 这是用「精度换成本」的明确取舍；若补账，成本就回到全量模拟。
原术语与出处：SET-FIDELITY；background_tick_interval=4、background_candidate_trials=1。
关联契约：SET-FIDELITY

屏障破口的迟滞（防刷）

屏障降到 30 才裂开，但要回升到 45 才算补上——开和关不是同一个阈值，就是为了防止反复刷。

  • 破口在屏障 ≤30 时形成，回升到 ≥45 才闭合。
  • 修复 +1/轮，前提是：秩序机构可运作、本轮没有成功的污染干预、没有仍在公开的异常。
  • 迟滞让「压低→触发→拉高→再压低」的循环拿不到重复收益。
例子 · 屏障 32 时还没有破口；打到 29 → 破口出现；回升到 40 破口仍在；到 45 才闭合。
为什么这样 · 单阈值会让阈值附近的微小波动反复触发一次性收益。
原术语与出处：SET-CIV；barrier_base_recovery=1。
关联契约：SET-CIV

终极降临：三轮公开仪式

赢的仪式要连续三轮付费维持，而且从第一轮起全世界都知道你在干什么。

  • 起始条件：苏醒 ≥90、至少一个有效宇宙锚 + 一个有效星系锚、指定宇宙锚的护持者作为仪式主体。
  • 起始即产生「正在降临」的公开事实——让抵抗更容易取得资格，但不跳过预告。
  • 第 1、2 轮只付费续命（每轮 3 低语 + 8 信仰），**不投骰**；第 3 轮付费时锁定概率，之后新增准备不追加、文明变化不暗改。
  • 中断（未付、取消、主体失效、锚点不足）已付不返还；失败创伤 +10，灾变 +20 且宇宙锚休眠；成功苏醒设 100。
  • 最后一轮不能越过同轮已确定的死亡、断联或锚点失效；终局后不再发普通收入。
例子 · 你开了降临，第二轮那个星系锚的护持者被清洗 → 仪式中断，前两轮花的 6 低语 16 信仰不退。

收入资格双口径

这轮能收多少供奉，看的是「轮初就在、轮末还在」的人，不是这轮最多时候的人数，也不是新招的人。

  • 阶段一在任何人口变动之前先拍一张各域无名信众数的快照，作为本轮资格起点；轮初清洗、迁移之后不许重拍（否则新搬来的会被算成老居民）。
  • 收入资格是当前人数的**子集**，不是第二份人口：恒满足「资格 ≤ 当前无名信众」以及「非信众 + 信众 + 具名活人 = 当地活人」。
  • 招募、神迹转化、跨域迁入只增加实际人数，不增加本轮资格；离开后同轮回来、脱教后同轮重新加入也不恢复资格。

证据确认与知情隔阂

机构要拿到「证据确认」得凑够独立查证强度；而且**一个机构知道，不等于别的机构知道**。

  • 同一目标的独立有效查证强度达到 3 才形成「证据确认」事实；不同目标之间不相加，同一个人对同一来源不能重复累计。
  • 没凑够强度但确实有暴露来源时，仍可发起有预告的正式调查；本批次刚产生的确认，**最早在下一批计划选择**里才能用于重大抵抗。
  • 本批次落地的事实、证据、新计划，不能反过来让本批次再选一项行动或升一档计划（防递归）。
  • 只有机构代表亲眼见证并以其职责记录、或其成员实际提交查证，才进该机构证据；跨机构/跨域传递必须引用真实通信通路与传递事实——没实现的入口就保持不传播，不用「全知」兜底。
  • 法则例外的确认只能来自已执行的正式事件结果，不能靠人物普通查证或玩家免费操作授予；同一授权来源只生效一次。
  • 只提高察觉而没有对象证据，不能产生对人物/圣物/锚点的定向打击。

暴露与持续异常

「被看见了」是当轮的事，「还在被议论」是持续状态——两者分开记，影响的是不同的恢复条件。

  • 普通暴露只标记**当轮**新增，并保留历史；它不会因为编年史里还留着记录就永久阻止屏障修复或察觉下降。
  • 持续公开异常必须绑定本域真实载体：人物要在本域且 active；圣物要在本域、未消耗未封存未被扣押；机构要仍存在可公开维持。
  • 没有固定的隐形过期轮数；恢复载体也不会自动重开已被明确解除的异常，重新公开必须产生新的合法事实。
  • 三条自然恢复各有条件：屏障 +1 需要秩序机构可运作 + 本轮无成功污染干预 + 无仍公开异常；污染 −2 需要无有效锚点 + 本轮无成功污染干预（这轮新增了污染就不扣）；察觉 −4 需要本轮无新暴露 + 无持续公开异常；**稳定不会自己漂移**。

接触背景资格

两个人「可能认识」是有严格条件的：同域、各自机构都还在运转、且同机构或两机构互相有往来。

  • 唯一判定：两个不同、现存且 active 的具名人物在同域；双方所属机构存在、可运作且仍是本人实际所属；且**同机构，或两机构当前 links 互相包含对方**。
  • 仅同域、有共同标签、有亲属关系、或只有一条**单向**往来，都不算。
  • 同机构或机构往来只提供「可能接触的背景」，绝不把合法候选全对登记成互相认识——只为抽中的有限人物对写入接触事实。
  • 初态类型权重：亲属 2 / 支持 4 / 合作 3 / 竞争 1 / 敌对 0 / 欠人情 0。**权重为 0 的类型不会在初始化时随机出现**：敌对只能由真实已声明的关系后果产生，欠人情只能由实际合作结果产生。
  • 邻接预算 min(n(n−1)/2, floor(5n/4))（六人目标 7 对，不是全连接 15 对）；个人上限 min(n−1, 4, 2+floor(影响/2))。
  • 初态关系只通知关系两端，不通知整个机构、全域或玩家。
例子 · 六人小团体最多生成 7 对关系，且不会出现「初始化就随机给你一个敌人」——敌人必须是你做了什么才产生的。

秘密依据不补证

秘密流传的依据只帮你自己扎根，**不会反过来给敌方补证据**；机构之间也不互通。

  • 承载者优先取原祈求/权能结果里明确的真实见证者或持有者，并核验那次结果实际给了他什么知识；**知情不能由「证明」赋予**，换承载者只接受原有的受管理告知或材料递交效果。
  • 当前只向机构递交记录，不会让任意成员自动知道；不传播父级事实，不回填旧见证。
  • 一个真实人物知道一份记录 ≠ 本域所有机构都知道；已有机构的全知不能靠新依据偷渡进来。
  • 公开的事件分支或实际调查可以产生它原本声明的知情与暴露；但**秘密依据本身不为敌方补证**，抵抗仍按已确认目标与原来源、预告、冷却执行，六类伤害不增加。
  • 旧的「否认」只记录职位、解释与态度；付费换空支持的选项已退役，不存在「先撤销旧否认才能秘密扎根」的步骤。
  • 预览只算缺口和候选依据副本，不写事实、不消耗随机、不制造首次圣物机会。
例子 · 你让三名信徒私下各自保留一段见证 → 这能扎根，但不会让当地机构因此获得抓你的证据。

两类祈求来源

祈求分两种：不认识你的人「向不知道谁」呼救，和认出你的人「向你」呼救——后者必须先真的认出你。

  • 作者明确两类：不知邪神者的无指向求告由底层联系承接；直接或间接知晓者可定向求告。
  • 知晓只由四种途径取得：成功的指认梦境、成功的指认谕言、献身被感知、已认知者的一次指定告知。**别的祈求成功不会让他自动认识你。**
  • 撤掉关注不会清空真实联系；玩家知道世界，不代表世界认识玩家。
  • 初始的无向献身只是合法尝试，它不预授知晓，也不保证能建成教团。
例子 · 你回应了一个陌生人的呼救并成功了——他仍然不认识你，下次仍是无指向求告。
为什么这样 · 「被帮助」和「被认识」是两件事，混在一起会让身份知晓机制失去意义。

⑤ 苏醒、锚点与终局

苏醒不是货币，不能存、不能买。它由「现实里还站得住多少立足点」决定，可大幅回退。

苏醒公式
A = clamp(初生自我 10 + 有限洞见(≤20) + Σ所有「有效」锚点贡献 − 创伤, 0, 99)
终局前上限 99；终局成功设为 100。历史峰值只用于保留已见权能说明与信仰容量。

锚定：一次性动作，但必须持续付费

污染达序号门槛 + 蓝本事实成立 + 人数/凝聚达标 + 一名可护持具名信徒 + 一件可绑定圣物 → 施锚定权能即时判定成败 → 成功先进入「休眠：待本轮供奉」→ 本轮实际付清供奉且维持条件仍成立，才变有效并开始贡献。失败成本不返还。

维护规则说明
可逐个拒付排优先序；上一轮已有效的锚点维持贡献到本轮供奉结算，只有实际拒付才休眠
零资金全部未付锚点休眠，不欠债、无随机保底
护持者出事死亡 / 离开 / 被献祭 → 立即停贡献
圣物失控同理停贡献；只有条目明确永久毁灭才转「被毁」
恢复资格 ≠ 激活材料或保管者恢复只重建资格，不免费把休眠锚激活；换护持者/圣物须重走锚定权能

终极降临：三轮公开仪式

轮次做什么
起始A ≥ 90 + 至少一个有效宇宙锚 + 一个有效星系锚 + 指定宇宙锚护持者为仪式主体 → 起始轮登记并立即产生「正在降临」的公开事实（让抵抗更容易取得资格，但不跳过预告）
第 1、2 轮只付费续命（每轮 3 低语 + 8 信仰），不提前投终局骰

临时失能非死亡

护持者被关了、失踪了，锚点立刻停贡献——但他没死，绑定还在，回来也不用重做整套流程。

  • 护持者死亡、离开、被献祭 → 立即撤销其锚点贡献；圣物失去控制同理。
  • 拘禁、失踪这类**临时**失能也会立刻停贡献，但保留原名义绑定；释放或归来不会自动换人，也不会立刻免供奉激活。
  • 只有条目明确让媒介永久毁灭时才转「被毁」，否则通常是休眠。
  • 被破坏的是哪一个锚点，要与暴露来源和抵抗目标一致（不能随缘挑一个）。
  • 无关官方代表换任、态度由支持变敌视、旧的否认记录，都不会单独让锚点休眠；只有材料、绑定或所需载体真的没了才按原因失效。
