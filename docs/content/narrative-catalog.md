# 文明与叙事内容手册

状态：策划第一版；蓝本与标杆可用于后续实施，尚非全量发行内容。数值、条目与效果以 CSV 为唯一源，本文件讲设计意图、语义和生产方法。

## 内容入口与责任

- [civilization_profiles.csv](../../data/civilization_profiles.csv)：八个文明蓝本的范式、组织、初始状态和玩法路径。
- [civilization_conditions.csv](../../data/civilization_conditions.csv)：每个蓝本的进入、传播、机构承认条件、禁用捷径与圣物类型池。
- [prayers.csv](../../data/prayers.csv)：十二个祈求，两种回应的基础收益和始终代价；统一四档结算见权能规则。
- [prayer_facts.csv](../../data/prayer_facts.csv)：每种诉求成功、失败、到期后世界究竟发生什么，及依赖成功事实的条件代价。
- [events.csv](../../data/events.csv)：十二个状态/历史事件的时窗、冷却、优先级、默认分支与目标失效策略。
- [event_effects.csv](../../data/event_effects.csv)：二十四个事件选项的成本和后果。
- [event_parameters.csv](../../data/event_parameters.csv)：本内容族共用的调度与记忆参数。

数据是策划输入，不把代码中的物品、敌人、事件列表反向导出为“来源”。验证用 `feasibility_*.csv` 是独立技术夹具，不能与这些正式设计基线混用。

## 文明生成的具体变化范围

蓝本的层级、矛盾类型、进入/传播/扎根路线在本版固定，防止随机生成抹掉身份。可变部分包括名称、机构名称、人物、关系、初始冲突、通路和有限的范式偏移。

范式变异每次从一个非零分量移出不超过十个百分点，加到另一个已允许分量，保持总和一百且不把蓝本主导范式降出主导阈值；零分量本版不凭空变为新范式。偏移量应落入 `civilization_parameters.csv` 的共用范围。组织方式只从该蓝本允许列表中选。稳定与屏障在蓝本初始值上下有限扰动并裁到合法范围，其幅度也由参数表控制。

先生成三类机构职能，再把人物与机构绑定。家庭关系、契约关系与政治对立均须双方存在；不可出现人物是自己的亲属、同时担任互斥职位或契约另一端不存在。名字相同不等于同一人，身份不同也不允许共用同一圣物实例。

同一文明蓝本被重复选中时，至少更换关系布局或真实矛盾涉及的人与机构，不能仅改名改初始数值。全局种子决定结构，内容版本决定蓝本含义；二者都随存档记录。

## 机构条件如何形成可实施的目标

每个机构维护自己曾接收的真实证据与当前代表；条件表中的“本机构”不能解释为同域任何机构共享。证据是历史事实的引用，不是可无限复制的普通货币。

进入决定哪些初始联系合法；传播决定哪些成功干预能继续扩展；制度承认决定该机构是否具备锚定资格。普通浅触/入梦仍能在未满足传播条件时产生有限污染，只是不能获得该蓝本的大范围传播与机构资格。

条件表中的数量、不同人物、不同回合与存活要求均同时成立才通过。检查不再投第二颗隐藏骰子。界面将未满足的条件列为具体缺口，例如“还需另一位存活见证者”，不能只显示“扎根条件不足”。

每个成功神迹事实绑定当时选定的一个机构。若浅触与深干预产生不同事实，以实际结果为准：秘密证言不能被当作公开见证；入梦可写梦境接触，但不会自动写公共记录；谕言只给准备，不无条件满足仪式见证。每个权能造成的事实标签须由条目声明，不能根据华丽台词自行推断。

若本域当前没有与蓝本有关的合法祈求，合法的聆听可从已有机构/人物痕迹揭示其尚未完成的处境，之后成为候选；不能直接补出所需的成功事实。这样存在可规划的推进路径，也保留时间、资源与风险代价。

## 祈求的共同语义

祈求人及所有被提及对象在候选生成时绑定并记录。执行前复核：病危亲属必须仍活着且病危；第二份证言需要不同的存活且未被拘禁见证者；记忆深干预需要三名现存关系人；圣物请求需要真实被夺物件；法则例外只在已接触宇宙域中出现。只缺深干预对象时禁用该分支，不能连合法浅触一起消失。

正面结果中的“理智/忠诚增加”按上限裁切；“忠诚四十/七十”是达到至少该值，不把原有更高值降低。新增无名追随者占用本域人口余量，不能凭空增加世界人口；产生具体见证者时从既存人群提升为具名对象。具体主诉求的成败事实以 prayer_facts 为准：救人成功确实解除本次病危，失败不会无说明当场杀人，但到期仍病危可死亡；隐匿只暂时撤销普通追查目标资格，不撤销已有抵抗计划。

“隐藏/失去匿名/被调查/出现争议”各有边界：隐藏使普通追查不能直接选中该人，但不抹去公共事实；失去匿名使其成为合法调查目标；调查资格不是立刻伤害；争议让对应事件族成为候选，不等于当场强制触发。

“保留记忆”指该人物能继续作为某条事实的有效见证者；“删除见证资格”只撤销当下可用于机构条件的资格，编年史中的事实永远保留。没有机制支持的“他突然忘了所有事”不得作为随机文本副作用。

## 事件的共同语义

一个事件选项只写入一次因果记录。事件未出现、对象不合法、玩家资源不足，都不能先偷偷施加付费分支。所有选项的不可逆成本在执行前列出。

变异是人物状态标签：在本内容族中只产生表中列出的理智/察觉变化，并允许后续变异事件；不默认额外加战力、不默认必死。公开先知标签的额外察觉只在该域执行传教策略时生效一次；同源不叠加，纠正或失位后停止。

“欠人情”是关系事实，用于后续请求候选，不在当前版本暗设未写明的债务利息。敌对关系影响该机构/人物成为调查方、阻止合作资格；不直接等于全局察觉上限。

事件时窗之外仍未发生，则机会类取消并留下历史；已预告抵抗按到期默认结果执行。先知死亡后的“遗言争议”只允许在存活继任者与已写遗言存在时沿用分支，否则记录结束，不能复活原先知。EVENT_04 没有合法异端传播对象时，默认只执行正统否认、不给新增信众；不能让缺失的接收对象凭空带来人口收益。

## 圣物从哪里来

每个机构第一次满足本蓝本的制度承认条件时，出现一次“神迹遗物”处置机会；这发生在锚定之前，避免“先有锚才有圣物、先有圣物才有锚”的循环。实例拥有机构来源与首个关键事实身份，重复失去/恢复承认不再产生新物件。

该机会提供三种清楚处置：支付回收信仰把一件相应类型圣物存入本域教团库藏；将其作为公开见证换取一次少量信仰并永久放弃物件；保持原地待下轮处理但有可见到期。回收支出、公开收益、暴露和期限见参数表。没有教团库藏时可由一名合法信徒携带；无持有人则只能等待或选择公开。

类型从蓝本列明池中抽取，类型可重复，实例身份不可重复。每域三机构和有限世界给出有界来源。六种圣物类型不等于整局只有六件；其他圣物来源须是明示且唯一的叙事机会，不能每次播种成功都掉一件。

公开见证、回收、分解和绑定锚点互相排斥，不能同一实例多次兑现。作者原稿允许圣物转化为其他资源；具体转化选择见圣物 CSV 及权能规则，源物件被消耗后不能再成为后续奖励。

## 三条标杆因果链

**救命者成为调查证人。** PRAYER_01 的病危亲属存活 → EVENT_01 接受变异 → 产生真实公开异常与可调查身份 → 文明调查该见证人 → 玩家保护、隐藏、利用或放弃。每一步都引用同一人物及来源；如果第一步失败，就没有“被你救活”的后文。

**仪式成为制度，又被制度束缚。** 盐梦诸邦的 PRAYER_05 在不同回合留下见证 → EVENT_04 支持合法祭司 → 满足机构承认并出现一次遗物 → 锚定 → 祭司死亡/换任时重新检查资格。制度不是一次点击后永久获得的增益。

**集体记忆抵抗同化。** 归一众声的 PRAYER_07 与三名现存关系人绑定 → EVENT_06 保留分歧、牺牲稳定 → 形成机构条件 → 后续文明尝试抹除见证资格 → 少于所需存活见证者时锚点休眠。无法用新随机人名直接替换失去的见证者。

这三条用于说明生产标准与测试因果，不构成被作者拒绝的短可玩阶段，也不要求先试玩它们才能继续完整设计。

## AI 内容生产与编辑

流程是：作者/策划给定机制功能与语调 → AI 提供有数量上限的候选 → 检查资格、效果、引用、冷却、唯一性及成本 → 编辑检查叙事因果和人物一致 → 写入 CSV → 以固定种子回归再进入内容版本。

每批先精写两至三个标杆再扩展；不得用十份换名同机制条目冒充十种体验。质量判断分开：机器可以查重复 ID、越界、缺字段和非法效果，不能证明文案新鲜、世界观细腻或玩家喜欢。

当前正式策划表中部分条件和效果采用明确的自然语言，便于人审；它们尚不是直接执行的效果脚本。正式实施时应按本案含义建立有限结构化效果词汇和校验，再由 CSV 装载或生成代码；这一步是规则翻译，不能让运行时 AI 自由解释，也不能把现有结构检查误报为全部自然语言效果已可执行。

首发内容规模作为后续预算提案：十二至十六个文明蓝本、四十八至七十二类祈求、六十至九十类事件，至少每个蓝本包含进入/扩张/抵抗/人物损失/后果回调的完整内容链。不是本次已交付条目数，也不是多就好；先保证结构覆盖，再按实际重复率调整。

不把在线 LLM 作为游戏结算者。以后若增加可选的文字润色层，它只能引用已经锁定的事实与效果；超时、无网络或输出不合格时返回编辑过的本地文本，不能使玩家失去存档或改变结果。该在线功能不在本版交付范围。
