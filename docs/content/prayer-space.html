16. 祈求生成与回应系统（2026-11-06，正式接入）

本节承接 §15 的研究，给出生成、回应、结算和续存规则。本批按制作人最新要求交付 50 条祈求与按处境变化的具体回应；不继续扩写至 100 条。全部案例见 阅读目录，策划源见 prayer_space_cases.csv。新情境使用具体回应及独立处境账本；原十二类机制卡继续按原合同结算。

16.1 玩家循环与生成单位

玩家浏览当前世界中的求告，看清谁希望改变什么，从当下可行的具体介入中选一项，支付费用，看到实际改变。后续来自这个改变留下的关系、暴露或责任。救人、得知事实、取得物件、建立供给关系各自有作用，不统一折算成一笔信仰奖励。

一次生成的单位是“处境”，祈求是其中一方的表达。处境保存世界、参与者及其不同立场、受影响对象、当前阻力、原危机时间、已知范围、目标状态和结果。多个参与者可以对同一处境提出相反诉求，但不得把同一结果重复出售。求告者可能隐瞒或误解事实；幕后事实在首次成立时固定，不因玩家选择某个选项临时改写真相。

求告者想要的结果与玩家所选介入的成功条件分别保存。例如请求“全船靠岸”，开路成功只建立通路，身体改造成功只赋予逃生能力；两者都不能显示“船员已经获救”。指引之后的普通行动，在条件齐备时按该处境既定结果结算，不要求玩家再进入逐人传话、搬运或阅读记录的菜单。

16.2 可组合维度与处境语法

生成空间由以下相互约束的维度组成；不按一个总表随机抽完整故事，也不将维度数量直接相乘作为内容量。

  • 生活背景：海港、土地、身体、亲属、律法、职业组织、信仰、工艺、梦境、异常通路。十种背景框架及条件见 prayer_space_frames.csv。背景可以重叠；世界有何背景取决于当地真实条件，不由文明类型名称硬推。
  • 社会位置：本人、照护者、职业责任人、利益获得者、受损者、权威持有人、被控制者；绑定既有人物及其可用关系。同一事故从押运员、货主或收货人的立场产生不同目标。
  • 核心关切：生存、生计、亲密、归属、尊严、自主、公正、名誉、权力、求知、信任、安宁、责任。允许复合，采用一个主关切组织原话。
  • 目标动词：保住、恢复、取得、脱离、揭露、隐去、迫使、阻止、接续、改变自身。每个动词必须有具体对象和可判定的目标状态。
  • 阻力与期限：自然风险、资源缺口、持有人拒绝、制度限制、关系冲突、既有责任、异常影响。请求窗口与原危机时钟分别登记。
  • 认识与意愿：求告者知道什么、相信什么、愿付什么、是否知道回应者身份；不得由“绝望”自动推导愿意变形、献身或改信。
  • 介入：有限操作、作用对象、尺度、持续时间、成功代价、失败风险；不按慈悲／交易／恐怖等固定档位填满菜单。
  • 表达：恳求、责问、交易、试探、抗议、炫耀；只能改变措辞时属于文字变体，不算新机制。

九种处境语法见 prayer_space_scenes.csv：危机迫近、生活缺口、控制与保管、冲突与裁定、责任与束缚、异常侵入、接触与诱惑、关系与相处、继承与延续。每种定义角色槽、必要前提、目标形状与时钟规则；推荐操作只是候选提示，实际合法性由操作合同与真实对象决定。

绑定顺序为：选择有当前联系的世界 → 选择兼容背景 → 绑定处境语法和实际对象 → 绑定求告立场与目标 → 生成回应 → 固定表达。不存在海洋不能生成渔获；没有实际亲属关系不能生成母女；没有权力的机构不能授予资格。普通背景可按 DEC-026 一次概括成立，只保存将被行动消费的事实，不新增完整市场、医疗或司法模拟。

50 条是这套空间的已写派生实例，覆盖海港、生计、身体、家庭、律法五种背景；其余背景只有生成框架，本批没有声称已完成对应篇目。实例中的职业称呼是角色槽，不是另建一套与正式 NPC 无关的人物库；进入游戏时绑定已定名字，不外露短编号或内部 ID。

16.3 回应的构成与合法性

有限操作的输入、输出、持续性和禁令见 prayer_space_operators.csv。回应是“操作 + 真实对象 + 明确参数 + 费用档 + 后果”，不是一段任意执行的文本。

操作包括揭示、指引、庇护、救助、修复、遮蔽、开路、转移、交换、誓约、限制、解除、身体改造、记忆改变、感官通道、公开显现、资格改变、持续依赖、假象、毁去、断联、接触和物件牵引。常用时长统一：庇护一轮；遮蔽、行为限制、通路两轮；感官通道、物件牵引、誓约与供给依赖三轮。明示分支的永久变化写在选项中；曲解分支明示“后果未知，改变可能无法挽回”，不提前剧透具体变形。

每个候选检查对象存活与归属、接触途径、操作者资格、对方意愿、所需物件、费用与当前局势。信息指引只在能给接收者新增有用信息时成立，玩家查阅已知资料不付费。交换要求实际可交付并已同意的对象；资格变更要求机构确有权限；修复不能重建已经灭失的人；幻象不能成为真实证据。非自愿干预必须是明确的限制、夺取或欺骗，不能包装成双方同意。

具体实例中的“仅在可逆时”“须有可接收地点”等，是生成与执行前置，未满足时不生成可点击回应。凡需要指定接收者、财物或作用范围，卡片出现前即绑定实际对象与数量，不能留给玩家选完之后才告知无效。

每项通常提供二至五种介入；实际只剩一种有意义的可执行介入时允许单选，零种则不能进入新可回应卡。按收益、代价、对象和后续状态合并重复候选。不能选择的不混入可选列表；已有卡因资源变化暂不可回应时，就地显示具体缺口，保留暂缓与放弃。普通回应说明已知后果；曲解明确标为未知，不展示未发生的具体结局。必付资源、能否执行和使用一次回应机会始终可见。

回应的非人尺度与未知

回应按 approach 和 intensity 表达介入方式及异化程度：有限帮助、索取交换、强制支配、身体／身份／环境的亵变，以及曲解。它们是可组合的维度，不是每条都填齐的固定套餐；每个处境按实际取舍配置二至五项，不能靠换标题、随机删项或给同一办法加费用来制造数量差异。暂缓与不再回应不计入数量。

疯狂必须改变愿望的实现方式：保住生命却改变其赖以生存的身体；恢复归属却侵蚀身份；使话被听到却夺走另一个人的嘴。允许残酷、掠夺和非自愿改造作为邪神的选择，由明确状态与后果承担，不将所有回应包装成互利善举。人类愿望保持具体可信，非人的理解越过人类默认的身体、时间、关系与主体边界。

disclosure=unknown 的曲解显示短预兆 omen，不显示分支池、分支权重、潜在结局及后续合同。未知来自愿望可能被怎样理解，不等同于单纯的成功／失败率。底层 outcomes 至少两个有不同实际后果的有限结果，每项有独立 ID、正权重、当前前置、状态变化、目标、后续／维护及揭晓文案。提交时仅从当前合法结果抽取一次；全失效则不执行、不收费。抽中结果连同执行事实和随机身份持久保存，预览、反复打开与完成后读档均不重抽。

玩家执行前知道固定支出与未知性质，执行后看到已经发生的怪事及实际损失／变化；未发生的其他可能性继续保密。神迹检定的成功只意味着介入显现，不保证求告者得到善果，曲解结果不标成“成功救助”。旧存档已冻结的普通选项保持旧合同，不因新内容版本被变成随机曲解。

文案以物件、动作和说话者为中心。标题短，祈求像当事人会脱口而出的话；按钮写邪神做什么；结果写发生了什么。后台的“真实／指定／实际／权限／可核实”由执行校验承担，不批量塞进玩家句子。规则必要的代价保留，禁止用整段限定条款磨掉场景。

16.4 费用、检定与四类结果

八种报价档见 prayer_space_costs.csv。费用档是该回应的报价，不是玩家看到的强弱档位。数值为本次设计初值：线索采用现行低语一、信仰零的可接近基线；局部短效略增信仰；修复与强制沿现行低语二、信仰四的深干预基线；永久改造增加信仰；公开介入增加察觉。未声称已完成经济平衡。

低语与信仰在确认执行时一次支付，失败不返还；条件失效则整笔取消、不收费、不占回应名额。报价中的污染与察觉为成功后本世界变化；灾变只追加该档灾变列，不再叠加成功污染／察觉。物件交付、永久变形、身份公开等成功代价只在对应事实成立后执行。另有逐轮费用时必须单列首轮费用、总次数和中断结果；首轮即发生的费用计入可支付检查。

不确定神迹使用权能系统 §3 的同一百分骰公式、目标域难度、准备限制与四档区间；报价表明确检定类型与主属性。主体默认是承受或理解神意的祈求人；只有操作要求代理时才绑定一个事先合法的代理，不在结算时选最高属性者替骰。涉及多名受益者的一次神迹仍只投一次，不能靠人数重复抽取成功。界面按实际绑定结果显示成功与灾变概率，本目录未绑定存档，不编造概率。

  • 成功：完成该选项的成功效果，并落实全部已声明的成功代价。
  • 深成：本批没有额外的直接数量奖励，因此与成功产生同一组实体／关系结果。不得凭深成再救一人、再复制一件物品、把暂时庇护变成永久治愈。以后新增数量奖励时须在内容数据明确后沿共通倍率结算。
  • 失败：已付低语／信仰消耗，主要效果与成功代价不成立，原处境继续。
  • 灾变：同失败，再追加报价档中的主体理智损失与本世界察觉增加。不临时编写未预告的死亡、献身或第三方伤害。

确定性交换在双方当前条件满足时原子结算，不投骰；未来责任的成立不意味着未来工作已经完成。“交换”报价也可用于各方同意的有限约定，但每次交付仍按实际履约发生。超自然夺取、假象或强制不能套用此档绕过检定。价格与检定档在绑定后固定，不能先承诺成功再追加隐藏费用。

16.5 结果如何进入游戏

结果必须写入可消费的状态，不以一段叙事冒充作用。开路建立通行窗口；转移改位置和保管；治疗解除指定伤病；机关认可改变限定资格；揭示更新指定接收者知情；身体改变获得明确能力和缺陷；供给建立有期限的服务与维护义务。每种实例中的目标、主要效果、成功代价共同定义操作的参数边界。

持续内容保留开始轮、剩余次数、付款人、实际对象、每次交付和中断结果。供奉型供给在本轮及随后两轮各另付一信仰；断供停止服务，无预告不得额外致死。实体粮食等分期承诺冻结原交付总量，不能每轮对剩余量重新取比例，也不能把约定但未到账的收入提前花掉。自动履约只执行已获同意的固定计划，有新的取舍才再次询问玩家。

本批中“获得指引”“听到证词”不自动让机构裁决、他人服从或人物改信；关系与信仰转变继续受原消费者规则约束。成功不一律送信众、忠诚或圣物。真实见证只记录实际看到的人；副本不增加独立见证。可能引出的追查按现有反制资格产生，不因一句“可能引起追查”立即凭空扣资源。

玩家结算首先看到结果状态与数字：例如“粮食：已送达”“原器件：遗失”“祭食：已交一份／还需两份”。再用一句短反馈说明人物反应。需要继续推进的普通事项显示进度和缺口；不让玩家进入记录根、保管关系或因果图完成无取舍的手续。

16.6 生成、调度与重复控制

参数源见 prayer_space_parameters.csv。轮初先清理已解决、已死亡或失效的请求，再处理已预告到期事实，然后保留仍有效的旧卡并补足现行最低供给。最多同时展示三项，每轮最多回应一项；不要求补满三项。

每轮在轮转的已联系世界中，最多绑定二十四个完整候选；原有保障路线先保留，其余按稀缺位置参与选择。候选权重为近期新决策签名四、近期出现过的签名一；已存在且将到期的危机再乘二。签名保留十二轮，由背景、处境语法、主关切、利益关系形状、主要操作及结果边界组成，换姓名不算新签名。权重只在合法候选之间选择，不会先选一个故事再强造缺失前提。

同世界同处境语法默认间隔四轮，同人物普通新诉求间隔三轮；已展示请求继续存在不受冷却误删。一个已经确定的关键后果回调不因新鲜度被无限压住，沿既有机会保障与到期规则进入相应流程。背景候选未被选中不会每个都生成隐藏危机。无合法普通候选时返回原有最低供给合同，不能在 UI 新造一张保证成功的祈求。

每次实际生成冻结处境身份、角色、原危机、请求到期轮、允许披露的信息、回应对象与结果方案、报价版本及随机流状态。读档或打开详情不重抽；预览只读取当前资格与费用，不推进随机序列。提交时再核资源与目标，状态变化则取消并告知，不能静默换人或改价。

16.7 暂缓、拒绝与后续

所有祈求共享“暂缓”和“不再回应”控制，不为每个故事写一份固定沉默选项凑数量。暂缓无费用、不占回应名额，不重置请求或危机时间。不再回应关闭该请求，无自动退款、察觉下降或任意忠诚惩罚；原处境按已经成立的后果继续。

任何已经执行的回应，无论成败都消费当轮回应机会并关闭该卡。若主要目标仍未实现，后续只有在原规则允许且产生新决定时才能形成另一请求，不能原样再次出售或延长原危机。已执行的费用和唯一结果按处境根身份、回应提交与效果种类去重；另一个人对同一船货求告不能复制粮食或再收一份成功奖励。

回应导致的影响可进入下一轮回调，例如被救者面对公开见证压力、三轮供给即将结束、被夺走物件的原持有人作出反应。仅感谢或复述既有结果进入短反馈／编年史，不占主祈求。后续行为遵守角色意愿和权限，不能把所有受益者写成无条件忠诚。

16.8 数据交付与接入边界

本批数据由六份 CSV 构成：背景、处境语法、操作合同、报价、调度参数、派生实例。实例回应字段依次存放“具体名称｜操作引用｜报价引用｜成功结果｜成功代价或局限”；阅读目录由数据生成，不反向从 HTML 提取策划内容。内部键仅用于引用，不在祈求或人物名称后显示。

生产装载由 src/content/prayer_space_catalog.gd 注册六份设计 CSV，并装载 prayer_space_runtime.csv（50 个有限处境）及 prayer_space_response_contracts.csv（每个回应的类型化执行合同）。效果由对象路径、前置、有限更新、定时规则和维护规则执行，不解析自由文案。独立版本和随机流保存在 prayer_system.space；已冻结的报价、结果合同与旧消费身份保持原语义，兼容新内容版本。

当前调度的限定：新情境绑定聚焦世界与现存活跃人物；CIV01/02/03/04/06 支持本批人类生活背景。每轮合计最多三项，其中新情境最多两项，保留原机制供给；24 候选预算、处境四轮／人物三轮冷却、十二轮签名记忆（当前签名为背景／语法／关切）；尚未采用已存危机加权及利益关系／结果边界的完整签名。五十个有限处境依真实角色绑定派生，不宣称已经实现其余五种背景或任意自由组合。普通背景首次固定后由处境内对象、责任与定时消费者推进，不新增完整社会模拟。

正式界面展示具体介入、已知代价与实际成功／灾变概率；首次维护费单列，失败不扣成功后维护。暂缓只关闭阅读，不再回应关闭请求但不取消危机。玩家投影不外露执行合同、完整场景快照或底层因果图。真实执行经过 Session、准入、轮次事务、实际扣费、结果及保存恢复链路。

15.1 研究依据与设计提取

以下历史材料不构成普遍心理学定律，也不用于把真实宗教映射成邪教；采用其中的生活处境、社会关系和求告行为。小说采用其冲突结构，不直接搬用角色、神名和剧情。

  • 大都会博物馆：产后还愿浮雕：馆方推测母婴存活的场景是向治疗神表达保护后的感谢。提取：身体、照护关系、人生关口，以及求援之后的还愿；不把感谢本身都做成需要玩家再次付款的主祈求。
  • UCL／Petrie Museum：致亡者书信：向近期去世的亲属求助，涉及疾病、财产争议与生前／死后的照料义务。提取：祈求依附于具体关系和互惠期待，语气可以是恳求、追问或责备；不一律写成陌生人的绝望献身。
  • UNESCO：妈祖信俗：海洋生活背景之外也涉及生育、平安与日常问题。提取：职业风险、社区仪式与个人生活共同影响求告；日常希望也能成为动机。
  • 不列颠罗马铭文：Biccus 诅咒片：被盗物品与向神转交的表述。提取：寻回、惩罚与申诉可以共存，也可以分离；对神的求告并非天然无私。
  • 《印斯茅斯之影》原文：渔获、财富与非人力量的交换。提取：现实利益能够建立长期依赖，个人受益可能转成整个社区的责任与冲突。
  • 《暗夜呢喃》原文：以脱离身体的旅行与知识作为诱惑，交流者身份和信息可信性构成恐怖。提取：愿望可以真的得到满足，同时改变主体的身体、控制权或判断条件；不能把所有代价压成理智扣点。
  • 《克苏鲁的呼唤》原文：梦境、雕塑与远方的记录逐渐关联。提取：接触未知不等于已知神名或加入教团，同一影响可被不同人理解为疾病、灵感或征兆。
  • 《星之彩》原文：看似丰盛却不能食用的收成，以及生活环境逐步失常。提取：成果的外观与实际可用性可以分离；此结构不是每次回应必有恶意反转。
