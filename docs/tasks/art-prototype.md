# 表现层原型任务概要

本文件是本轮执行概要与图片交付索引，不新增机制规格。交互合同以[ui-interaction](../specs/ui-interaction.md)及各正式系统spec为准。当前处于表现层第2步；三方向共十二张细化图已生成，均待制作人审查，未选定正式风格、色调或生产技术。

## 已确认的表现原则

- **感知距离（DEC-043）：**平时感知零散、较远的现实联系；聚焦一个对象后，已知的具体处境变清晰；结束或退出后退回。视觉聚焦不自动等同机制F关注，不新增知情，也不要求强制过场。
- **情绪与角色（DEC-044）：**常态克制，带少量持续异样；涉及自身、权能与神意时可显露邪神气氛。疯狂、诡异与阴郁是屏幕前玩家的感受，不是邪神恐惧自身的心理。此为创作牵引。
- **世界先于教团（DEC-045）：**先理解世界生活与认知方式，再推导当地人怎样理解邪神及其教团表达。具体现实片段为主，象征、器物与痕迹为辅。世界名称不规定唯一字面景观，人物职业不固定年龄、性别与服饰。
- **共同来源与差异（DEC-046）：**保留少量经各文化转译的神性特征；不同世界的具体表达须有区别，不能只换色贴标。
- **生产与扩展（DEC-046/047）：**以制作人与AI工具协作为主，不依赖持续人工美术。分别识别可复用方法、文化相容的实际资产和必须定制的身份图像；未来新增世界的投入要经样板实测，不预建庞大素材库或自动生成系统。
- **色调独立（DEC-049/050）：**完整彩色、光照、材质与空间仍须呈现；选择方向不等于选定色调，也不意味着改为灰阶。跨方向共享玩法处境和文化逻辑，不固定同一人设、世界道具、图标和UI几何。同一方向的跨场景身份保持连续。
- **已有交互继续有效：**成熟桌面信息可读可找；主区总览与同级子页两层；具体祈求同屏呈现身份、诉求、选择及固定提交；不可用原因优先；全局入口不重复。不得通过生成图改写机制或已验收交互。
