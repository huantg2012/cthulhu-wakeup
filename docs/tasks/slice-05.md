code 实现，design 定向复核现有规则，qa 以可否证反例核验。前置 TASK-IDENTITY / TASK-ECONOMY / TASK-FIDELITY-VERIFY 已满足。正式规则仍在 system-powers-cults 第5/10章和 system-turn-economy，不另创第二份规则。

- 任命读取POWER_APPOINT正式CSV，确定性付费，在下轮轮初生效；保留指定人物及原持久令牌。到期死亡/迁出/离团或临时失能等资格失效取消，不换人、不退款、不刷新任务机会。领袖可兼一个护持职务，不能跨域或护持多锚点。
