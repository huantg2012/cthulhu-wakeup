## 2. 样本与真实上下文

第一轮用一个完整祈求回应作为跨层样本：**看见祈求 → 读懂求告者与处境 → 比较浅触／深应及合法准备 → 查看相关人物 → 返回原选择 → 执行／必要不可逆确认 → 读实际结果 → 返回现状。**

选择理由：此流程同时需要世界处境、具名人物、卡片身份、资源与风险、行动反馈以及后果，能暴露整体语言是否成立；只画一个远景或卡面无法检验这些关系。此样本不代表其他所有表面已经覆盖。

起点使用 `Session.start_new(1)` 的真实第一行动窗口，或从该窗口保存的独立副本。当前执行核实：初态为 T1/events 且事件清单为空，须调用一次 `Session.progress()` 进入 actions，不能直接强改 phase。当前样本是 `BACKGROUND-00000001` / `PRAYER_08`「让我的声音被听见」，求告者为 `NPC-00000007` 困惑的记录者，世界为 `DOMAIN-001` 镜证议会；浅／深均有真实合法预览，且二者均需原不可逆确认。这里记录的是本次样本事实，不是未来版本的数据常量。随机状态、正式预览与独立存档 SHA256 由实现证据登记；费用与四档概率继续现读。若该种子当前无法提供完整可执行样本，改用另一真实种子并如实登记，三卡始终共享同一个新起点。

生产上下文来源：

- `src/presentation/session.gd`：`start_new` / `project` / `preview_action` / `execute_action` / 保存恢复。
- `src/presentation/production/prayer_view.gd`：当前祈求定位、浅／深草稿、关联查看及返回、必要确认、回应与实际回执。
- `src/presentation/experience_actions.gd`：`resolve_row`、字段候选、唯一候选归一、`semantics.prayer`、缺口和支付后果。
- `src/presentation/experience_feedback.gd`：实际结果与前后状态变化。

**明确的布局例外：**三卡研究的对象包括 UI 结构，所以新布局不复刻旧生产坐标。它们须在同一 Godot 渲染环境消费同一生产 Session／投影／行动语义，不能另造浏览器假机制、固定成功回执或三个独立规则引擎。此例外只涉及布局，不豁免真实数据与完整输入链。

## 3. 所有候选共享的机制约束

| 约束 | 锁定合同 | 可否改变表现 |
| --- | --- | --- |
| 回合与阶段 | 原 Turn 顺序；事件未结束不开放普通回应；浏览／切卡不推进回合 | 可改变阶段提示的载体与位置 |
| 祈求供给 | 使用当前合法候选和原期限；本轮至多回应一项；没有候选不补造卡 | 可改变摘要、列表及情境布局 |
| 知情 | 世界、人物、四维精度／观察轮次及已知事实只取正式投影 | 可改变揭示顺序，不泄露未知值 |
| 模式与准备 | 只提供正式 shallow/deep 与真实可用字段；唯一强制依据可归一，不造一步选择 | 可改变选项形态及解释展开 |
| 资格 | 与执行共享正式规则；缺人物、媒介、资源或阶段分别解释；查询未完成不判无候选 | 可改变缺口控件，不放宽规则 |
| 费用与必付 | 低语、信仰、人物理智及其他必付来自当次正式预览与语义 | 可分组，不省略不可逆代价 |
| 概率与后果 | 四档概率来自同次预览；确定过程不造概率；可能后果与已发生结果分开 | 可改变概率读法，不改数值与语义 |
| 时间／打断 | 浏览、退出、只读、切卡、选择模式、取消确认均不消耗资源、不抽骰、不推进时钟 | 可制作可跳过短过渡，不用动效强制等待 |
| 执行 | 只经原 Session；重复输入不得重复消费；拒绝执行与合法失败分开 | 可改变反馈，不伪造成功 |
| 返回与记忆 | 只读人物期间收起原执行；一次返回恢复模式、合法选择、位置并重查 | 可改变空间组织，不叠无限资料链 |
| 实际结果 | 从原结果与前后投影解释真实变化，并标本轮回应机会已用 | 可变为场景变化、回执或卡片状态 |
| 跨候选切换 | 三卡展示同一局面；已执行后切卡仍是已回应状态；只有显式重置才恢复起点 | 切卡不暗中重开、回滚或加资源 |
| 存档 | 独立比较目录；原正式存档只读；重置从本轮起点副本恢复 | 可改存档提示，不覆盖正式局 |
| 画幅与输入 | 1280×720 逻辑画布，1920×1080 输出；鼠标与键盘可执行、返回 | 可改几何，不写多断点／不改工程默认 |

数值源仍为 `data/*.csv → code`。任何展示数值均取正式数据或查询；本合同不抄写第二份费用和成功率。

## 4. 三张完整组合卡

以下是平行候选，没有推荐顺序。每张卡都须覆盖同一流程和场景、卡片、人物、图标、条件、动作与结果，不能只替换背景或色板。

### A · 谋局图谱

**一句话读法：**邪神看见的不是一座供它俯瞰的城市，而是能被拨动的人、组织和现实联系。

- **载体：**神侧的已知联系图谱。图中位置是阅读组织；无正式通路事实时不连线，不能把世界画成共同地理、自动传播线路或可行军节点。
- **构造：**世界／当前联系形成场景骨架，祈求作为具体机会进入局势；选中后以人物与处境插图稳定主任务，回应条件在相邻固定决策区展开。结果回到同一对象，显示其真实变化。
- **图像与对象语言：**具有明确剪影的小型情境图、人物身份、组织标记和可辨认媒介；权能与关系动作共享一组可记忆符号。未知区不能用假城镇填满。
- **参考：**[Shadows of Forbidden Gods](https://store.steampowered.com/app/1741640/Shadows_of_Forbidden_Gods/) 学代理、施力与反制的局势读法；不搬运共同地理与移动代理人的机制。[The Fabulous Fear Machine](https://store.steampowered.com/app/1540350/The_Fabulous_Fear_Machine/) 学区域影响、机会和对手活动的可读性；不加入恐惧配方、传播计时或其漫画外观。
- **这张卡检验：**多个世界和干预机会能否读成可操纵的局势，同时保持眼前人物与回应的重量。

### B · 神谕绘卷

**一句话读法：**凡人的具体处境展开在眼前，邪神的回应从这幅现实中发生。

- **载体：**神侧感知的一幅具体生活／仪式场景。图像是当前人和事的情境，非玩家肉身在现场；不新增全知、移动或同情立场。
- **构造：**场景与人物成为主要阅读锚；身份、诉求和有限选项形成清楚顺序。外围保留当前世界、资源和其他机会。关联阅读在同一任务内替换辅助区，返回不丢情境。
- **图像与对象语言：**有文化特征的群体与场所、可辨认的求告者、克制但完整的绘画色彩；卡片承载具体故事而非统一建筑缩略图。图标用于重复概念，代价仍以文字和数值清楚表达。
- **参考：**[Six Ages](https://store.steampowered.com/app/881420/Six_Ages_Ride_Like_the_Wind/) 学插画、文化与决策共处；不采用氏族领袖的保护立场。[Sunless Skies](https://store.steampowered.com/app/596970/SUNLESS_SKIES/) 学稳定阅读中心及辅助信息组织；不把所有文明统一为维多利亚文化。
- **这张卡检验：**场景能否让祈求者和处境成立，同时让条件、成本和后果在阅读后自然可达。

### C · 禁仪案卷

**一句话读法：**人、物和神迹作为持续存在的对象，被邪神挑选、组合并留下结果。

- **载体：**神侧对人物、物件与已发生事实的仪式性整理；卷页／印记是表现隐喻，不宣称邪神在使用人类电脑或书桌。
- **构造：**当前祈求与人物形成一组身份清楚的案卷；模式、准备与代价依附当前事情，执行后原案卷变成已回应记录。浏览人物时只有一个关联阅读位置，不形成散牌寻找与无限窗口。
- **图像与对象语言：**完整人物插图、具体器物、清楚的图章／权能符号，以及相互关联但有主从的卡片；材质承担身份和层级，不以密集花纹吞掉信息。
- **参考：**[The Shrouded Isle](https://store.steampowered.com/app/501320/The_Shrouded_Isle/) 学人物在组织中的用途与损失；不把本作收缩成单岛人物审判。[Cultist Simulator](https://store.steampowered.com/app/718670/Cultist_Simulator/) 学持续对象、符号及仪式准备的身份；不照搬散牌桌面、实时计时和隐藏配方学习。
- **这张卡检验：**对象能否拥有清楚身份与可持续的状态，又不把回应变成表格填写或卡牌整理劳动。

## 5. 允许在选定时拆分的维度

可拆：场景与人物画法、卡面／承托材质、字体家族、权能／资源图标造型、过渡与结果反馈的节奏。拆分后仍需检查文化与造型一致性、文字密度、边界和输入热区。

不可直接拼接：一张卡的整体空间层级、另一张卡的导航规则和第三张卡的对象展开逻辑。它们共同决定视线与返回；若人要求混合，先做一套完整新组合再判断，不能硬拼后暗删条件。

全卡共同保留：事情与主体先成立、主要玩法直接可达、当场读代价和后果、查看不执行、一次明确返回、实际结果与预览分开。权能总数、世界容量、信息归属等全局边界不因第一样本暂未展示而被删。

## 6. 实机验收与证据

代码／自动检查只能证明以下限定合同；审美、读法与方向归制作人。

本轮旧版取样由主执行者留在 [baseline](../qa/presentation-rebuild/baseline/)：`01-new-prayer.png`、`02-deep-preview.png`、`03-related-person.png`。**制作人随后澄清：祈求左侧大面积海面是立绘预留槽，目前只留占位。撤回“空海面证明布局浪费／无情境结构”的归因；素材未接入不能证明版式本身失效。**公平比较应在旧布局填入适用立绘后，检查人物、处境、文字和操作的完整关系。截图中同背景重复与人物身份不足首先属于占位现状；金色文字层级及关键后果滚动属于待在完整画面中复核的假设。以上仅限该组实机状态，不扩大为所有页面已审查，不把原计划缺失当成结构缺失。

1. 记录实际 Session 起点、种子、内容 ID、独立存档哈希与运行版本。三卡切换前后 `turn.snapshot()`、知情快照和资源相同。
2. 三卡至少完成摘要、回应准备、人物只读与一次返回、实际结果四个可操作状态；有不可逆确认时必须走真实确认／取消。截图须附具体输入步骤，不能用最终静帧冒充流程。
3. 模式与准备切换来自同一正式查询；预览的费用、概率、必付及主要后果在三个方向一致。返回保留合法选择并重算；无效选择不能沿旧预览执行。
4. 执行只消费一次。合法失败仍产生正式结果并用掉回应；执行拒绝不付费。结算后切换卡不重新开放回应；重置样本不改正式存档。
5. 1280逻辑／1080输出下，**不滚动即可同时看见当前主体、回应方式、目标／请求期限、费用与必付、关键四档概率／风险、执行与退出**；详情和完整后果可以局部滚动，但不能把关键不利后果只藏在末尾。人物关联返回后恢复原模式、合法选择与原焦点，并现查预览。标准与放大文字按实际支持范围记录；未检查不得标通过。
6. 图标本体、选中与不可用状态可区分；鼠标与键盘指向同一对象。中文无缺字，长名和多行后果不覆盖执行／返回；动效期间可正常操作，减少动效不改变时点。图像不提供投影未知事实；原创人物／场景造型须在比较入口明确为示意，不把服饰、建筑或表情当作已经确认的文化设定或人物状态。
7. 新文字类别以正文与背板对比度不低于 4.5:1、大字／关键图形不低于 3:1 为制作检查下限；动态插图上的实际取样需留证。状态还须有形状、文字或位置差别，不只靠颜色。该检查不代表审美通过。

交付每卡一句话读法、真实入口、按键／鼠标操作、同类状态截图与剩余差异。数字键1/2/3切方向；显式“重置样本”恢复共同起点。换种子可用时清楚标新样本，不把变化的祈求当成方向差异。

制作人判断只需回答：哪种整体最像自己愿意玩的邪神叙事策略；哪种最容易看清眼前人物与可做之事；有无想保留的局部画法／卡面／符号。不要求制作人先掌握美术术语。不得由 agent 代选、宣布收敛或把自动通过当审美通过。

## 7. 选定后的全表现层覆盖

这次授权覆盖完整玩家触达层；第一轮不是缩减最终范围。获选组合先登记 DEC、原地更新唯一视觉正文和适用参数；依制作人后续接入指示，再按完整行为逐批推广：
