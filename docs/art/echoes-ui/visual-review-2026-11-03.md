# 幽界群像 UI 母版 · 视觉偏差审查

制作人认可上一轮布局与规范，但指出去装饰过头、重要对象图标退居次位、文字配色失去层级。本次实际并置查看原 `echoes-home`、`echoes-prayer` 与母版 `01`、`02`、`06`，诊断只针对可见差异；没有重开方向选择，不评价尚未制作的中央文化场景，不把下面修正建议记作人工审美验收。

**主要偏差是把“减少华丽程度”实施成了同时移除材质、象征物和颜色分工。** 布局的阅读与操作关系得到保留，但原稿让界面属于这个游戏的几种线索一起减弱：有厚薄的承载面、不同状态的表面变化、有辨识度的物件/权能图形，以及金、青、白、灰、红各自引导的阅读路径。只有把这些关系恢复到控件中，后续中央文化资产才不会承担全部游戏身份。

## 依据与保留边界

- DEC-043/044：远距离感知、聚焦具体处境；邪神气氛与凡人日常有主次，不把整个画面做成持续高强度特效。
- DEC-045/046：世界文化先于教团表达。通用 UI 的纹理或徽记不能把所有文化设为同一种建筑、宗教或材料。
- DEC-047：制作依赖人与 AI 工具协作，复用与修订成本需要实际验证；细边、角饰和表面应能复用，不能每个面板重画一张整图。
- DEC-051/052：幽界群像已选中，四维与具体反制保有权重；源图的控件错位和文字误差不是应继承的真相。
- DEC-053 及本轮反馈：底栏压缩、轮初祈求居中、中央文化资源独立继续有效；“沉重、幽闭、克制的压迫感”允许有材质与贵重物的光泽，不等于全屏同一种灰黑。

保持固定 1600×900 主画布、顶部/左索引/消息/底栏边界、十二权能、1–3 祈求居中和固定提交。通过控件内部表现恢复层级，不用扩大底栏或缩字来补美术。界面文字仍由正式数据与已有交互合同约束。

中央未铺文化场景是本批授权的制作边界，不能把“没有建筑插画”列作本次失败原因。上表的人物问题仅要求 UI 保留身份图形与关联位置，不要求本轮追加完整人物立绘或世界场景。

## 五项修正与需要验证的后果

### 1. 恢复少量真实的表面层次

在既有矩形内部建立三类可复用表面：安静的暗旧面、当前对象的浅骨/暖边面、重要行动的厚边暗面。常态表面可有低频明暗和极少破损；边界有受光边、暗侧或磨损转折；角饰只在一级容器少量出现。保留幽暗包围，减少全边持续亮金与每行花纹。

**需看到的后果：**遮住文字后，仍能指出哪个是当前对象、哪个是可选回应、哪个是普通资料；正常尺寸下表面有差异，承字区仍安静。若只是再加一圈细线或噪点，而控件仍是同一块平面，本项未解决。

### 2. 让重要图形重新拥有视觉面积

底栏不增高。权能在现有格位中恢复约 **32–36 px** 的主体轮廓、适度粗细变化或实心部分；外圈、内边距、装饰线让位于图形本身。圣物在原格位中给约 **40–48 px** 的器物位置，采用能区分根钉、铃、印章等的轮廓研究，与权能符号明确区分。低语/信仰/苏醒在顶部恢复约 **24–28 px** 的固定资源图形。不要用同一个皇冠同时代替祭司、任命、教团身份。

当前能够用可编辑矢量完成轮廓研究；完整器物材质与人物图像后续单独制作。资产成熟度须继续标明，不能因增加线条就称为最终圣物小像。

**需看到的后果：**不读名称也能分清资源、权能、圣物三类；十二权能仍完整；原已能读清的名称与状态没有变小、挤出或截断。缩成普通桌面观看尺寸后，图形仍比装饰边更醒目。

### 3. 恢复金、青、白、灰、红的语义分工

| 颜色职责 | 优先使用位置 | 边界 |
| --- | --- | --- |
| 暖金/骨色 | 区块标题、重要神性/权能身份、信仰图形、当前选择/执行 | 不把每个数值、全文和全部边框都染金；选择仍须形状/表面标记 |
| 冷青 | 低语图形、世界/来源关联、可追查的知识关系 | 不自动表示“已精确掌握”；估计/历史/未知必须明写，青色不是实时扫描 |
| 浅白 | 诉求、实际对象姓名、主要事实、金额与后果正文 | 关键正文保持足够对比，不为气氛变成灰字 |
| 灰 | 历史时点、来源补充、解释及未掌握状态 | 不吞没必须在决策前读到的费用、期限和缺口；未知不填 0 |
| 红 | 迫近期限、已知损害、当前反制、危险动作 | 必须伴对象、原因/期限或具体损害，不成为普通强调色 |

苏醒保留当前独立紫色语义，避免把原资源类型重新压成同一种金色。先以语义 token 管理，不在不同页面局部手填任意近似色。颜色需要与字体大小、图标、位置共同工作，不要求用户仅凭色相理解规则。

**需看到的后果：**`01` 的世界、诉求、求告者、期限可以依视觉层级快速分开；`02` 的必付与成功/失败条件仍能分别读懂；`06` 展示的是实际语义样例，不能只列色块。所有必要文字保持既定对比下限。

### 4. 当前选择拥有自己的皮肤，身份具有连续指向

左侧当前对象、中央当前诉求和当前回应方式分别有稳定选中语法：浅骨/暖边表面用于对象定位，短实心标记用于选择；键盘焦点保留独立轮廓。未选择时三张祈求同等可选，不给最急一张伪造默认选中。打开祈求后，世界名、求告者、相应身份图形在标题与资料区对应，普通查阅不会改变这个对应。

**需看到的后果：**原稿的“在哪里、正在处理谁”能够在紧凑布局中保持；选中态、键盘焦点、不可用态可以并存且互不冒充。标题和图形提升身份，不把更多大亮面堆到屏幕上。

### 5. 用同一套控件把修正铺到实际页面

先修 `01` 祈求比较、`02` 实际回应与 `06` 控件样板，再检查管理/世界页的同类结构；相同资源、名字、来源、期限和按钮在所有页面用同一语义。保留 `02` 的真实 T4 数字、未掌握四维、费用与概率，不为美术填成熟局示意。

**需看到的后果：**新的材质、图标和文字层级在正文密度较高的 `02` 仍成立，`06` 可以解释已出现的真实控件。不能只把主视觉页修好，而管理/世界页继续保持首版平面线框。

## 复核边界

本诊断只支持沿已选方向定向修正。新材质、色值与图形首先作为可审阅母版提议；最终美术是否成立由制作人判断。后续复核先并置本报告引用的原方向与修订图，再核布局尺寸、文字内容和机器可测对比；不以通过机器检查代替画面判断。

本次不读取或使用已禁用的 `in-game-ux` 及其副本，不改机制、不改中央文化资产、不评价实际引擎输入或动态性能。

## 0.2 实际修订图复核

2026-11-03，在原 `echoes-home/prayer`、`archive-v01/01-round-prayers`、`archive-v01/02-prayer-response` 与新 `01`–`04` 之间作实际看图比较。本节只记录静态画面中的变化；`06` 当时仍在更新，未纳入此次复核。没有重新运行原型。**本轮前段曾参考 `visual-art-production`；制作人明确禁用后即停止读取和执行，不能表述成全批从未使用。**禁用后的本次复核直接依据制作人反馈、已选原稿和游戏语义。

### 已能在画面中看见的修正

1. **材质与边框不再只有同一条灰线。** `01` 三个祈求、`02` 人物/回应、`03` 经营、`04` 现实依托与来源各有暗旧底、局部暖边与角部转折；大面积承字区仍相对安静。外框与内框的同源形状让页面属于同一套控件。原稿的边缘材质已有对应的 UI 表现，不依赖补中央插画才能看见。
2. **选择表面重新明确。** `03/04` 左侧镜证议会选中行由深面变为浅骨面，深色字/图形与其余行明显区分；`02` 浅触与 `03` 守持也有实填表面、边界与勾。相比旧母版，选择状态已经不只靠一枚细勾辨认。其与提交层级的局部冲突见下文。
3. **重要图标重新成为可见对象。** 顶部低语/信仰/苏醒恢复独立资源图形；`01` 三项祈求有不同的内容图形；底部十二权能有明确主形；根钉、余响铃、空名印恢复不同器物外形。`02` 的普通人物标记与“任命”不再共用同一个皇冠。以上是图形职责与可见面积的恢复，不代表人物或圣物最终美术已获批准。
4. **文字出现了语义分组。** `01` 的金色诉求/身份、青色世界与关联入口、白色事实、灰色补充、红色迫近请求可以分别辨认。`02` 必付/成功/失败与灾变行、`04` 四维和反制仍独立；灰色未知没有被重新填成数字。顶部苏醒保留紫色识别。
5. **已有几何与功能负荷得到保留。** 画面中的底栏仍然紧凑，十二项权能可同时看到；新回合三项祈求仍处中央；`02` 实际费用与提交留在固定底部；管理页仍为中央文化资产留独立范围。该结论仅是看图观察，矩形尺寸与可点击性由各自检查负责。

### 值得本轮立即修的两处

**R1 · 期限色在 `02` 与其他页面之间发生语义偏移。** `02` 左侧“第6轮到期”呈青色，视觉上与下方资料/历史入口同类；`01` 的普通期限使用金/骨色，本轮到期使用红色。应把 `02` 的日期恢复到共同期限语义，青色继续用于世界、来源与可追查关系。修后在 `01/02/04` 都能通过相同颜色职责辨别“哪里可查”与“何时到期”，并保留文字本身。

**R2 · 回应/策略的选中态与真正提交同样亮、同一种实填。** `02` 上方“浅触”选中面与右下“以浅触回应”都为浅金实填，上方面积更大；`03` 的已选“守持”也沿用此面。选择已变清楚，但“当前选了什么”与“现在会执行什么”的强调重新靠位置区分。建议把回应方式、策略选择改为温暗材质、清楚金边/短实体标和勾；让真正提交保留浅骨实填。左侧当前对象行可保留浅骨面作为导航定位，因为其位置和形状与执行动作明确不同。修后须同时满足：已选方式仍显著，真正提交是行动区最明确的亮面，未选与不可用不与已选混淆。

不建议为本轮继续扩大装饰或加中央场景。当前可见图形与颜色已经给出沿原方向修正的实物依据；人物个性、独立文化徽记和正式器物材质属于后续资产范围，保留为未验而不据占位图宣布完成。
