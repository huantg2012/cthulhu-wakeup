# 幽界群像 · UI 视觉规范 v0.1

本文件规定本批布局母版和可复用控件的表现，不另立游戏规则。交互、合法阶段、费用、知情及结果以[交互规格](../../specs/ui-interaction.md)和正式 Session 为准；本规范与母版均未接入引擎，也未经制作人视觉终审。中央文化场景、人物与世界资产单独制作。

## 确认范围与本批提议

**已确认：**制作人选定“幽界群像”；本批授权 UI 布局母版、控件拆分和第一版视觉规范。底部功能栏须压缩；轮初尚有待处理祈求时，祈求默认占据中央任务区；减少华丽装饰；气氛明确选定为**“沉重、幽闭、克制的压迫感”**；中央文化资产与 UI 分离。气氛选择不等于每个控件或本批母版已获视觉终审。

**沿用：**高远感知、人物与场所的具体身份、两层主导航、唯一当前行动草稿、固定可见提交、实际对象关联、世界四维及反制、全部十二权能可浏览。普通查阅保留当前行动；视觉聚焦不增加机制关注或隐藏知识。轮初强制事件仍按正式阶段先处理。

**设计提议：**下述几何、颜色、字体、材质强度及动效时长是 v0.1 制作基线，供本批母版直接检验；不冒记为制作人已逐项批准的最终色板。[tokens.json](tokens.json)是本批颜色、字体与矩形的唯一机器数据源；本文说明其语义与使用关系。母版、tokens 与本文须同步，不能把旧图的生成误差固化为规范。

方向参考为 [总览](../../game-state/presentation-refinement-2026-11-03/echoes-home.png)、[祈求](../../game-state/presentation-refinement-2026-11-03/echoes-prayer.png)、[管理](../../game-state/presentation-refinement-2026-11-03/echoes-manage.png)、[世界](../../game-state/presentation-refinement-2026-11-03/echoes-world.png)。保留其远距场所、具象图标和稳定外围；本批明确削弱满屏金边、羊皮纸亮面与花藤角饰。

## 画幅、阅读次序与空间

母版固定 **1600×900**。这是本批制作画幅，不改项目工程分辨率，不增加响应式断点。

- 顶部全局带高 **56 px**。回合/阶段、低语、信仰和苏醒共用一条基线；苏醒保留明确视觉权重，资源名与数值分开。
- 左侧索引 **x16、y76、w208、h668**，含左缘共占 **224 px**。名称、选中、重要期限和检索稳定，不随新消息自动换序。数量多时只滚索引内容，标题和检索保持可达。
- 主区 **x248、y76、w1336、h668**，下沿 **y744**。承担轮初祈求、普通主体、行动和世界态势；不永久预留一块无内容的右侧栏。
- 最新消息 **x16、y760、h32**，一行摘要可展开；完整记录在原深层查看中阅读。新消息不把当前任务挤走。右侧“结束回合”的视觉文字同处此栏，实际独立热区高 **44 px**，范围 **y754–798**，与 **y804** 起的底栏保留 6 px 间隔；不可仅把 32 px 文字带当点击高度。
- 底部功能栏 **x16、y804、w1568、h84**，连同下缘 12 px 留白共同占用 **96 px**（y804–900；与消息条之间另有12px分区间距），约占画高 **10.7%**。不得以缩小正文、裁掉名称或把主要功能藏入悬停来获得空间。
- 十二权能按正式 CSV 顺序保留，同一条栏完整可浏览；当前母版优先一次呈现十二项。若局部溢出，提供明确范围与滚动入口，不生成“常用权能”子集。
- 十二权能在本母版采用单排约 **70×64 px** 的格位；圣物采用右侧 **3 个高 56 px、宽约 140 px** 的格位，实际宽度按剩余区域分配，附总数与独立的查看全部入口。图像用于辨认，名称与绑定/携带状态沿同一实例更新。

第一阅读层是“当前要处理的事及其对象”，第二层是“选择、代价和确定后果”，第三层是“关联资料与全局资源”。外围框架不与当前诉求争同等亮度。

轮初有待处理祈求且进入合法自由行动阶段时，中央先给 1–3 项可比较概览，可直接选择浅触/深应并回应；不强制处理，也不自动替玩家选最紧急一项。切到其他主体后，用紧凑摘要保持待处理数量与回应机会，不强制拉回。已回应后收缩祈求，并交还中央给可继续操作的主体；不把“轮初默认”变成每次导航都抢焦点。

祈求组在主区横向居中，数量减少时不把单项拉满主区：**1 项宽 560 px**（长内容需要时可到 620 px）；**2 项各 392 px，间距 20 px，总宽 804 px**；**3 项在主区左右各留 40 px，间距各 20 px，总宽 1256 px，每项约 405.33 px**。三种状态共用字级与控件高度；数量变化不靠缩字号维持布局。

## 材料与边界

UI 的表现是被幽暗压住的刻痕与薄承载面。窒息感来自外围沉重、局部显露和静默中的异样，不通过模糊文字、压低关键内容对比或持续抖动画面实现。

- **环境层：**近黑冷底，允许大尺度不均匀暗部；不在承字区覆盖密集颗粒。文化画面在中部显露，环境可在场所外缘吞没细节。
- **承字层：**近乎不透光的暗面，保留极轻纹理。列表行以间距和短分隔组织，不给每行再套一层繁复框。
- **一级边界：**仅当前祈求、当前行动与必要确认使用完整细轮廓；外沿常规 1 px，重点边缘最多 2 px。常态不发光。
- **二级边界：**普通资料用分隔线、标题或局部侧标，不重复包边。没有交互意义的边线允许低对比；可操作轮廓须另有合格的文字/标记。
- **装饰：**保留少量不对称缺口和被侵蚀的角部；同一控件不叠加花藤、金属亮边、宝石、纸张撕边四套语言。装饰不进入文字内边距。
- **主执行：**当前可提交动作采用 `accent` 骨色实填、`void` 深色文字，作为当前唯一强强调；普通查阅、回应方式选择与返回沿用深面细边。实填仅用于当前提交，不铺满多个导航项或整张祈求。

## 字体与尺寸

标题可采用有稳定中文覆盖的宋体类字形，正文采用清晰的中文黑体类字形。正式字体须另核可分发授权、数字字形与缺字回退；母版预览字体不自动成为打包字体。

| 层级 | 尺寸 / 行高 | 用途 |
| --- | --- | --- |
| 主任务标题 | 32 / 44 px | 轮初中央主诉求/该屏主任务；每屏只一处 |
| 普通主体/区块标题 | 28 / 36 px | 具体祈求、人物、教团、世界及区块标题；每区只一处 |
| 分节/重要数值 | 22 / 30 px | 回应选择、资源、重要期限 |
| 正文/操作 | 20 / 30 px | 诉求、代价、后果、执行动作、对象名 |
| 辅助信息 | 18 / 26 px | 来源、观察时点、列表副行、底栏名称 |

正文不以 16 px 以下尺寸承载。底栏通过减少容器高度、图标外圈与留白压缩，权能图标 **28–32 px** 配 **18 px** 名称。重要金额、期限及操作不减为脚注。数字使用等宽数字特性（字体支持时），标签、数值、单位相邻但分字段。

长段落左对齐，优先 30 px 行高；普通承字区四周至少 16 px，关联行间 8 px，独立段间 16 px。只在短按钮、权能名称和单个数值上居中。标题字形可有历史感，正文不加发光、描边或大字距。

## 颜色与可读性基线

下列颜色是本批低饱和 UI 试用值，承担跨世界不变的全局语义，不是每个世界各换一套的界面皮肤。世界文化的材料色、局部灯光与邪神反馈色不由此全局统一；它们接入时须守承字区和强调预算。

| Token | 值 | 语义 |
| --- | --- | --- |
| `void` | `#080E12` | 环境底与外缘 |
| `surface` | `#10191D` | 稳定承字面 |
| `raised` | `#182227` | 控件面与轻微层次；不独自承担选中语义 |
| `text` | `#D9D8CD` | 正文、名称、主要数值 |
| `secondary` | `#A6AFAA` | 来源、说明、历史时点 |
| `accent` | `#C7BA96` | 骨色：当前选择、焦点、当前提交实填 |
| `risk` | `#D88A7A` | 已知损害、迫近期限、当前反制 |
| `divine` | `#A99ABB` | 神意/权能反馈，少量出现；不代成功色 |
| `line` | `#43504F` | 无独立语义的分隔线 |

静态纯色样本对 `surface` 的对比分别为：`text` 12.43:1、`secondary` 7.92:1、`accent` 9.24:1、`risk` 6.65:1、`divine` 6.81:1；主按钮的 `void` 文字对 `accent` 实填约 10.07:1。该计算不证明纹理、透明层与场景合成后的实际可读性。

实现验收下限：正文及任何必要理由 **≥4.5:1**；有独立语义的图标、选中标记、键盘焦点与控件边界 **≥3:1**。`line` 对承字面只有约 2.12:1，`raised` 对承字面约 1.10:1，两者不可独自承担这些语义；需配可读名称与合格标记。由 Code 在色值和实际合成采样中执行检查；本批文档没有宣称运行时闸门已实现。正文背后不得出现会使合成对比跌破下限的亮纹理或雾光。

风险色同时带实际对象、事件名与期限；不以红色/绿色单独判好坏。不可用仍保留可读名称和具体原因；未知用“未掌握”，不使用灰色 0。屏障、污染、察觉、稳定各自具名，颜色不把四维合并为单条占领进度。

## 图标及交互状态

权能用可在 28–32 px 辨认的实意轮廓：每枚一个主形，内部最多两层重要结构；不靠细密圆环与小符号区分。圣物保留物件小像和稳定轮廓。两类尺度、表现职责不同，不混成同一排抽象花纹。任何首次出现或易混图标均配名称。

**本批母版范围：**当前代码原生 SVG glyph 仅用于位置、线条与尺寸研究，是占位资产；其形状不定义正式人物身份、教团徽记或圣物小像。最终权能图标与圣物资源绘制另行按上述职责制作，当前占位不能作为“完整美术资源已交付”的证据。

| 状态 | 可见表现 | 行为约束 |
| --- | --- | --- |
| 静默可用 | 正文对比、克制边界；不持续闪光 | 名称/目标可直接辨认 |
| 当前选择 | 骨色短边、实心小标记、轻微面色差 | 改选择不移动控件或改变尺寸 |
| 键盘所在 | 独立细轮廓，与当前选择标记可同时看见 | 鼠标移走不抹掉键盘位置 |
| 指向可操作项 | 同尺寸轻亮一档，必要时显示补充说明 | 必要费用、理由不只藏在指向提示 |
| 正在执行 | 原位置写执行中，阻止重复提交 | 不播放假成功；完成后读正式结果 |
| 条件不足 | 图像压低强调、名称仍可读，先列实际缺口 | 可查看详情；执行不形成可收费路径 |
| 本轮已回应 | “本轮已回应”明确标记，收缩为只读摘要 | 不保留看似还能提交的高亮 |
| 迫近或已知损害 | 风险色短标、事件名、对象和期限 | 不与普通选中共用唯一标识 |

主提交使用明确动作，如“以浅触回应”“施行入梦”；与费用、对象和本轮机会放在同一可见位置。浅触/深应各自保留必付代价和条件后果；费用改变时更新原行，不跳出独立提示抢焦点。二次确认只用于正式交互已规定的事项。

## 遮罩、动态与实际反馈

- 普通对象查看不加全屏黑幕，不中断当前草稿。祈求居中属于主任务区状态，不是另开一个封住全局的弹窗。
- 需要阻断的正式事件/确认使用稳定暗幕，首版建议黑色 **48%**；正文面保持不透明。遮罩位于世界与外围读数之上，窗口之下；不得留下可误触的背景按钮。
- 本批建议控件反馈 **100–160 ms**，主区显露/收束 **240–360 ms**。固定文字、资源和操作不随雾层位移，不用弹跳缩放。
- 窒息感由文化场所外缘逐渐被吞没、低频微弱环境运动、主动作前后的短暂明暗变化承担。阅读时画面不连续闪动；实际动画保持可关闭或缩减的技术余地。
- 行动后先呈现正式结果中的对象、实际变化与持续状态；神意脉冲/局部显露只作辅助，不替随机结果预演成功。源头不明确的视觉变化不制造新事实。

## 空、多、长与历史状态

- **无教团/无圣物：**保留对应入口与真实数量，显示短空态；不陈列伪造的锁定收藏品，不在中央永久占据大空面。
- **祈求 1–3 项：**中央先比较实际对象、诉求和期限，再展开所选项；不拉伸单条为巨幅海报。零合法请求依正式供给/错误状态显示，UI 不编一张补位卡。
- **同轮已回应：**保留只读记录与关联对象；下一步主体占据主区，不让不可执行的长祈求继续压住全部内容。
- **多对象：**列表局部滚动，保留数量、查询和所处范围；选中的对象离屏后仍有可定位标记。新危机追加摘要，不抢正在读的行。
- **长名称：**索引允许两行，必要时省略且选中页显示完整名称；目标确认、费用、期限和风险正文不省略。不得通过持续缩字塞入。
- **长诉求/长结果：**中央正文局部滚动，身份、关键代价及提交固定；长原文可展开，关键风险在原提交面仍存在。
- **不可用：**在投入选择/滚动之前说明最先可解释的实际原因；多个缺口可以展开。灰态不等于对象失去身份，也不等于可以跳过检查。
- **风险：**当前反制按对象、期限、已公告后果呈现；未知概率/隐含后果不得填成确定文本。请求期限与原危机期限分别标注。
- **历史/未知：**每项保留“第 X 轮观察”“估计区间/当时确值/未掌握”的区别；老记录不做持续呼吸光或“实时”暗示。打开页面不会刷新事实，聆听旧来源不变成实时扫描。

## 中央文化资产接入合同

UI、场景、动态反馈必须可独立修订。中央文化资产不含文字、数值、按钮、固定名称或 UI 边框；文化场所不得画成带假点击区域的成品截图。

1. 场景按固定画幅提供主体范围、人物身份定位点、允许裁切区、承字避让区与前景遮挡层说明；具体文化资产另列清单，本文件不建立建筑或服饰设定。
2. 提供同一地点可对应的远感知与聚焦表现。放大与显露保持场所、人物身份和主要器物关系；UI 不要求整屏持续三维镜头运动。
3. 场景允许被 UI 挤出、裁切和遮蔽的区域须明确；人物标记挂稳定定位点，固定资源、索引、摘要、提交保持屏幕坐标。场景缩放不带动 HUD。
4. UI 的承字面必须自行保证对比；中央场景的亮点/火光不穿过费用、期限和按钮。场景可见性与视觉聚焦不授予新的世界知情。
5. 不把建筑明暗、人物姿态或人数作为未注册状态的唯一编码。领袖失效、圣物绑定、反制等仍有正式文字及图标，画面变化只能由实际公开状态驱动。
6. 独立交付环境底、场所主体、必要遮挡、局部运动和实际回应反馈层；本批只规定可拆分边界，不承诺每个文化必须有同样层数或同样资产数量。

## 本批审阅与后续验证

本批人工视觉审阅看五件事：底栏是否让出实质空间；轮初是否立刻读到具体祈求；去掉花纹后是否仍保有幽界群像的身份；窒息感是否来自空间与明暗而非难读；中央文化区域是否能独立替换而不破坏信息次序。

实现前再核母版几何、字体授权、真实最长内容、全部十二权能、混合知情精度与提交位置。引擎内需实际检查键鼠焦点、滚动、取消、保存恢复与正式结果；颜色对比、矩形和按钮可达性由机器检查，人判断画面气质与阅读疲劳。当前仅文档/母版交付，不记录美术、交互、性能或整局验收通过。

本批不读取或使用已被制作人禁用的 `in-game-ux` 及其副本、附属经验；不重开整体视觉方向抽卡。
