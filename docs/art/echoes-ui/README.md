## 本批改变与保留的边界

- 新回合合法进入actions后，待处理祈求默认占中央；events依原机制先处理。玩家仍能先查资料、使用权能或跳过回应，不自动选择“最急”一项。
- 每轮只有一次回应机会；执行失败也会用掉。其他祈求保留只读查看，不能继续显示有效提交。查看关联对象不替换实际行动目标。
- 底栏压缩冗余留白与容器厚度，保留32px权能图形及48px圣物位置，十二权能仍按固定顺序展示。未解锁标记不代表其余权能必定有合法目标；正式接入时必须展示当前缺口和可用性。
- 压迫感采用深暗包围、哑面与有限亮部；正文、焦点、费用、期限保持可读。动画只列规范提议，未制作或验证。
- 无新玩法、无CSV数值调整、无角色/教团命名规则变更、无中央文化资产制作、无引擎UI替换。

## 重建

HTML仅为内部PNG渲染源，交付以PNG和Markdown规范为主。设计稿不提供可玩的HTML替代品。

```sh
python3 tools/ui-master/build.py
node tools/ui-master/render.cjs
```

构建读取正式CSV与已保存的`runtime/prayer-preview.json`，不会运行游戏、修改存档或重算概率。渲染使用Playwright与本机Chrome；其他机器通过`PLAYWRIGHT_MODULE`和`CHROME_PATH`指定路径。源码在`tools/ui-master/`，修改母版先改源码，再生成PNG及检查记录。
