## 实际实现

- `world.js` 保存本轮选定的原作色板角色；原服务会与 `EData` 核对选定色板。粗布、亚麻、石灰岩、盐、湿岩、水与铜的材料基色由这些角色混合得到，不是最后统一着色。
- `portrait.js` 先定义连续披衣、头颈遮蔽、肘腕与托盏关系。曲线只定义褶皱约束，`foldField()` 从连续曲线距离及沿线衰减形成高度。袖子不是曲线扫掠的圆截面，肩膀也没有独立球状法线。后续改成宽袖向肘下垂落，去除贴臂回弯形成的管状暗边。
- `sanctuary.js` 先定义二维斜俯视轮廓与遮挡顺序：两段不同高度的潮蚀岩岸、残顶礼拜堂、分段阶梯、跨隙桥、下沉环井、洞穴与码头。屋面、干墙、湿崖、铜与布各自有材料约束。礼仪队列、持灯者、供物、渔网、铜钟和舟只依附在这些位置。
- `engine.js` 对各材料区域计算相关的颜色、绘画高度、反光与局部发光。岩石胞格缝只用于石材，砖砌墙另有斜向灰缝；布料采用受力褶场、定向纤维和染色场；水的螺旋与反光受水域限制。湿区影响石色与反光，局部腐蚀同时影响颜色/高度/发光。
- 高度差分作用于二维插画指定的朝向。受光借鉴原作的漫反射曲线、暖色明暗交界与材质镜面；另有屏幕空间的潮水与烛火局部照明、显式遮挡阴影。**它是插画近似，没有任意视点、完整空间投影或光线追踪，不等同原球面算法。**
- 每次运行输出材料色、形体受光和完整受光三个中间图。辅助 normals 输入刻意为空，以兼容原 API 并跳过上轮的 Godot 表面 shader；本轮表面和受光在浏览器中生成。
- `style_2d.gd` 在独立临时工程中保留原天空、bloom 与 post 程序。二维插画将 `px_scale` 设为 **0.68**，保留中尺度褶皱和建筑细节；**原作星球仍用其原来的参数，原作源码没有修改。** 因此不能声称二维与原球体使用完全相同的后期配置。

没有 ImageGen、预画成品随机抽选、新增三维人物/建筑/场景模型。没有复制原球面的 Voronoi 覆盖人物。二维轮廓和场的规则本身仍由作者设计；单对母版自身不包含姿态文法；新的人物文法见下节。
