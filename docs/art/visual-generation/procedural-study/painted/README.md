# 当前：一个人物、一个教团的直接二维绘画

制作人已退回上一轮假人与底盘方案。按最新要求，本次停止原型扩展和测试矩阵，固定溺亡之海 / 世界 1339 / 人物 1339 / 色板 0 / 暗黑厚涂 sid 0，只重做一对实际画面。当前入口：http://127.0.0.1:8951/painted/ ，原 `二维绘景新样本.command` 仍可启动。同尺度对照在 `evidence/focus/comparison.png`，实际参数和输出在同目录。

## 换掉的生成方法

当前入口使用 `focus-person.js`、`focus-cult.js`、`brush.js`。不再调用旧 `person.js` / `cult.js` 的分段曲线袖面、圆肩、坡度场和整块地面生成。`field.js` 只提供确定性随机、颜色和噪声数学函数，其 Painter、drape、sleeve 均未被当前绘画调用。

这次直接画完整色料图：整体轮廓 → 大明暗区 → 遮挡/投影 → 材料分区 → 顺褶皱/岩层的定向笔触。空辅助图只是兼容既有 API；`style_2d.gd` 对空辅助输入使用普通 CanvasItem，**不执行旧法线/坡度 shader**。原天空与 bloom/post 保持原实现。没有新增三维模型，没有 ImageGen，也没有从成品图中随机选择。

人物：完整披衣轮廓包含肩部，近侧弯臂与远侧前臂通过衣料覆盖、受力褶和遮挡辨认；手抱潮历，不画独立圆肩或等宽袖管。近侧亮部偏暖绿，远侧与下摆偏蓝紫，帽内空洞保留。

教团：用高处洞窟、三段祭径、下沉潮井、桥下裂谷和低处潮汐登陆点形成不同高差；祭径串联日常供物、侧龛与潮井围聚。水只处在沟谷/井内/下方海面，不再给整片场地加一个共同底盘。灯火、潮井冷光和湿岩反光各有限定位置。

## 原作研究落实

重新阅读 `s_drowned`、腐蚀层、夜光层和 `common.style_shade`：原作的海陆阈值负责材料区隔；石地胞格变化受陆地约束；湿面与石面镜面值不同；发光由少量裂缝、涡心和侵蚀位置控制；大球体明暗决定后续细节的可见性，后期只组织已有颜色。

本次转译的是这些绘画组织关系：先保留大面积暗部，暖色盐蚀与冷湿面分区，局部祭火/水光形成焦点，岩层与衣料各用自己的笔触方向。二维明暗和投影由绘画规则表达，**不是原球面算法的复刻，也不具备任意光源下的物理重照明能力**。

已实际生成并查看首稿和两次局部绘画修正，最终亲自查看与用户案例的并排截图。没有运行或增加同参/hash/全原型测试矩阵；上轮测试记录只适用于上轮，不能用作本次美术证明。原星球仍由原 API 按同参生成/使用对应缓存，未修改原作源码。
