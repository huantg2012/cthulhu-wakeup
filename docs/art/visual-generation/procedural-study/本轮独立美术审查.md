# 独立美术审查：原型三联图的失败及重做依据

审查对象：`evidence/all-archetypes/` 中上一轮 11 组输出，结合 `family.js`、`paint.js` 与原作 `planet_body.gdshaderinc`、`noise.gdshaderinc`、`common.gdshaderinc`、`post.gdshader` 源码。审查者参与过上轮制作，不是盲审。本记录先于本轮重做；审美结论不由代码检查代替。

## 画面与结构

1. **观看尺度错误**：多数教团只有一个扁平的正面图形加薄底座，俯视面、两侧面和前后遮挡没有共同透视。角色和工作痕迹少，读不出可供人活动的地方；星球则是有前后、明暗和表面层次的完整天体。应把场地、建筑、屋顶、台阶放进同一斜俯视坐标，再按深度绘制，不能拿等腰三角形堆在圆盘上充当微缩场景。
2. **人物像陶罐**：上一轮大形是包住手臂的圆角梯形，肩、肘和胸廓没有层次，头是圆孔；左右对称、无颈和肩部倾斜，身体在画幅下缘封口。服装并不遵循人体受力，装饰更改不能修复轮廓。应先安排头颈、肩、肘、腕和躯干的连接，再绘制遮盖这些结构的袖子、斗篷或围领；画幅可在胸腰处自然裁切，不用画成容器底。
3. **个体不可区分**：原型固定姿势/体型，仅细节受 seed 影响；世界和人物共用 seed，改变角色同时改变星球。应将世界种子和人物种子拆开，同一世界内可改变体态、姿势、头部遮蔽方式、衣服结构与持物，且这些变化要能在缩略图读到。
4. **材质与空间脱节**：`paint.js` 根据每个路径包围盒造一个近似凸面的法线，长方形墙、布条和手套都像软膨胀体；每片独立重新算光，不能组成连续体积。需要将建筑面显式标注平面朝向，将布料褶皱、体块和缝线分开，避免把每条路径都当独立球面。
5. **细节频率和美术语言错位**：原星球有大轮廓、受光过渡、中尺度地形和少量高亮的层级。旧对象主要靠粗矢量色块、强轮廓与稀疏符号，后期虽相同也不会产生相同的层次；尤其星之彩仅取紫色，丢失原作的虹彩。不能再把“引用了相同函数”说成“画风已对齐”。

## 原作方法：从结构到画面

- 原作先有球面几何和统一法线、方向光、环境光与边缘光；每一种 `s_*` 输出表面颜色、发光、镜面、**高度**。高度同样参与扰动法线，因此局部颜色与受光有联系。大尺度明暗先来自球体，再叠地貌；不是靠给平面加噪点构建形。
- 原型 0：扭曲 FBM 地形决定海陆与近岸，Voronoi 仅在陆地形成地块和裂缝，漩涡单独作用于海。1：扭曲 FBM 与两尺度梯度脊纹，巨眼由另一个函数处理。2：FBM 体积＋胞团＋噪声脉管，脉管同时影响颜色/高度/发光。3：ridged 地势、菌落蒙版和稀疏胞格孢点，不是全画面均匀菌斑。
- 4：两种尺度的 Voronoi 裂缝与熔岩阈值驱动亮热区、凹陷与发光。5：量化 FBM 台地、噪声裂缝和按纬度分布的雪。6：胞格边缘、视角和 FBM 共同决定虹彩以及边缘发光；不能只用调色板替代。7：扭曲 FBM、沙纹、湖面阈值和密集城市胞格缝。8：多级 FBM 域扭曲的流动色带和自发光，不使用胞格地表。9：胞格裂缝、方向条纹和脉管协同改变高度与发光。10：两种尺度的胞格中心定义坑穴和坑沿，叠加噪声高度。
- 风格不只是最后滤镜：`style_shade` 改变漫反射分段、环境光和补光；`post.gdshader` 分别处理厚涂 Kuwahara、赛璐璐描边、铜版排线、像素量化、水彩晕染、杂志网点。星球的背景、灯光和后期与主体分层。教团/人物仍要各自有可信结构和材料，才能得到相近的表达。

## 本轮可核对目标与边界

- 教团：地表能看见顶部和两个不同朝向的侧面；屋顶、墙、台阶沿同一投影；前后物体存在遮挡；11 原型有自身主题配置，种子改变场地结构。直接二维投影绘制，不新增三维模型。
- 人物：肩宽、脖颈、上臂、前臂连接并可辨；衣装不形成密闭陶罐；同世界不同人物种子必须改变明显轮廓/姿态/头部，而不是只换饰物。角色是视觉候选而非正式玩法对象。
- 风格和材料：复用原有函数和风格但如实说明二维域的简化；至少比较几个差异明显的原型、画风和同世界多个角色，原星球按同参数保持原作输出。任何自动验证仅说明功能，不宣称美术已获得制作人认可。

## 制作人纠偏及实际复看（本轮）

上面的“斜俯视网格 + 面朝向 + 建筑几何”虽然输出二维路径，实际创作方式仍是用盒体组合来模拟建模；实屏见 `evidence/geometry-rejected/first-attempt.png`。它比制作人给出的上一版更像简化模型：村落空旷、结构机械，人物四肢像硬块盔甲且依旧类似容器。同世界六个人物的截图见 `evidence/geometry-rejected/person-seeds.png`；姿势/头饰变化不能弥补绘画和形体的退步。**该方法已退回，不作为制作方向。**

生成入口已恢复制作人截图对应的 `cult.js` / `person.js` 绘画基线（溺亡之海、黄衣王城）与上一轮其他原型实验；恢复后的对照为 `evidence/geometry-rejected/restored-baseline.png`。增加了独立人物种子，但基线 0、7 只有两种手势和有限轮廓变化，其他原型也未满足人物数量所需的差异化。原星球生成源码未改，画面恢复不等于美术通过。

真正尚待解决的是**二维程序绘画的表示和生成方法**：人物不能只靠几个凸形片、切割布片或形式化骨架拼接；微缩场景不能只靠投影盒体；而原作程序地表的不同尺度与材质耦合也不能简单移植为均匀覆盖的石纹。需要让强模型围绕这一问题提出并实现绘画算法，目标、文件和可核查结果见 `ASTRA-ULTRA-生成算法任务书.md`。
