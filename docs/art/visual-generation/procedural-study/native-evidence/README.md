# Godot 原生迁移证据

当前生成入口：仓库根目录 `诸界立绘生成.command`；游戏工程内场景 `res://src/art_generation/workbench/workbench.tscn`。全流程 GDScript、Godot shader、Image 与 SubViewport；未接 Session。旧网页和服务器不参与生成。

- [实际工作台](workbench.png)：原生控件、世界和教团预览、人物列表；点击图可放大，阶段下拉可看材料／形体／完整受光，按钮可导出 PNG 和参数。
- [冷原与炎狱并排](two-worlds.png)：每个世界展示原作星球、候选教团、四个独立种子人物。世界种子均为 1339，人物种子为 1000–1003，sid 0；冷原色板 4，炎狱色板 6。
- [迁移前后对照](migration-comparison.png)：同参潮汐世界／教团／裁决者，世界 1339、人物 1000、sid 0、色板 0。上行为已有历史输出，下行为 Godot 内实际生成。人物构型及教团布局沿用现有版本，没有借迁移做一轮身份／姿态重设。
- [水彩不同画风](bone-watercolor/person-0-1000.png)：骸骨之月，sid 6、色板 8；同目录有对应世界与教团。
- `tide/`、`frozen/`、`fire/`、`bone-watercolor/` 中保留各自最终图、材料色、形体受光、完整受光及 `parameters.json`；[samples.json](samples.json) 是本轮实际出图范围。

## 必要检查结果

- `check_rules.gd` 在 Godot 内建立全部 11 原型教团与各世界支持的人物背景，全部运行完成。计数保持潮汐 6 类／48 种离散组合，其余 4 类／24 种。此项只证明构造规则可运行。
- [invariants.json](invariants.json)：潮汐裁决者同参重绘最终像素一致；人物种子 1000→1001 后人物图改变，世界和教团像素不变。限定同主机和渲染器，不声称跨 GPU 字节一致。
- 原作参考目录逐文件 SHA-256 与迁移前记录一致；新模块采用独立移植副本与局部 shader 参数，没有修改原始 `godot-base`。
- [pixel-comparison.json](pixel-comparison.json)：同参迁移对照存在细微像素差异。世界平均通道误差约 0.28–0.40／255、教团约 1.28–1.61／255、人物约 0.67–0.81／255；少数边缘误差明显高于均值。这些数字只辅助定位，不能代替看图。
- 本轮亲自查看了原生世界、教团、人物大图、旧版同参图、冷原／炎狱并排和另一画风。结构、职业造型差异与主要光团保留；没有宣布新审美通过。

## 实际覆盖与剩余边界

实现保留 11 原型 × 6 画风选项；本轮实际完整生成检查为潮汐、冷原、炎狱的 sid 0，以及骸骨 sid 6，不代表全部 66 组合逐一出图或获审美批准。GPU 导数、曲线栅格抗锯齿、局部柔化和细碎笔触与历史 CPU 版本不逐像素等价。当前冷原的亮领口和原人物姿态等既有表现保留，后续美术调整应走独立反馈，不混入技术迁移。

输出固定 960×960。当前采用串行请求与当前世界内存缓存；实际记录的暖启动样本约 4–9 秒一组，编译冷启动更慢，不能据此承诺正式每回合卡片预算。后台离屏渲染显式推进帧，生成结束停掉后期视口更新。正式回合调度、缓存持久化、正式 NPC 绑定、目标平台性能／导出打包未接入。
