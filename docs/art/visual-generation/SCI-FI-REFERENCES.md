## 1. 具名参考（已核实）

| 参考 | 出处 | 借的工程形态 |
| --- | --- | --- |
| **卡尔达肖夫尺度** | Nikolai Kardashev, 1964，按能量利用把文明分 I 行星级 / II 恒星级 / III 星系级 | 三档分级本身的骨架 |
| **戴森球 / 戴森云** | Freeman Dyson, 1960《Science》"Search for Artificial Stellar Sources of Infra-Red Radiation"；思想实验灵感可追至 Olaf Stapledon 1937《Star Maker（造星者）》 | 围绕恒星的**轨道结构群／完整壳**，截获恒星输出；文明已不住在行星上 |
| **环形世界 Ringworld** | Larry Niven, 1970《Ringworld》 | 绕恒星的**一条完整巨环**，内侧是连续人工地表，边缘墙与阴影方块；从远处看是一条连续环带，不是碎片 |
| **轨道环 Orbital ring** | Paul Birch, 1982 起发表于 JBIS | **绕行星的一圈环 + 垂到地面的固定缆索**，用于发射与运输；从太空看是「球被一圈结构系住」 |
| **超行星／壳世界 Supramundane world / Shellworld** | Paul Birch 的 Supra-Jupiter 概念（JBIS 1982 起）；Orion's Arm 的 Shellworld 词条 | 在行星外建**同心壳层**把整颗行星包起来，外面是新表面；Orion's Arm 版本还把地表下挖成内层球体并填充空气、水与照明，使表面积翻倍 |
| **行星拆解作为建材** | K2 文明的常见设定（拆行星造轨道栖息体） | 行星不再是容器而是**原料**；文明已脱离母星 |

## 2. 禁令（防止照搬与跑偏）

1. **只借工程形态与尺度关系**：环带、壳层、缆索、连续面板、阴影方块这类**视觉拓扑**；不用作品名、角色、专有名词、剧情设定。
2. **不引入数值**：半径、功率、质量、转速一律不写进设定，也不作为画面依据。
3. **不出现文明细节**：城市、机构、招牌、居民、记录、灯火、证言、契约——天体图承载不了，制作人已明确现在不做。
4. **不做盈亏**：全域均匀照明，无昼夜半球、无相位感。
5. **不套原作视角**：不用 `scene / composition / 11 个 ARCH 原型` 那套镜头设计；三种等级共用同一观察位置。
6. **参考只用来钉方向**，不替代本作设定：每个世界仍由 `civilization_profiles.csv` 的原型场决定形态，四个原型必须给出四种不同的建造方式。
7. **宇宙级禁止散落小碎片**：必须是连续、巨大、几何精确的单一巨构；不放中央圆核。

## 3. 三档 → 参考锚点 → 可见形态

| 等级 | 能力层 | 参考锚点 | 该建成了什么（画面） |
| --- | --- | --- | --- |
| **星球级** | K-I 以下，地表薄层 | 现实地表文明；早期 terraforming 意象 | 一颗完整自然行星 + 极稀疏夜面灯点；**没有任何巨构** |
| **星系级** | K-I → II，开始动用轨道尺度结构 | **Paul Birch 轨道环**、**Supramundane shell / Shellworld** | 母星被**连续人工壳面整体包覆**（全球重构，不是挖洞），外面一条倾斜的**轨道环**；球体仍是主体，但一眼看出已是工程体。**垂到球面的缆索／塔尚未实现**，是下一版待补部件 |
| **宇宙级** | K-II 以上，行星成为原料 | **Niven Ringworld**、**Dyson sphere/swarm**、多层壳（Matrioshka 式）、行星拆解 | 母星**完全不作为球体出现**，只剩连续巨构：环世界／多层同心壳／正交轨道环阵／胞格穹顶；无球面、无地平线、无散片、无圆核 |

### 四种原型对应的建造方式（差异必须显著）

| 原型 | 星系级：怎么包覆 | 宇宙级：留下什么连续巨构 |
| --- | --- | --- |
| 潮界 · 灰湾 | 沿螺旋洋流带铺经向巨型条带壳面，轨道环沿螺旋相位倾斜 | **环世界**：两条倾斜大环带 + 一条内环 |
| 层台 · 石阶 | 沿量化台阶铺水平层板壳面 | **壳世界**：三层同心球壳骨架 + 一条环带 |
| 陨野 · 环野 | 沿坑环铺同心环带壳面 | **轨道环阵**：两个正交大环 + 中环 |
| 菌原 · 斑原 | 沿细胞缝铺胞格模块壳面 | **胞格穹顶**：大球壳骨架 + 两条斜环 |

壳面与巨构都保留各自原型原有的色板与场纹样，所以同一等级下四个世界仍然不同。

## 4. 为什么这一版不再是「薯片」或「挖洞」

- 上一版把「拆解」做成 20 个压扁球（散落扁片）→ 换成 **Ring 网格（连续环带）+ Planet 网格（连续球壳骨架）**，构件数量从 20 降到 2–3 个、**每个都是单一连续大结构**。
- 上一版把「破坏性」做成在球面挖洞露内层 → 换成 **全球连续人工壳面 + 轨道环 + 缆索**，是「建成了什么」而不是「破坏了什么」。
- 参考锚点决定了形态下限：Ringworld 是一条环，Dyson shell 是完整壳，Orbital ring 是环加缆索——都不允许出现一堆零散小块。
