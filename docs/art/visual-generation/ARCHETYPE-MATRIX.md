## 1. 原作「星球原型」的核心原理

### 1.1 不是 11 张贴图，是 11 份**程序化场配方**

`shaders/planet_body.gdshaderinc` 里 11 个 `#if ARCH == N` 分支，每个都在算一份 `Surf`：

```glsl
struct Surf { vec3 alb; vec3 emit; float spec; float h; float land; };
```

**所有原型只往这 5 个槽写值**。之后的光照 `style_shade`、凹凸 `perturb_normal`、符文铭刻、腐化蔓延、众眼、夜面灯、环阴影、菲涅尔大气、8 种媒介后期、装帧——全部共享、完全不知道前面是哪个原型。

> **第一原理：统一输出契约。** 换原型 = 换内容生成函数，不换后面整条管线。这是「11 种画面只花一份管线的钱」的原因。

### 1.2 一套可组合的算子库

`noise.gdshaderinc` + `planet_body.gdshaderinc` 提供：

| 类 | 算子 |
| --- | --- |
| 噪声场 | `hash13/33/12/22`、`gnoise3`、`fbm3`、`ridged3`、`voronoi3`（F1/F2/cell id） |
| 域变换 | `warp3` 域扭曲、多级 fbm 自反馈、`rot2` 旋转 |
| 解析几何 | `crater/rim` 陨坑、`sd_segment`、`circle_line`、`glyph_dist` 生成式文字、`apply_eye` 眼睑/虹膜/瞳孔 |
| 阈值与坐标 | 海平面 `smoothstep`、纬度冰盖、高度量化 `floor(h*7)/7`、`atan2` 对数螺旋、余弦调色板 |
| 描线 | `fwidth` + SDF 恒定线宽 |

### 1.3 配方之间差的是**场的类型**，不是参数

| 原型 | 配方（结构性差异） |
| --- | --- |
| 溺亡之海 | 域扭曲 fbm 高度场 → 海平面阈值 → 对数螺旋漩涡 → Voronoi 石缝 → 海岸线 |
| 凝视之眼 | 脊线 `pow(1-|noise|,6)` 皱纹 → 参数化单巨眼 |
| 血肉之星 | Voronoi 细胞 + 血管脊线 `pow(...,14/18)` + 脉动 |
| 菌蚀冥星 | `ridged3` 山脉 + 纬度冰盖 + Voronoi 菌落斑点 + 呼吸 |
| 炎狱之星 | 双层 Voronoi `F2-F1` 裂缝 + 熔岩阈值 + 闪烁 |
| 冷原 | 高度量化台地 + 雪线 + 裂纹 |
| 星之彩 | Voronoi cell hash → 色相 → 余弦调色板 `cos(TAU*(hue+vec3(0,.33,.67)))` |
| 黄衣王城 | 正弦沙丘 + 湖 + Voronoi 城市网格发光 + 夜面灯 |
| 混沌核心 | 三级 fbm 域扭曲自反馈 |
| 古神之茧 | Voronoi 裂缝 + 纵向条纹 `sin(p.y*60)` + 脉动 |
| 骸骨之月 | 双层解析陨坑 `crater = (d²-1)*0.35`、`rim = exp(-((d-1)/0.18)²)` |

> **第二原理：换的是场。** 溺亡之海用「阈值」造海陆，冷原用「量化」造台地，骸骨之月用「解析式」造坑，星之彩用「cell hash」直接造颜色。这不是同一张图调参，是换了生成逻辑，所以视觉熵才高。

### 1.4 编译期与运行期解耦

`main.gd:75-79` 为每个原型编译一个 `#define ARCH N` 的 WebGL program（结构差异走编译期）；`data.gd:54-66` 的 `ARCHETYPES` 表给每个原型配 `pals / sea / night / atmo / bump`（外观差异走数据表）；`generator.gd:181-213` 把色板、符文、腐化等逐实例 uniform 注入。

> **第三原理：结构用宏、外观用表与 uniform。** 加新原型只需写一份配方 + 一行表，不动管线。

## 2. 做法分解（可复用的五步）

1. **定契约**：先钉死 `Surf`，让所有下游只依赖它。
2. **建算子库**：噪声 / 域变换 / 解析几何 / 阈值 / 描线，做成可组合函数。
3. **写配方**：每份配方至少更换**两类算子**（场类型 + 阈值方式 + 坐标域），避免沦为换色。
4. **共享后处理**：光照、风格化、装帧全部一份。
5. **配方与参数表分离**：结构进编译期变体，色板/强度进数据表。

本游戏照此重做，但**原型名与题材按本作世界观重写**，剔除触手、众眼、克苏鲁音节专名。

## 3. 本游戏方案：原型 × 改造等级的二维矩阵

### 3.1 轴 A：母星原型（本作 4 个工作原型）

统一契约扩展为 `alb / h / land / keyline / keyid`：新增的 `keyline` 是该原型自己的**关键场线**，`keyid` 是场单元 id——两者供改造层使用，是「改造以原型为材料」的接口。

| 原型 | 配方 | 关键场 `keyline` |
| --- | --- | --- |
| **潮界** | `warp3` 域扭曲 fbm + 海平面阈值 + 对数螺旋洋流 + Voronoi 石缝 | 海岸线 + 石缝 |
| **层台** | `floor(h*7)/7` 高度量化台地 + 雪线 + 脊线裂纹 | 台地跳变边界 + 裂纹 |
| **陨野** | 双层解析陨坑 `crater/rim` + 无大气灰壤 | 坑环脊 |
| **菌原** | Voronoi 细胞斑 + 血管脊线 + 余弦调色板 + 呼吸 | 细胞缝 + 脊线 |

每个原型配自己的推荐色板（对应原作 `ARCHETYPES[].pals`）：潮界深海靛蓝 / 层台冷原霜灰 / 陨野骨白苍灰 / 菌原腐沼胆绿。

### 3.2 轴 B：文明改造等级 —— 方向、方法、可见效果三者都不同

| | **星球级 · 微痕** | **星系级 · 重铸** | **宇宙级 · 遗蜕** |
| --- | --- | --- | --- |
| **方向** | 顺应自然 | 覆盖自然 | 脱离母星 |
| **方法** | 场**一点不改**，只沿 `keyline` 放极稀疏标记 | 用**规则几何重写**场：把原型的阈值/边界改成规则刻度，工程落点由 `keyline` 决定 | 按 `keyid` 的场边界**切壳**，把场从球面剥离成结构 |
| **可见效果** | 完整自然球，几乎看不出改造 | 闭合球仍在，但被张扬的规则工程压过 | 球面不连续、地平线消失、露出空核，看不出是行星 |
| **原型场是否被改** | 否 | 是（被压暗、被几何覆盖） | 是（被剥离，仅以碎片纹样残留） |
| **文明位置** | 母星表面 | 母星表面 | 已脱离 |
| **动效** | 灯点轻闪 | 能量沿工程线流动、夜面光网 | 壳层差速、结构呼吸、核心脉动 |

**星系级的四种工程语法互不相同**（这是原型驱动的关键，不是通用贴网格）：

- 潮界 → 海岸拉直成规则**环形堤** + 放射状**运河**
- 层台 → 台地切成规则**梯田方格** + 垂直井
- 陨野 → 陨坑填成**同心矿坑阵列** + 辐条
- 菌原 → 细胞斑规整成**棋盘模块**，按 `keyid` 交替

**宇宙级的四种切壳形状互不相同**：潮界沿对数螺旋切螺旋带 / 层台沿量化台阶切水平层板 / 陨野沿坑环切同心壳环 / 菌原沿细胞边界切多边形块。碎片上都保留各自原型原有的地表纹样与特征色。

## 4. 四个世界示例（佐证有效性）

均为**同一 seed 4242、同一观察位置、同一半径、同一媒介**，只变 `tf_arch` 与 `terraform`。

### 世界一 · 灰湾（潮界）

- **原型**：深蓝海洋球，对数螺旋洋流与石缝清晰，海陆由阈值划分。
- **星球级**：一颗自洽的蓝色水世界，夜面沿海岸线有极稀疏暖灯，从太空看不出改造。
- **星系级**：海岸被拉直成规则环形堤、放射运河切开洋面，蓝色棋盘状工程覆盖整球——改造方向是**治水与岸线工程**。
- **宇宙级**：沿螺旋相位切成蓝白螺旋带壳片，中心亮核，碎片上还留着旧洋流纹。
- **为什么与别的不同**：它的场是「阈值 + 螺旋」，所以工程只能落在岸线与螺旋相位上；换成层台或陨野，同样三档会长出完全不同的东西。

### 世界二 · 石阶（层台）

- **原型**：白灰台地球，`floor(h*7)/7` 量化出一级级平顶，极冠雪线明显。
- **星球级**：干净的霜白台地世界，夜面沿台地边界有零星灯。
- **星系级**：台地被切成规则梯田方格与垂直井，斜向条纹状工程覆盖——改造方向是**开垦与分层采掘**。
- **宇宙级**：沿量化台阶切成水平层板，一层层错开，像被拆开的阶梯。
- **为什么与别的不同**：它的场是「高度量化」，所以改造天然沿水平层展开，与潮界的螺旋、陨野的圆环完全不同。

### 世界三 · 环野（陨野）

- **原型**：灰褐无大气陨坑球，双层解析坑与环脊，斑驳灰壤。
- **星球级**：满布坑环的干燥世界，灯点极少。
- **星系级**：坑被填成规则同心矿坑阵列与辐条，金色网格压过原来的随机坑分布——改造方向是**填坑与规则采矿**。
- **宇宙级**：沿坑环切成同心壳环，露出大块空洞，碎片边缘还带着坑的圆弧。
- **为什么与别的不同**：它的场是「解析圆」，所以工程与切壳都是极坐标的同心/放射，而不是方格或螺旋。

### 世界四 · 斑原（菌原）

- **原型**：荧光绿色菌落斑块球，Voronoi 细胞缝与脊线，随时间呼吸。
- **星球级**：斑块自然的绿世界，呼吸极缓。
- **星系级**：细胞斑被规整成棋盘模块，按细胞编号交替明暗，绿色工程从斑块边界长出来——改造方向是**驯化与规整生命斑块**。
- **宇宙级**：沿细胞边界切出水平条纹状多边形块，绿色纹样仍留在碎片上。
- **为什么与别的不同**：它的场是「细胞 hash」，工程与切壳都跟着细胞 id 走。

> 四个例子覆盖**至少 3 个**的要求。横向看同一行，四个世界结构不同；纵向看同一列，三档递进不同。

GODOT=/Applications/Godot.app/Contents/MacOS/Godot
BASE=docs/art/visual-generation/godot-base
# 4 原型 × 3 等级，同 seed
$GODOT --path "$BASE" -- --shots=/tmp/out \
  $(for lv in 0 1 2; do for a in 0 1 2 3; do

## 7. 已知弱点（不自行宣布通过）

- 星系级潮界与层台都呈网格感，工程语法的区分度还可以再拉开（潮界应更偏同心环、少些方格）。
- 宇宙级菌原的切壳呈水平条纹，与层台的层板略像；需让细胞边界在切壳里更主导。
- 星球级的灯点在当前光向下很弱，符合「几乎看不出」但需制作人确认度。
- 四个原型是本作工作原型，尚未覆盖原作 11 个的丰富度；`keyid` 目前只用于切壳与模块交替，未参与更多生成维度。
- 原型名与四个世界名都是工作名；色板推荐表仍是脚本里的临时数组，未进 `data/`。
- 未接 Session、未接公开投影、未动交互框架。
