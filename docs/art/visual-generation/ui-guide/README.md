# 图文美术规范的构建与来源

直接打开 [index.html](index.html)；无需服务器或网络。它是[唯一规范正文](../ui-art-standard.md)与 [manifest.json](manifest.json) 的派生阅览版，不另维护一份规则。阅读顺序与正文一致：每张图和动态只在所属条目出现一次；点击图片打开原尺寸，其来源、尺寸与不适用范围就近折叠，引用有效范围集中在文末附录。没有另设重复的画廊或控件墙。

当前包含四张获准场景图、完整 24 秒动态和十张图解／控件板。每张图标明用途、来源、规则编号、尺寸与不适用范围。三种状态分别是：获准母版、实际代码复现、衍生设计待审。文件名含 `approved` 只指画法来源，不能代替逐态审阅。

## 重建

在仓库根目录运行，Python 使用 Pillow 与 markdown-it-py：

```sh
python3 docs/art/visual-generation/ui-guide/build_guide.py
```

脚本先核对获准原图和动态的指纹，然后从它们生成注释图、固定范围抽帧和阅览版。只改规范正文或清单时使用 `--reader-only`；只重建文档图解时使用 `--figures-only`。原图不改写。

六张原生控件板由 `specimens.gd` 直接调用母版组件与字体。捕获命令、单图重建、真实按钮状态和宿主继承残留见 [README.capture.md](README.capture.md)。不依赖 ImageGen，不把 HTML/CSS 近似外观当作原生控件。

## 引用维护

`manifest.json` 为每份参考登记当前允许章节／用途、明确排除范围与核对指纹。文件存在或 hash 不变仅证明来源没丢失；是否仍有效须对照制作人后续裁决、现行合同与真实代码。

本轮已处理：交互 spec 中旧 F5 与“唯一视觉规范”的失效转引；现行合同与历史段分界；旧交互设计中已被替代的三世界构图／常驻品牌；字体 README 的旧点阵试验。旧 `echoes-ui` 仅用脚本统计文档结构，没有读入其具体视觉规则或旧图。后续发现新冲突时修引用范围，不靠自动改 hash 宣布有效。构建阅览版前会校验引用指纹；来源变化时停止构建，要求复查允许／排除范围，不自动刷新批准。

新图解与衍生控件不写入已批准基线。制作人接受新的视觉决定后，在唯一规范与决定记录中明确范围，再登记其证据；不要覆盖原获准截图。
