# 粗印画牌 · UI 美术与竖卡探索

当前：2026-11-12 制作人已要求提交高维注视精修，随后要求屏幕四周出现起伏浮动、暗中窥探与形体将要探出的感觉。本轮增加可运行的外围动态，沿现有灰绿粗绘材质，动态强度与氛围待制作人审阅。

## 当前入口

双击项目根目录 `UI视觉探索.command`。

- F1：3 个真实世界的竖卡，空间足够时平铺。
- F2：12 张排布样牌，当前卡完整露出，两侧收叠。
- F3：24 张排布样牌，继续翻动查看，不把所有卡缩到一屏。
- F4：同一潮汐世界的星球、教团、人物材质对照。
- F5：暂停／继续外围动态，便于观察形变与阅读感受。
- 左右拖动、滚轮、触控板横滚或左右键翻卡。点侧边卡将其带到前方；点当前完整世界卡／Enter 进入原有当地页面。拖动松手不执行进入。

12／24 张档仅重复已有插图验证排布，扩展卡明确写「排布样牌」，不创建 Session 世界，也不声称生成了更多新立绘。F4 是美术对照，不提交游戏行动。正式入口未替换。

## 对上一轮的诊断与本轮画法

原图共同语言是大色块塑形、方向性笔触、不均匀边缘、暗部省略和局部发光。上一轮的连续金线、精确双框、平滑底面和细宋体共同构成精装展示架，与原图分离。不是通过给旧框覆盖噪点来修正。

本轮改为暗墨颜料底、厚薄不匀的灰绿色卡边、低对比块面及短笔触。文字区压低纹理，让立绘的翠光、火光、冰光承担主要色彩。焦点使用露出、轻微抬起和少量不连续亮边。层叠后仅当前卡显示完整名称、状态及四维，侧卡保留插图和编号，避免指标碎片堆在一起。

字体拆分职责，均实际随项目打包：**Fusion Pixel 12px** 保留给游戏名、场景标题和卡名；**LXGW WenKai Screen** 用于正文、控件和数字。标题沿 24／36 逻辑字号与点阵渲染，正文主要为 14px、灰度抗锯齿和线性过滤；顶栏数值为 20px，窄按钮直写文字保留 12px。正文完整字形，不加随机缺墨。来源、OFL 许可与上游许可见 `type/README.md`。

背景以手定轮廓分成冷色远雾、较窄的灰绿中景雾带和底部近景暗幕；左侧阅读区与底栏保留安静暗场。纹理局限于雾带，不再满屏铺同尺度团纹。卡片减少长边磨损，保留角部干笔和局部亮边，收窄接触阴影；图窗柔化仅用于收边，避免读作磨砂玻璃。普通导航底色退后，责任入口居中，回合责任保留较完整的色块。

### 高维注视精修

背景与卡面共用 `occult_marks.gd` 的二维干笔眼形，颜色继承灰绿颜料，不另添金线、符文或辉光。背景只露出巨大眼形的一部分：逻辑中心 `(800,160)`、宽高 `760×250`，瞳孔大部分被卡片遮住，轮廓由低频雾块和断笔打散；两道来自画外的褶皱补充尺度。左侧阅读区与顶部资源区压低纹样。

卡片说明板保留很暗的同源眼形压纹和边缘褶皱，实际标题／正文行进一步降低纹样强度。卡头小印记使用既有聚焦／悬停状态，当前卡睁眼、邻卡收敛，不新增交互。共同意图是把卡片读成受玩家注意力支配的客体，立绘依然承担主要颜色与细节。

首稿完整悬空眼形被内部复看指出有「徽标／外部观察者」读法，因此放大、下移并增加雾中遮断。验收观察点：先读到立绘和信息，再发现注视；背景不出现完整发亮的脸或徽标；12／24 张收叠不产生亮纹栅栏；原插图像素与非世界控件的行为不变。表达是否足够明确仍由制作人判定。

具名参考锚点：[Inscryption](https://store.steampowered.com/app/1092790/Inscryption/) 用于卡片作为可操纵物件的读法；[DICEOMANCER](https://store.steampowered.com/app/2501600/DICEOMANCER/) 用于手绘卡面、控件与插图同属一种绘画的方向。只借鉴这些问题，不移植对方的相机、战斗布局、规则或资产。实际材质母本仍是本项目生成器。

### 外围动态

本轮选择缓慢潜伏、窥视的表达。四周暗膜通过二维 shader 的颜料场位移起伏，六处卷曲暗形用有厚薄的二维曲线带绘制，宽根藏在画外，末端逐渐淡出。曲线各自按 17–24 秒的周期伸展，末端落后于中段，局部约 12–18 逻辑像素的往复位移。顶底空档承载较深的弯折，两侧只露出窄边，四角文字和按钮附近抑制雾层。

第一轮卷曲形体只露出细线，复看后增加中段宽度与进入画面的深度，保持脊线暗度。运动观察点为形体确实伸入／蜷回、各边节奏错开、中央立绘与正文保持稳定、四角控件清楚。程序只绘制外围透明层，依原舞台生命周期创建和释放，鼠标穿透。噪声纹理启动时生成并缓存，动态使用统一时钟，支持暂停和定时截帧。

`evidence/peripheral-motion.webp` 为 12 秒、12 fps、1280×720 的实际运行采样，循环回放会从结尾跳回开头；现场动画持续演算。通过 `--mode=2 --capture-motion=/绝对目录` 可导出 144 张 PNG，常规 `--capture` 固定在第 4 秒，方便比较材质。F5 是独立美术入口的预览工具。

## 范围与授权

本轮新增交互仅限制作人点名的世界卡承载方式：由少量固定横向主次块改为竖卡平铺／层叠／左右翻动。其余资源、责任、导航按钮位置和既有回调保留。正式玩法、世界投影、费用、保存、生成器和正式默认场景代码均不修改。

样板仍实例化 `src/presentation/production/game_root.tscn`，使用现成 `docs/qa/ui-manifest/saves/ongoing.json` 的独立副本。世界进入回到原 `_inspect_world` 路径。新材质与竖卡仅在独立入口覆盖「诸界态势」，当地及其他页面不在本轮美术范围内。

1280×720 逻辑画布，1920×1080 展示。卡尺寸为 260×390；容器按可用宽度判断能否平铺，放不下时焦点卡完整露出，最多显示左右各五张邻卡，其他卡仍可继续翻到。

## 有限验证与证据

`evidence/01-three-worlds.png`、`02-twelve-worlds.png`、`03-twenty-four-worlds.png`、`04-shared-world-art.png` 为正式 Godot 场景实际截图。`painted-evidence.json` 记录排布与非世界按钮对照。

本轮按字体、材质变化复看实际截图：正文完整笔形、卡底文字留白、图窗过渡、背景层次与原入口几何。更换字体暴露的顶栏两位数字裁切已修正；capture 同时检查数值文本的实际字宽不超过可用宽度，`resource_text_fits` 为 true。原非世界按钮位置、可见性与连接保持不变。

注视精修后重新捕获上述四种画面，复看三类立绘、冷暖世界及密集叠卡中的纹样强度；`resource_text_fits` 与非世界按钮对照仍通过。仅增加缓存的程序绘制材质，没有重新生成原立绘。

外围动态完成后更新四张定时截图，数值宽度与非世界按钮对照继续通过。导出的 WebP 已核对为 144 帧，复看 0／4／10 秒形变及三类立绘静帧，运动维持在外围。当前美术风险是连续四边仍稍有框饰读法，缓慢潜伏的强度较克制，需由制作人观看动态后判断。未扩展游戏功能回归。

翻卡实现未修改，复用上一轮容器的单次图形输入证据：键盘、滚轮、侧卡聚焦、当前卡进入、拖动松手不误入及首尾范围。没有重跑全游戏或扩展功能回归。触控板硬件手感与最终美术品质留待制作人亲自体验。`before-refinement.png` 保留精修前画面供比较。
