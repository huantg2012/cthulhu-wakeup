## 对上一轮的诊断与本轮画法

原图共同语言是大色块塑形、方向性笔触、不均匀边缘、暗部省略和局部发光。上一轮的连续金线、精确双框、平滑底面和细宋体共同构成精装展示架，与原图分离。不是通过给旧框覆盖噪点来修正。

本轮改为暗墨颜料底、厚薄不匀的灰绿色卡边、低对比块面及短笔触。文字区压低纹理，让立绘的翠光、火光、冰光承担主要色彩。焦点使用露出、轻微抬起和少量不连续亮边。层叠后仅当前卡显示完整名称、状态及四维，侧卡保留插图和编号，避免指标碎片堆在一起。

字体拆分职责，均实际随项目打包：**Fusion Pixel 12px** 保留给场景标题和卡名；**LXGW WenKai Screen** 用于正文、控件和数字。标题沿 24／36 逻辑字号与点阵渲染，正文主要为 14px、灰度抗锯齿和线性过滤；顶栏数值为 20px，窄按钮直写文字保留 12px。正文完整字形，不加随机缺墨。来源、OFL 许可与上游许可见 `type/README.md`。

背景以手定轮廓分成冷色远雾、较窄的灰绿中景雾带和底部近景暗幕；左侧阅读区与底栏保留安静暗场。纹理局限于雾带，不再满屏铺同尺度团纹。卡片减少长边磨损，保留角部干笔和局部亮边，收窄接触阴影；图窗柔化仅用于收边，避免读作磨砂玻璃。普通导航底色退后，责任入口居中，回合责任保留较完整的色块。

### 高维注视精修

背景与卡面共用 `occult_marks.gd` 的二维干笔眼形，颜色继承灰绿颜料，不另添金线、符文或辉光。背景只露出巨大眼形的一部分：逻辑中心 `(800,160)`、宽高 `760×250`，瞳孔大部分被卡片遮住，轮廓由低频雾块和断笔打散；两道来自画外的褶皱补充尺度。左侧阅读区与顶部资源区压低纹样。

卡片说明板保留很暗的同源眼形压纹和边缘褶皱，实际标题／正文行进一步降低纹样强度。卡头小印记使用既有聚焦／悬停状态，当前卡睁眼、邻卡收敛，不新增交互。共同意图是把卡片读成受玩家注意力支配的客体，立绘依然承担主要颜色与细节。

首稿完整悬空眼形被内部复看指出有「徽标／外部观察者」读法，因此放大、下移并增加雾中遮断。验收观察点：先读到立绘和信息，再发现注视；背景不出现完整发亮的脸或徽标；12／24 张收叠不产生亮纹栅栏；原插图像素与非世界控件的行为不变。本版表达已随整合母版获制作人通过；其他场景仍按接入规范复看。

具名参考锚点：[Inscryption](https://store.steampowered.com/app/1092790/Inscryption/) 用于卡片作为可操纵物件的读法；[DICEOMANCER](https://store.steampowered.com/app/2501600/DICEOMANCER/) 用于手绘卡面、控件与插图同属一种绘画的方向。只借鉴这些问题，不移植对方的相机、战斗布局、规则或资产。实际材质母本仍是本项目生成器。

### 外围动态

外围由三个实际深度层组成。后层是大雾团和起伏暗膜，中层是从膜边延伸出的六处卷曲形体，前层是覆盖整个外围的稀薄流雾。雾穿过根部与空隙，也同时遮住皮膜和眼形。三层共用灰绿颜料场、雾场与 24 秒时钟，四角阅读区压低效果。

五只异形眼睛均由承载表面定位。三只眼睛直接画在固定三角带的 UV 中，位于顶部、底部和左侧卷形的宽面，随曲面平移、旋转、弯曲。另两只眼睛绑定顶部及右侧暗膜的同一边界函数，眼心高度、倾斜和纵向尺度随膜面起伏。眼睛采用三裂瞳核、偏心小孔和不规则虹膜，前景雾连续遮蔽其所在的整个表面。

外围材质统一在 `peripheral_fields.gdshaderinc`，后层、卷形表面与前雾分别由三个 shader 绘制。卷形使用缓存 UV／索引的固定三角带，避免动态重新三角化造成贴图跳变。噪声启动时生成并缓存，各层鼠标穿透。所有时间分量为 24 秒周期的整数谐波，位置与速度首尾连续，F5 可暂停／继续观察。

游戏内顶栏已按制作人明确指示移除常驻游戏名，轮次和阶段信息左移至原游戏名的位置。此项直接更新正式 `round_view.gd` 的顶栏构建及交互 spec，独立样板同步呈现。

`evidence/peripheral-motion.mp4` 与 `peripheral-motion.webp` 为 24 秒、60 fps、1280×720 的完整周期采样。通过 `--mode=2 --capture-motion=/绝对目录` 导出 1440 帧及一张周期端点，再运行 `python3 docs/art/visual-generation/ui-study/encode_motion.py /绝对目录 --ffmpeg /ffmpeg路径` 编码。编码器先检查起止端点逐像素相同，再排除重复端点。WebP 使用无损编码并检查每帧为 16／17 ms，避免压缩合并帧造成停顿。常规 `--capture` 固定在第 4 秒。

平滑性修复沿用上一轮发现：旧 12 秒回放硬切造成暗膜跳回，动态多边形重新三角化造成触手贴图突变，有损 WebP 曾合并细微变化。当前使用固定曲面坐标和共同雾层，验收关注眼睛跟随载体、前后遮挡以及完整周期端点。本版浓雾、异形眼与氛围整合已获制作人通过；派生场景的阅读保护和运行接入仍须逐批核对。

## 范围与授权

本轮新增交互仅限制作人点名的世界卡承载方式：由少量固定横向主次块改为竖卡平铺／层叠／左右翻动。其余资源、责任、导航按钮位置和既有回调保留。本轮正式代码包含制作人点名的顶栏标题移除与轮次左移。外围材质与世界卡继续由独立探索入口加载。

样板仍实例化 `src/presentation/production/game_root.tscn`，使用现成 `docs/qa/ui-manifest/saves/ongoing.json` 的独立副本。世界进入回到原 `_inspect_world` 路径。新材质与竖卡仅在独立入口覆盖「诸界态势」，当地及其他页面不在本轮美术范围内。

1280×720 逻辑画布，1920×1080 展示。卡尺寸为 260×390；容器按可用宽度判断能否平铺，放不下时焦点卡完整露出，最多显示左右各五张邻卡，其他卡仍可继续翻到。

## 有限验证与证据

`evidence/01-three-worlds.png`、`02-twelve-worlds.png`、`03-twenty-four-worlds.png`、`04-shared-world-art.png` 为正式 Godot 场景实际截图。`painted-evidence.json` 记录排布与非世界按钮对照。

本轮按字体、材质变化复看实际截图：正文完整笔形、卡底文字留白、图窗过渡、背景层次与原入口几何。更换字体暴露的顶栏两位数字裁切已修正；capture 同时检查数值文本的实际字宽不超过可用宽度，`resource_text_fits` 为 true。原非世界按钮位置、可见性与连接保持不变。

注视精修后重新捕获上述四种画面，复看三类立绘、冷暖世界及密集叠卡中的纹样强度；`resource_text_fits` 与非世界按钮对照仍通过。仅增加缓存的程序绘制材质，没有重新生成原立绘。

整合方案更新四张定时截图，数值宽度与非世界按钮对照通过。复看标题移除、轮次位置、眼形依附及前雾遮挡。三只卷形眼的曲面定位抽查保持同一 UV 与三角索引，眼心在周期内随载体移动约 9–13 像素，24 秒时回到起点。完整导出 1440 帧、60 fps、24 秒；起止采样逐像素一致，WebP 每帧 16／17 ms 的时长检查通过。

翻卡实现未修改，复用上一轮容器的单次图形输入证据：键盘、滚轮、侧卡聚焦、当前卡进入、拖动松手不误入及首尾范围。没有重跑全游戏或扩展功能回归。母版美术已获制作人通过；触控板硬件细节不因本次美术 PASS 自动成为专项验证通过。`before-refinement.png` 保留精修前画面供比较。
