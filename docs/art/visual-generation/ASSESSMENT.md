# 《旧日星图 · Eldritch Starchart》客观评价

> 配套文件：`REVIEW.md`（技术与美术调查正文）。本文只做**判断**，不重复调查过程。
> 所有图像数字均由 `analysis/img/` 的实拍图测得；测量口径与可复核数据见 §1。

---

## 0. 评价基准与证据等级

「好不好」必须先说清**以什么用途评判**。三个基准下结论完全不同，混在一起谈必然失真：

| 基准 | 含义 | 结论 |
| --- | --- | --- |
| **A. 单页概念图 / 风格探索工具** | 人调参数、出 PNG、做气氛板与风格对比 | **优秀**。架构与目的高度契合 |
| **B. 游戏运行时资产管线** | 每帧实时渲染、多个物体、可混用、可维护 | **不合格**。预算模型与渲染模型都不适配 |
| **C. 可复用的美术方法论** | 把「画笔」抽象迁到别的项目 | **优秀，但必须重实现**。可搬的是算子库与 `Surf` 契约，不是运行时代码 |

**证据等级**（下文每条标注）：

- **[A]** 实拍图 + 图像统计 + 代码行号，可复核
- **[B]** 静态代码推算，**未做运行时 profiling**，只给量级不给帧率
- **[C]** 审美 / 设计判断，主观，供讨论

**测量口径**：截图均为 940×520 的导出图版。全图统计裁 `(24,24)-(916,430)` 避开边框、刊头、左下标题卡；主体统计裁 `(300,60)-(640,380)` 只取中央星球。`dark = 灰度<0.10 的像素占比`，`bright = 灰度>0.85 占比`，`edge = 相邻像素灰度差均值 / 255`（**高频能量，同时包含真实边缘、媒介网点与噪声，不等于信息量**），`cx/cy` 为亮度加权重心（缩至 64×32 后按 `(v-56)*2` 加权）。全部 8 张风格图使用同一分辨率原图，横向可比。

## 2. 一处需要修正的预设（客观性的自我校验）

调查阶段的直觉判断是：**「铜版画 / 水彩把发光压掉后，主体会变空，说明内容层靠发光救场」**。

实测**不支持**这个说法：style-2 主体 `edge` 从 0.0205 升到 **0.0502**（2.4×），`std` 从 0.174 升到 0.347 —— 交叉排线**增加**了局部结构，不是抹掉。

因此修正为更准确的判断：

> 风格切换不是「换质感」，而是**重排视觉层级**。style-0 的焦点是「极暗底上的亮裂纹」（主体 dark 63.6%）；style-2 把主体提到中灰（dark 0%，mean 0.348），焦点变成「圆形剪影与纸白的黑白关系」；style-5 把主体整体点亮（mean 0.433），原先的发光语义彻底消失。**形体一致 ≠ 焦点一致。**

真正内部信息最弱的不是铜版，而是 **style-1（std 0.084，主体 83.9% 近黑）与 style-3（edge 0.0156，8 者最低）**。

## 3. 技术评价

### 3.1 得分项

| # | 判断 | 依据 | 等级 |
| --- | --- | --- | --- |
| T+1 | **分层与职责边界清晰**：`data.gd`（静态表）/ `generator.gd`（纯 `RefCounted`，无 `_process`）/ `main.gd`（渲染图与 UI）/ `overlay.gd`（排版）互不侵入；`build()` 每次清空重建，无隐藏状态 | 代码结构；`generator.gd:1-2, 111-147` | A |
| T+2 | **确定性设计是产品级的**：`sub(k)` 用特征编号做种子盐，调一个滑块不重排整张构图；`seed_vec()` 给每个材质独立噪声相位；URL seed；批跑固定 `time_acc=3.0` + 等 4 帧 | `generator.gd:33-35`、`main.gd:110,122-132`、`shots.gd:15-16` | A |
| T+3 | **三层参数化是真架构决策，不是堆功能**：编译期 `#define ARCH`（结构差异）/ 逐实例 uniform（外观差异）/ 独立随机流（构图差异） | `main.gd:75-79`、`generator.gd:181-213` | A |
| T+4 | **兼容性取舍有明确收益**：放弃 screen texture / BackBufferCopy，换 WebGL2 可移植 + **导出 PNG 天然含后期与装帧** | `main.gd:138-225`；全局 0 匹配 | A |
| T+5 | **资产极轻**：1.3 MB GLB（13 网格、0 材质、0 贴图）+ 2.3 MB pck，覆盖 11×10×8×3×6×5 组合空间 | 文件实测；`build_assets.py:322-329` | A |

### 3.2 失分项

| # | 判断 | 依据 | 等级 |
| --- | --- | --- | --- |
| T−1 | **预算模型是「一张静态图」，不是游戏帧**。4 个 SubViewport 全部 `UPDATE_ALWAYS`；默认 style=0 的 Kuwahara 在**全分辨率 64 次采样/像素**（1280×720 约 5900 万次/帧）；bloom 在 1/4 分辨率再 130 次；3D 侧每个像素要跑多次 `fbm3(6 oct)`=48 次 hash 与 `voronoi3c`=27 次邻域 hash。漂亮来自「不计成本的每像素求值」 | `post.gdshader:61-83`、`bloom_blur.gdshader:6-24`、`noise.gdshaderinc`；**静态推算，未 profiling** | B |
| T−2 | **风格是全屏后期，不是物体材质**。8 种里多数靠 `post.gdshader` 单 pass，无法只对某个物体施风格；Sobel 是全屏边缘检测而非物体轮廓，实测 style-1 全图 `edge`(0.0179) 高于 style-0(0.0168) 而主体 `std` 只有 0.084 —— **描线描到了背景噪点，主体反而更平** | 代码 + §1.1/1.2 数据 | A |
| T−3 | **`g_style` 是高耦合全局变量**：13 个文件、32 处分支。加第 9 种风格至少要同步 3D 明暗、各 spatial shader 特化、后期分支、CPU 边框、`data.gd` 权重五处以上；漏一处风格就「不纯」 | grep 实测 + `overlay.gd:86-181` | A |
| T−4 | **泛化性弱**：环阴影是针对「一个行星 + 一个环」的硬编码射线求交特例（`planet_body.gdshaderinc:518-531`）；解析光照无物体间阴影、无 GI、无多次散射，对需要物体相互关系的场景不够 | 代码 | A |
| T−5 | **可维护性隐患**：`planet_body.gdshaderinc` 559 行塞进 11 个原型 + 眼 + 符文 + 腐化 + 光照，靠 `#if` 裁剪；uniform 全靠字符串 key，无 schema、无类型检查；`mat(key)` 字符串索引，拼错运行时才炸；`_ready()` 同步编译 11 个 WebGL program 阻塞 Web 首屏；魔法数（`0.1031 / 31.32 / 2.03 / 1.7,9.2,3.1`）无推导 | `main.gd:75-79`、`generator.gd:65-68,181-213` | A |
| T−6 | **确定性有边界**：桌面端 `main.gd:133-134` 随机覆盖 seed，Web 端不覆盖 —— 同一命令两端结果不同；`g_time` 让 PNG 随帧变化（仅批跑靠固定 3.0 绕过） | 代码 | A |
| T−7 | **零测试、零 shader 编译检查、零回归基线**。对 11×10×8×3×6×5 的组合空间，仅有手动 `--shots` 与 `_style_sheet()` 目视对比；且 `README.md:11` 的批跑示例与 `main.gd:101-107` 语义不符（每个 `--cfg=` 只出 1 张图） | 代码 + 文档 | A |
| T−8 | 死代码 / 配置噪声：`main.gd:38` 的 `bloom_a_rect: ColorRect` 从未赋值；`build_assets.py:37-50` 的 `set_corner_colors()` 从未调用；GLB 导入开着 `generate_lods / create_shadow_meshes / light_baking` 但项目 0 光源；`_collect_meshes` 按节点名取 mesh 与 `use_name_suffixes=true` 形成隐式契约 | 代码 | A |

### 3.3 技术定级

> **工具级作品，非生产级渲染管线。** 在基准 A 下它几乎没有多余设计；在基准 B 下，T−1/T−2/T−5 是结构性的，无法通过调参修补，需要重新设计渲染模型（物体材质化风格、LOD/缓存、profiling 门槛、参数 schema）。把它称为「可复用的游戏美术管线」是过高评价；准确说法是「一套优秀的离线生成工具 + 一份可借鉴的算子清单」。

## 4. 美术评价

### 4.1 得分项

| # | 判断 | 依据 | 等级 |
| --- | --- | --- | --- |
| A+1 | **题材与媒介高度自洽**：宇宙恐怖 × 古董印刷 × 伪档案装帧。说服力强且不靠堆细节，靠的是「媒介一致性」——`g_style` 一个整数贯穿 3D 明暗、后期滤镜、边框、字体描边、bloom 权重 | 实拍 8 张 + 代码 | A |
| A+2 | **「8 风格 = 8 种承印物」是正确且经济的框架**：实测 8 张的 `cx` 全部落在 0.45~0.50、`cy` 0.40~0.57，构图确实完全一致；`mean` 从 0.084 到 0.732 说明媒介转换是彻底反转而非调色。一次造型投入，八次媒介产出 | §1.1 数据 + `grid-styles.png` | A |
| A+3 | **色板结构稳定**：`c0..c3` 走 `ramp4()`，`c4` 独立进 `emit`，底色与发光在数据结构上就分离；10 套色板没有明显废板 | `planet_body.gdshaderinc:59-65`、`data.gd:68-89` | A |
| A+4 | **装帧层性价比高**：约 320 行 CPU `_draw()` 提供了 `PLATE VIII`、`Fig. I.`、`25¢`、RA/DEC、色卡、准星、抖动边框，把渲染图抬成「游戏世界里的物件」。这一步成本远低于再画一层 3D 细节 | `overlay.gd:67-319` + 实拍 | A |
| A+5 | **动效克制**：差分热力图显示 2.6 秒内变化集中在环符文滚动、裂纹脉动、触手摆动三处局部区域，其余画面近乎静止。低频、局部、无叙事，适合放进 HUD 而不制造噪音 | `img/anim-diff.png` | A |

### 4.2 失分项

| # | 判断 | 依据 | 等级 |
| --- | --- | --- | --- |
| A−1 | **风格切换重排视觉层级，「跨媒介复用」要打折扣**。主体 `mean` 从 0.059（赛璐璐）到 0.433（全息），`dark` 从 83.9% 到 0%。以「发光裂纹」为焦点的设计，在减色 / 单色媒介里焦点变成剪影或网格。**对需要在卡牌、图鉴、UI 里保持识别度的游戏资产，这是实质风险** | §1.2 + 实拍 `style-0/2/5/6` | A |
| A−2 | **8 种风格完成度不等价**：style-1 主体 `std` 0.084（最低）、83.9% 近黑，硬分层把中间调砍光，同时全屏 Sobel 把噪点描出来；style-3「低多边形」名不副实——`lowpoly` 只改变 `p` 的取法（`normalize(v_face)`），**`Surf` 配方完全不变**，实测主体 `edge` 0.0156 为 8 者最低，看不出块面感；style-5 全息渗透最深、最统一 | §1.2 + `planet_body.gdshaderinc:434`、`generator.gd:199-201` | A |
| A−3 | **部分「细节感」来自印刷噪声而非造型**：style-7 全图 `edge` 0.1312 是 style-0 的 7.8 倍，主体区 0.0913 是 4.5 倍，主要来自 CMYK 四角网点；style-4 的像素抖动同理 | §1.1/1.2 + `post.gdshader:207-225` | A |
| A−4 | **暗部几乎无信息，视觉冲击依赖极少数发光像素**：style-0/1/3/4 有 58~74% 像素 `luma<0.10`，`bright>0.85` 仅 0~0.2%。4 个 seed 的 `bright` 也都 ≤4.2%。一旦 bloom 被关或 `emit` 被压（`g_style==6` 时 `em_scale=0.55`），画面靠纸白或轮廓撑，内容层独立强度不足 | §1.1/1.3 + `planet_body.gdshaderinc:550` | A |
| A−5 | **构图同质化，参数空间大但视觉熵小**。4 个 seed 里 3 个主体重心聚在 `cx 0.35~0.40 / cy 0.45~0.51`，只有 seed-777（巨构地平线，`cy=0.80`）真正跳出。11 个原型换的主要是**表面纹理**而非形体语言；6 种构图里多数随机结果仍是「一个球 + 一圈环 + 几颗卫星 + 左下标题卡」 | §1.3 + 实拍 4 张 | A |
| A−6 | **缺少尺度锚点**。无人物、建筑、飞船等参照，seed-777 的「巨构地平线」读起来更像「一个球的下半部分」而非「站在星球表面」。这是纯天体题材的固有局限 | 实拍 | C |
| A−7 | **「眼睛」母题密度过高，语义稀释**。4 个 shader / 34 处，加上眼之星、星云巨眼、裂隙群眼、奇景宇宙之眼、传送门之眼，至少 6 类对象能长眼；单张图常同时出现 2~3 组（如 `seed-42`）。恐怖感本应来自「不该有眼的地方有眼」，重复后更像装饰纹样 | grep 计数 + 实拍 | C（审美判断） |
| A−8 | **媒介拟态没贯彻到排版层**：铜版 / 水彩风格下物体有纸纹、排线、套印噪声，而 `PLATE VIII`、`Fig. I.` 是干净矢量字，真实古董图版的文字同样会有墨色不均与错位。这正是它最强卖点上的一处不一致 | `style-2.png` / `style-6.png` 实拍对比 `overlay.gd:28-34` | C |
| A−9 | **动效的美术价值有限**：低频局部变化让画面「活着」，但不产生节奏或叙事；`g_time` 全局同族相位（各 shader 加 hash 偏移），缺事件级编排。作为氛围合格，作为「动态立绘」卖点略被高估 | `anim-diff.png` + `main.gd:317-320` | C |
| A−10 | **副文本不自洽**：观测数据（自转周期、表面重力、温度）为随机数字，不同原型之间无物理一致性。概念图无妨，若当游戏内档案直接使用会露馅 | `lore.gd` / `generator.gd:410-430` + 实拍右栏 | A |

### 4.3 美术定级

> **强在「媒介与装帧的统一性」，弱在「造型与构图的多样性」，内容层偏依赖发光与后期。**
> 它是一套优秀的**风格 / 质感研究工具与气氛板生成器**，不是能支撑完整游戏视觉的资产体系（缺角色、缺场景、缺尺度、缺叙事）。A−1 与 A−4 相互关联：视觉冲击主要由「高对比发光 + 印刷质感」两种手段提供，当手段被风格转换削弱时，内容层的薄弱就暴露出来。

| 动效 | **中**（克制但价值有限） | A + C |

**三句话总结**：

1. 作为**工具**，它完成度高、几乎没有多余设计，可以直接用。
2. 作为**游戏运行时管线**，它的预算模型、全屏后期依赖与工程底座都不合格，不能搬代码，只能搬方法论。
3. 作为**美术**，它的价值在「一套内容换八种媒介」的框架与装帧意识，代价是构图同质、内容层依赖发光、跨风格焦点不一致。

## 6. 若目标是把能力迁进游戏，改进优先级

| 优先级 | 动作 | 解决的失分项 |
| --- | --- | --- |
| **P0** | 把「风格」从全屏 pass 改成**物体材质级 + 可分层合成**（至少支持「哪些物体用哪种媒介」），并给描线换成物体轮廓/深度来源而非全屏 Sobel | T−2、A−1、A−2 |
| **P0** | 强化内容层：给 `Surf` 增加独立于 `emit` 的**结构遮罩通道**，让主体在减色 / 单色媒介下仍保有层级；降低对 bloom 的依赖 | A−1、A−4 |
| **P1** | 补工程底座：shader 编译校验、uniform schema 与类型检查、组合回归基线（固定 seed + 固定 `time_acc` 的像素比对）、运行时 profiling 门槛 | T−5、T−7、T−1 |
| **P1** | 扩充构图自由度：把「主体尺度 / 偏位 / 前景遮挡 / 尺度锚点」提升为独立参数族，而不是让 11 个原型只换表面纹理 | A−5、A−6 |
| **P2** | 统一媒介到排版层（文字也吃纸纹 / 套印）、收敛眼睛母题密度、给副文本加物理自洽约束 | A−7、A−8、A−10 |
