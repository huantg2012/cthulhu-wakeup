## 1. 背景依据：文明到底能对行星做什么

之前的问题不是美术，是**没有工程能力的概念**——把「改造」理解成「在球面上贴更强的图案」。按天体工程与科幻里通行的能力阶梯，改造深度的本质是**能移动多少质量**：

| 能力层 | 可调用的工程 | 物证（从太空看得见什么） |
| --- | --- | --- |
| **行星表面文明**（卡尔达肖夫 I 型以下，如人类） | 城市、取水、露天开采、夜间照明；只动地表薄层 | 几乎看不见；只有夜面稀疏灯点。**行星整体形状、反照率、轨道都没变** |
| **恒星级工程文明**（I → II 型之间） | 地壳剥离、大陆级开挖、全球峡谷、极冠移除／融化、地幔暴露、轨道环与同步构造、质量驱动器 | **球体被物理切开或剥掉大块**，露出内层（熔岩／层理／海底／生物质），轮廓出现不规则缺口 |
| **恒星系级／超工程文明**（II 型以上） | 行星拆解（planetary disassembly）、戴森云、环世界、壳世界、轨道环阵列；行星不再是容器而是**原料** | **球体不存在了**：没有闭合球面、没有地平线，只剩构件与空核，文明已不在这里 |

借用的概念锚点（均为通行的科幻／天体工程概念，此处只作设计分级，不做数值断言）：卡尔达肖夫尺度、戴森球／戴森云、环世界、壳世界、轨道环、质量驱动器、行星拆解、地壳剥离。

> **关键认知**：星系级要看见「球被切开、内层暴露」，不是「球上多了网格」；宇宙级要看见「球没了」，不是「球上少了些碎片」。

## 2. 本轮修掉的五件事

| 制作人指出 | 之前 | 现在 |
| --- | --- | --- |
| 星系级太单一、太轻太规整 | 四种原型都在球面上铺规则网格／刻线 | 四种**破坏性大开挖**：vertex 把剥离区径向压陷 13% 造成真实缺口，fragment 露出各自的内层，断面由低频噪声调制、不规整 |
| 宇宙级不够、甚至不如上一版 | 只 `discard` 掉约四成壳片，仍有球形轮廓 | **不再放置完整球体**：按原型几何语言把质量重排成 20 个独立构件（螺旋壳片／水平层板／轨道环阵／戴森云散件）+ 空核 |
| 缺少天体工程背景 | 三档是「同一套几何语言的开关」 | 三档对应**三种本质不同的工程能力**（薄层改造／地壳剥离／整体拆解），见 §1 |
| 世界间改造方式差异不够 | 同一套网格换颜色、换切壳角度 | 开挖位置由各原型自己的场决定，露出的内层材料各不相同；拆解形态按原型几何语言分四种 |
| **盈亏** | `day = smoothstep(...)` 造成昼夜半球、一半球暗掉 | **全域均匀照明** `alb*(0.94+0.06*ndl)`，只保留极轻的方向渐变与菲涅尔边缘；无相位感、无昼夜分界 |

> 「盈亏」按昼夜半球明暗二分（terminator）理解并移除。若制作人指的是别的（例如宇宙级中央那个空核），说一句即可改。

## 3. 三档新设定：方向 / 方法 / 可见效果

| | **星球级 · 微痕** | **星系级 · 破坏性开挖** | **宇宙级 · 整体拆解** |
| --- | --- | --- | --- |
| **方向** | 顺应自然 | 覆盖并破坏自然 | 脱离母星、把行星当原料 |
| **方法** | 场一点不改，只沿 `keyline` 放极稀疏标记 | 按原型的场决定剥离位置；vertex 径向压陷形成真实缺口，fragment 露出内层、断面发光、大陆级裂谷 | 完全不放球体，改为独立构件装配；构件保留原型纹样 + 断面层理 + 结构边缘光 |
| **可见效果** | 完整自然球，全域均匀照明，几乎看不出改造 | 球体仍在但被大块剥开，内层暴露，轮廓不规则 | 无球面、无地平线，只有构件与空核，看不出曾是行星 |
| **改的是几何还是贴图** | 都不改 | **改几何 + 改材质** | **改拓扑**：物体本身换了 |
| **文明位置** | 母星表面 | 母星表面 | 已脱离 |
| **动效** | 灯点轻闪 | 断面熔光／裂谷流动 | 构件呼吸、结构边缘光 |

## 4. 按原型的工程差异（本轮核心）

四个原型各有一份结构性不同的场配方（沿用原作 `Surf` 契约原理，详见 `ARCHETYPE-MATRIX.md` §1）。**改造以这份场为材料**，所以四种开挖与四种拆解互不相同：

| 原型 | 场配方 | **星系级开挖方式与露出的内层** | **宇宙级拆解形态** |
| --- | --- | --- | --- |
| **潮界 · 灰湾** | 域扭曲 fbm + 海平面阈值 + 对数螺旋洋流 + Voronoi 石缝 | 沿螺旋洋流带**抽干海水、剥去水层**，露出盐渍海底盆地；断面是蓝白壳层 | 沿螺旋臂排开的扁平壳片（水被抽成轨道带） |
| **层台 · 石阶** | `floor(h*7)/7` 高度量化台地 + 雪线 + 脊线裂纹 | 沿量化台阶**整层剥离地壳**，露出橙红地幔层理与熔光 | 水平层板堆叠（壳世界式分层） |
| **陨野 · 环野** | 双层解析陨坑 + 环脊 | 沿坑环**挖穿地壳成巨型竖井**，暗井 + 断面熔光 | 立起来的轨道环阵（坑环被拉成环构件）+ 空核 |
| **菌原 · 斑原** | Voronoi 细胞斑 + 血管脊线 + 余弦调色板 | 沿细胞边界把地壳**整块掀起翻开**，露出荧光生物质内层 | 细胞散件／戴森云式散布的扁平壳片 |

`excavation(p,q)` 在 vertex 与 fragment 共用，保证「哪里被挖掉」和「哪里露出内层」完全对齐；边界由 `fbm3(q*6,4)` 调制，所以是大陆级不规则断面，不是等间距图案。

## 5. 四个世界示例（同 seed 4242，逐张核对）

- **灰湾（潮界）**：蓝色螺旋水世界 → 沿螺旋带剥出蓝白海底与锯齿壳层，球体缺了大块 → 螺旋臂上的蓝色扁平壳片，中心空核，球面彻底消失。
- **石阶（层台）**：霜白台地球 → 水平层状剥离，橙红地幔层理横贯球面 → 六片水平层板悬空堆叠。
- **环野（陨野）**：灰褐陨坑球 → 坑环被挖穿成黑洞竖井 + 熔光边缘 → 一圈立起的轨道环构件，中央只剩空核。
- **斑原（菌原）**：荧光绿菌落斑块球 → 沿细胞缝翻开地壳，露出绿色生物质内层 → 绿色扁平壳片散布成云。

横向看同一行，四个世界结构不同；纵向看同一列，三档递进不同。

```bash
  --cfg=terraform:0,tf_arch:0,scene:0,style:0,seed:4242,palette:7,nebula:0.6 \

  --cfg=terraform:2,tf_arch:0,scene:0,style:0,seed:4242,palette:7,nebula:0.6 \
  # …其余三个原型同理
```

- `godot-baseline/matrix/`：12 张；`godot-baseline/matrix-grid.png`：4 原型 × 3 等级对照。

- 量化（64×36 低频灰度差）：同世界跨等级 8.34 / 同等级跨世界 13.67。**该指标对原型配色敏感、对「球变构件」这类形态变化不敏感**，只作参考；等级差异应看球面完整度与有无球形轮廓，逐张看图是清楚的。

## 8. 已知弱点（不自行宣布通过）

- 星系级潮界的剥离边缘仍有偏规整的「梳齿」状断面，需再打散。
- 宇宙级层台的层板仍偏亮，层理细节不够；陨野环阵的构件略密，读起来偏实心圆环。
- 全域均匀照明后球面立体感变弱（这是移除盈亏的代价），需要靠地形明暗与结构线补回，不能靠昼夜半球。
- 宇宙级构件只有 20 个，离「戴森云」应有的密度还差很远；受 WebGL 兼容与出图时间约束，暂未铺到数百级。
- 四个原型、世界名、色板推荐表仍是探索期工作值；未接 Session、未接公开投影、未动交互框架。
