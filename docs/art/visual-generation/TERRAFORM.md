# 母星改造层级 · 设定与描述（已被取代）

> **当前设定正文见 `ENGINEERING-TIERS.md`。** 本文的三档描述里，星系级仍是「规则刻痕／网格」、宇宙级仍是「破碎球壳」，均已被更彻底的破坏性开挖与整体拆解取代；本文保留作过程留痕。
>
> 2026-11-09。制作人设定：**世界层级 = 这颗母星被文明改造到什么程度**。
> 观察点固定：同一颗母星、同一个太空视角、同一个画面半径。三档之间不换镜头、不换场景、不换主体。

工作副标题「微痕 / 重铸 / 遗蜕」是探索期工作名，正式命名待定。三个正式层级名固定为：**星球级 / 星系级 / 宇宙级**。

---

## 0. 命题

原作把层级当成**镜头尺度**（星球立绘 / 星系图 / 星际奇景）。本设定把层级当成**同一物体被改造的程度**：

> 文明越往外走，母星越不像一颗行星。

所以递进不是「球 → 更多球 → 最多球」，也不是「近景 → 中景 → 远景」，而是**行星可读性的逐步丧失**：先还能看出是一颗自然的球，然后看出这颗球被彻底重铸过，最后已经认不出那是行星。

这与 `docs/world.md` §36 对齐：层级表示**影响与反制范围**，不是按人口逐层展开的地图。改造越深，文明的作用范围越大、反制越不依赖母星表面。

## 1. 三档设定

### 1.1 星球级 · 微痕

**文明在做什么**：住在地表，做微量改造。城市、道路、取水、耕作、夜间照明——都只改变地表薄薄一层，不改变行星的形状、反照率、自转或轨道。类比人类文明。

**从太空看见什么**：一颗完整的、自洽的自然行星。海陆、极冠、云带都是自然成因，明暗来自阳光与地形。仔细看夜面，能找到极稀疏的暖色灯点；它们不连片、不勾勒轮廓、不形成可见几何。

**看不见什么**：没有任何几何工程线、没有环球结构、没有非自然对称、没有张扬发光。把图放大也读不出「这颗星球被改造过」——这正是本档要守住的线。

**画面手段**：`tf_level=0`。自然地表（域扭曲 + fbm 地形 + 脊线 + Voronoi 石缝 + 海陆 + 极冠 + 云带）承担全部信息；改造只以 `hash > 0.942` 的稀疏夜面灯点出现，且只在暗面、只在陆地、冷色、极低强度。

**递进的临界点**：当灯点连成网、或地表出现第一条不属于自然成因的直线时，就已经不是星球级了。

### 1.2 星系级 · 重铸

**文明在做什么**：对地表做翻天覆地的改造。不是盖城市，是把地壳当材料用——沿赤道开凿环球工程带，沿经线架起脊梁，把大陆切成规则区块，在极冠叠同心构造。文明仍依附母星，但母星表面已经是造物而非地貌。

**从太空看见什么**：球还是球，边界仍闭合，还能数出「一颗行星」——但表面被**周期性、对称、等间距的几何秩序**压过。自然海陆仍在，却像被压在工程网格底下的旧底稿。能量沿这些工程线缓慢流动。夜面不再是零星灯点，而是成片的光网。

**看不见什么**：没有离开母星的居住体，没有第二颗行星，没有星系图式的轨道与卫星阵列。本档的重点是**一颗球被重铸**，不是「文明扩张到很多球」。

**画面手段**：`tf_level=1`。在原自然地表之上叠加五层工程语言——赤道宽暗工程带 + 细刻线、24 条经向脊梁、极冠同心环、36×18 大陆级刻痕网格、沿经纬流动的能量与夜面光网。工程遮罩把底色压暗再沿刻线提亮，让「意图」盖过「地质」。

**递进的临界点**：当球壳本身不再连续、地平线读不出来、中心露出不带地表的核时，就进入宇宙级。

### 1.3 宇宙级 · 遗蜕

**文明在做什么**：已经彻底脱离母星。母星不再是家园、不再是生产场所，被整体拆解、掏空、重排成一座没有用途的巨大结构。文明在别处；这里只剩工程遗迹。

**从太空看见什么**：**看不出这是一颗行星**。球面不再连续，沿纬度被切成彼此错开的壳带，各带径向推离、差速偏转；大半壳片被移除，碎片之间透出深空与星云；中心是一个没有居民、缓慢呼吸的亮核。碎片上还留着旧海陆的纹样——那是唯一能认出「这曾经是一颗行星」的线索。

**关键语气**：**空**。不是更繁华、不是更亮、不是更热闹。文明不在了，结构仍运转但没有用途。这比「巨型都市星球」更贴本作视角：邪神看文明，看到的是一层短促的痕迹。

**明确不做什么**：不另放一只巨眼、一道裂隙、一座星门、一个黑洞、一组方尖碑——那些是原作 `scene 2` 的「星际奇景」，是**另放一个新物体**。本档的物体自始至终只有母星自己，是它被改造后的形态。也不切到「宇宙全景」镜头，观察位置与前两档完全相同。

**画面手段**：`tf_level=2`。vertex 阶段按 9 条纬带 × 16 个面板把球壳推离并差速偏转；fragment 阶段按面板 hash `discard` 掉约四成壳片，保留的碎片显示旧地表纹样与结构边缘；`world_core.gdshader` 在球心放一个发光核；背景星云浓度提高，让碎片间不是死黑。

## 2. 三条递进轴（可量化、可回归）

| 轴 | 星球级 | 星系级 | 宇宙级 |
| --- | --- | --- | --- |
| **球面完整度** | 1.0 闭合球面 | 1.0 闭合球面 | ≈0.4 破碎壳片，地平线消失 |
| **改造痕迹的尺度** | 夜面像素级灯点 | 行星级工程带／经线／区块 | 超越行星：结构本身即主体 |
| **意图 vs 自然** | 自然 ≈100% | 几何秩序压过自然底稿 | 只剩工程，自然仅以残留纹样出现 |
| **文明是否在母星** | 是 | 是 | **否，已脱离** |
| **动效幅度** | 几乎静止，只有灯点轻闪 | 沿工程线流动、夜面光网呼吸 | 壳层差速、结构缓慢呼吸、核心脉动 |

三档是**同一套地表函数**打底，只是叠加的改造层逐级压过它——所以递进是连续的，不是三张互不相干的画。

## 3. 为什么这不是原版视角

明确**不使用**原作生成设计里的：

- `scene` 三分（星球立绘 / 星系图 / 星际奇景）
- `composition` 六档（居中 / 三分 / 巨构地平线 / 远景 / 日蚀逆光…）
- 11 个 `ARCH` 地表原型（溺亡之海、凝视之眼、古神之茧…）
- `star_type / wonder / count / rings / tentacles / eyes` 等题材参数
- 克苏鲁音节命名、图鉴编号式专名
- 另放新物体来表现「奇观」的做法

三档的相机、球半径、色板、天空特征、装帧全部一致，**唯一变量是 `terraform` 的 0/1/2**。这是本设定与原作最根本的区别：原作换镜头，这里换物体本身。

## 4. 保留下来的原作美术管线

新写的是**内容层与生成设计**，其余原样复用：

| 保留 | 文件 |
| --- | --- |
| 噪声库、解析光照、`style_shade`、全局 uniform | `shaders/common.gdshaderinc`、`noise.gdshaderinc` |

| 装帧（编号、引线、标题卡、边框、色卡） | `scripts/overlay.gd` |

媒介仍生效：同一内容层换成古典铜版画后，工程网格被排线译成制图感、纸白底与 `PLATE III` 装帧完整保留（见 `terraform-grid.png` 下排）。

## 5. 实物与复现

```bash
GODOT=/Applications/Godot.app/Contents/MacOS/Godot
BASE=docs/art/visual-generation/godot-base
$GODOT --path "$BASE" --editor --quit
$GODOT --path "$BASE" -- --shots=/tmp/out \
  --cfg=terraform:0,scene:0,style:0,seed:4242,palette:4,nebula:0.6 \
  --cfg=terraform:1,scene:0,style:0,seed:4242,palette:4,nebula:0.6 \
  --cfg=terraform:2,scene:0,style:0,seed:4242,palette:4,nebula:0.6
```

## 6. 已知弱点（不自行宣布通过）

- **星系级目前偏「刻痕／制图网格」语言**，张扬够了，但「翻天覆地重铸地表」的实体工程感还弱；若制作人要更硬的工程体量，需在赤道带补规则模块／桁架，而不是继续加亮线。
- 宇宙级的壳片颜色偏灰白，奇观感主要靠形态与亮核支撑；可再补冷色结构光与碎片间的连梁。
- 宇宙级碎片之间仍有较暗的横带，虽已透出星云，读起来仍略生硬。
- 星球级的夜面灯点在当前光照方向下很弱，几乎看不见——符合设定，但需制作人确认「几乎看不出」的度。
- 三档共用同一色板（冷原霜灰），尚未按蓝本调色；命名仍是工作名。
- 仍是概念图切片，未接 Session、未接公开投影、未动交互框架。
