当前概念大纲：让实际联系成为主场景（DEC-034提案）

本次只确定主体、功能之间的关系，以及它们何时值得进入玩家视野。以下是基于制作人新要求的设计提案，尚未经认可；不规定控件、布局尺寸、详细字段或完整制作计划。

核心体验：求告会过去，建立起来的联系会留下

开局，邪神感知到的是来自陌生现实的求告和少数可以触及的人。随着行动产生后果，具体人物、教团、圣物及神迹留下的痕迹逐渐成为持续存在的对象。它们会成长、受损、失控，也可能被利用或放弃。主场景随这些真实联系积累，而不是随已知世界数量不断增加等大的世界格子。

祈求与事件带来眼前抉择；人物、教团、圣物承接长期行动；锚点与降临形成有条件的持续责任。世界说明这些事情发生在哪里、受什么文明条件约束。玩家看到的是自己已经触及、还能影响的现实，而非一张脱离角色知情的全宇宙行政地图。

主体与功能如何连接

主体或功能 在整体中的职责 与其他主体的连接
祈求与事件提出眼前需要考虑的事情；事件只在合法阶段取得处理优先级带出相关人物、教团、圣物和世界。回应/处理结束后，原入口可以退下，真实后果留在主体上
重要人物与信徒是联系、施力、组织活动和承担职责的具体对象同一人可能是领袖、圣物持有人或锚点护持者；这些是同一人的关系，不能被拆成互不相干的副本。尚未有教团的人也可有合法行动
教团是持续发展的组织，也是常用指令、成员与收入的实际承载者传教/敛藏/守持作用于教团；成员任命使用既有权能；当地锚点与相关人物/圣物依真实关系相连。策略沿用，不强迫每轮重新下令
圣物是持续持有、使用和处置的具体东西与持有人、当地保管、权能准备或锚点绑定相连。它可能先于教团出现，不藏在教团成立后的功能里；失控或受损仍保留必要的已知状态
锚点与进行中的降临承载已经建立的立足点及跨回合投入锚点连接当地条件、教团、护持者、圣物与供奉；供奉顺序需跨世界统筹。降临开始后呈现其继续/中止与依赖，未开始时不占据日常中心
权能及其他主动操作为玩家提供作用于这些主体的手段权能保持完整稳定目录，并能从合法对象理解用途；教团指令、圣物处置、集会/祭仪/实践及记录转交按其真实主体和机会呈现，不勉强归为额外权能
邪神本体与回合统筹跨世界的资源投入、恢复与推进关注分配、敛息、结束回合等整体选择遵守各自资格；实际关注与展开查看分开。已回应后不能敛息，主场景不能把它误当作任意时点可用的恢复按钮
世界与文明提供身份、来源、行动条件和风险背景，始终可查无教团/锚点的世界默认边缘；若承载当前祈求、重要人物、遗物机会或迫近后果，则随这件事进入当前视野。世界数量不直接决定前景对象的数量

本表定义职责，不对应一组轮流占满主区的分类页面。常用主体保持可达，当前需要深入的关系才展开；不要求把所有人物、教团和圣物同时摊开，也不假设这些对象数量永远很少。

真正串起这些功能的是同一个人、同一件物、同一份预算及其持续后果。例如，一件圣物解除锚点绑定，既改变物件的可用途径，也影响锚点和当前苏醒；增加传教支出会减少本轮可用于供奉的信仰。玩家应能理解自己的一次处置牵动了什么，而不是跨几个分类页面拼凑结果。

功能何时进入视野

外露依据是玩家实际知道什么、当前联系允许什么、已经掌握什么、正在承担什么；不按固定回合发放界面功能，也不要求依次经历教团、圣物、锚点。

真实变化 概念上的呈现变化
获得具体祈求或有效人物联系人与诉求进入当前视野，带出当前合法的回应或施力手段
尚未拥有组织/物件，但已有合法机会在相关人物或事情上显露集会、祭仪、回收等实际选项；成团前的活动不能等到成团后才让玩家知道，圣物的取得机会不能等持有后才出现
建立教团或取得圣物新主体成为持续可达的常用对象，其指令与处置随实际资格出现；不再只藏在发现它的旧事件或某个世界资料里
建立锚点或启动持续降临引入真实的维持、供奉、续付与停止责任；让已有主体之间的依赖更明确
主体受损、失控、休眠或丧失呈现当前处境和仍合法的选择；不可用不等于删除记忆，也不把失去控制的对象继续画成可自由处置

权能完整清单和固定顺序继续保留；渐进显露改变的是相关主体、具体机会与当前重点，不能恢复“隐藏一部分权能”的做法。已经知晓且与当前目标有关的行动，暂时缺资源或条件时应保留可理解的限制，不能无声消失。

回合与后果如何接回主场景

祈求是每轮重要的选择，但不会在回应机会用完后继续占据主要操作空间。玩家随后仍面对已有的人物、教团、圣物与合法行动；他们的存在和可操作性不依赖还有没有祈求。

动作完成后，变化先反映到相关主体：人物的身份与状态、教团的安排、圣物的位置、锚点的有效性。未解除的危机继续随原对象存在。编年史常驻展示最新变化，并负责追溯它们如何发生；阅读记录不是理解刚刚执行结果的必经步骤。

低语、信仰及已有支出、苏醒、当前回合与关键期限提供共同判断背景。重要事件在合法阶段临时取得注意力；处理后回到持续对象。玩家可以保持既有教团指令、暂不使用某件圣物或结束回合，高频可达不意味着每轮都要逐项清空。

对方案一的实际修正与本批边界

保留“持续主场景＋当前对象前景＋按需深入”的方向。将教团、圣物和重要人物提升为主场景的常用主体，世界退回可查背景与当前对象的关联环境。旧图的整列世界及顶部三个世界块不再是必须保留的骨架；它们只有承担明确任务时才获得相应分量。

这份概念负责把主体、操作、出现条件和后果接通。旧18幅图是此前比较记录，尚未体现本次重心修订；本轮不重绘全部界面、不展开每个主体的详细交互或启动实现。后续仍按DEC-033取一个环节做出效果，再依制作人反馈推进。
