完整设计说明

从联系中感知现实：持续主场景提案

本轮按DEC-030重新组织界面。前版把祈求、权能、教团、人物、圣物、世界和历史各自铺满主区，实质仍是按类别换页；保留资源条和消息区没有解决上下文断裂。该导航及线框撤回，正确的信息核对保留。

制作人认可的起点是：邪神通过祈求、梦境、信徒和圣物逐渐感知不同现实，这些联系可以成为持续存在、直接操作的对象。以下空间安排、显示优先级和表现手段由此推导，尚未获具体布局认可。in-game-ux已明确禁用，直到制作人主动解除。

主场景应该让玩家感到什么

玩家不坐在一间人类指挥室里，也不站在宇宙外俯视完整星图。他身处尚未定形的混沌之中；一些凡人的声音、面貌、器物和群体从不同现实中浮现。眼前能看到多少，取决于已有的实际联系与情报，不能因为摆上场景就获得全知。

我建议以可接触的人和事为前景，以由此显露的世界为背景。这是本轮主推的组织方向，不是界面功能名。三个具体构想共同服务于它：

  1. 祈求让现实露出一角。 一次陌生呼唤可以只有声音、人物形象和少量已知处境；接触加深后，人物背后的文明才呈现可辨认的局部。世界之间不需要共同地平线：城市、仪式场所、舰群或非物质记录可以用不同切面表现，但只能表现实际获知的内容。
  2. 持续联系在同一位置留下存在。 信徒的身份、教团及圣物不是用完便消失的按钮。它们有稳定的视觉位置和当前状态；领袖死亡、圣物被扣押、教团停止供奉会发生在原对象上。场景位置是观看安排，不是世界坐标，也不是把人物或物件真的搬到邪神身边。
  3. 邪神施力，变化落回原处。 选中祈求者后，他的诉求、回应和代价在其附近展开；执行结果作用于这个人及其来源世界，随后留下实际变化与编年史记录。玩家不必在结果页和资料页之间重新拼接故事。

原有卡牌承载方向可以保留可辨认、可选取的对象形态，但不要求所有东西都装进等大的矩形卡，更不新增卡组、手牌容量、配方或整理牌桌玩法。图中的轮廓仅说明构图与关联，未锁定具体美术。

这里的分层不是远景只能看世界、中景只能看人物、近景只能看数字的机械对应。同一世界在正常时只需名称与简短状态；发生追捕且与当前祈求相关时，目标和期限应直接进入当前选择。

主界面没有“人物／圣物／教团／世界”轮流占满中央的导航。人物、教团和圣物首先从它们在场景中的具体对象进入；权能是常驻动作入口，也可从合法目标直接调用。全量名单、完整历史和设置有检索入口，但中后期频繁的教团指令不能被当成低频资料藏起来。

看一件事时，其他事情仍存在

以“让我的声音被听见”为例：玩家点选这则祈求，求告者在中央变得清楚，其已知世界获得对应强调；其他祈求保留在旁，已经建立的教团及其变化继续可见。浅触、深度干预、费用与后果在当前对象旁出现。

玩家若想先使用入梦，可以直接调用入梦并选此人。原祈求暂留为未完成的选择，界面明确当前将执行的是“入梦”，不是回应祈求。执行后就地显示真实结果、更新余额和人物状态，随后可回到原祈求；它不是延迟到轮末执行的计划，也不是一个新的行动队列。

需要看人物时侧面展开详情，需要比较时把有关的另一个人/圣物并置；不让玩家记住上页数值再切页。祈求/权能仍只要求原机制实际需要的目标或媒介，不能为了画面好看统一摆空槽。任命、转交、迁引仍通过有规则的操作完成，拖动一幅感知形象不会改变实际归属或位置。

如果某个教团同时发生值得留意的变化，它在自己的世界附近留下明确提示。玩家可以就地展开指令或成员，回到原回应时保留选择。若正在处理的是必须选择的事件，则中央事件窗口接管决策位置；普通消息和自由行动中新产生的候选事件不得借此随时抢焦点。

世界、教团与全局感怎样同时成立

主画面让玩家认出已接触的几处现实、在那里已有的教团/关键联系，以及哪里发生了会影响判断的变化。不是把每个世界的屏障、污染、察觉、稳定四组值全部铺开；具体已知状态在相关操作或展开资料时读取。

世界用可辨认的局部形象与名称作为稳定背景。教团摘要附着在其所在现实旁，正常时简短显示领袖、人数或当前指令中有用的内容；停止供奉、领袖失效、迫近清洗等异常直接说明事情与期限。全世界没有共同坐标，不画距离、疆域边界或无依据航线。只有查看实际已知通路时才画有名称和含义的连接。

只听见陌生祈求不自动补出完整世界、全部居民和机构。旧联系失效后，既有知识也不会凭空消失：相关资料保留，但“仍可接触”与“只剩旧记录”明确区分。苏醒升高可以改变角色表现的力度，不能自动增加规则未授予的情报。

规模增长时保留同一主场景，不靠新增类别页解决：

  • 常用或当前相关的具体联系展开，其余已知世界保留名称及状态摘要。单纯“保持展开”是阅读选择，不取得机制中的关注。
  • 世界增多时可缩成稳定的分组摘要，再展开其中一组；隐藏部分仍显示实际重要变化及可定位的对象。不能只给一个“有消息”的红点，也不能用自动轮播轮换世界。
  • 正常对象安静合并，异常与当前选择相关者单独可达；不按每次消息重新洗牌。位置变化由玩家展开/收起或明确切换查看范围触发。
  • 多团指令需要横向比较时打开集中展开层，保留世界来源、当前指令与支出；这属于信息加深，不把所有日常行为送入“教团页面”。
  • 全局感有显示容量上限。更多对象需要概括、筛选和检索；不承诺无限世界、人物同时以完整形象可读，也不把缩小字号当作扩容。

编年史在这个空间中的位置

底缘保留小型最新消息文字区，并可直接展开这件事及完整记录。对象上的变化与文字记录来自同一真实结果；画面表现不代替费用、状态和期限的清楚文字。过去不堆成不断增多的牌，避免让玩家每轮收拾残留物。

看某人或某世界时可以展开其相关往事，读旧记录不被新消息滚走。关闭阅读层回到原对象及原选择。人物永久变异、先知身份、圣物持有关系等继续留在对象状态里，而不只存在于编年史。

本轮可检查的结构条件

  • 展开一个祈求后，无需换页仍能比较其他祈求、看到余额和回应机会，并认出其他世界的重要变化。
  • 查看人物/圣物详情时，当前行动、目标及费用不被清空；返回恢复原选择，执行资格按最新状态重新核对。
  • 中央事件窗口只在实际合法阶段出现；相关资源与对象可查，不能靠关窗绕过事件。
  • 正常信息保持安静，临期危险持续可达；看过消息不等于解决，重要变化不因最新消息刷新而消失。
  • 图像远近不产生空间距离；展示位置不改变关注、归属或人物所在世界；没有事实依据的联系不画出来。
  • 图中场景外的状态选择器只用于审阅材料，不能被误读成游戏顶部菜单。材质、正式形象、动画和可玩接线仍后置。

规则与必要信息依据（继续有效）

正常一回合

  1. 展示轮初已经发生的变化。有必须处理的事件时处理事件，没有则直接开始自由行动。
  2. 主界面提供当前祈求和权能。每轮至多回应一张祈求，也可不回应；权能可在回应前或后使用，不强制排列成一串任务。
  3. 选中祈求后就在原操作里阅读诉求、选择回应、人物或媒介，并查看费用和结果。选择权能也是如此。不同权能只出现实际需要的选择项。
  4. 点击执行后立即扣费、结算并显示结果。玩家随后可继续合法行动；无需先去编年史才能知道成败。
  5. 已有教团的策略沿用上轮，按需要修改。查看人物、圣物、世界和历史不消耗行动资源，不强制逐页巡检。
  6. 点击结束回合后按原六阶段规则结算。普通回合不强制进入审核页面；实际重要到期事项可就地提醒。只读结算摘要不增加一个新行动阶段。

锚定是有条件的权能，持续降临是后期特定状态；二者的费用和依赖要讲清，但不代表日常操作。首团前的合法组织行动仍需入口，不能以低频为由删除既有玩法。

游戏内名称与信息取舍

玩家界面直接使用祈求、权能、教团、人物、信徒、圣物、世界、编年史、低语、信仰、苏醒，以及实际人物/组织/物件名称。世界为当前说明性的功能名，具体世界应以自身名称和已知特征辨认。

域、F/N/P、内部机构职责、事实编号、经营、当前牵动、现实依托、跨系统行动等不能作为玩家区块名。不能把“域”换成“诸域”继续使用，也不为邪神题材另造一套晦涩替代词。制作资料中的规则引用与缺口说明不进入游戏画面。

每项信息须至少支持一种真实需求：比较选择、理解规则与费用、识别人或事、察觉变化、记住仍在持续的事情、解释结果。暂时用不到的信息仍可查，但不挤占每轮核心操作。未知内容与尚未接入界面的内容分别登记。

查看一个已知世界：应当看到什么

玩家查的是“那个世界现在怎么样、我在那里能接触谁、我的行为留下了什么”。不能把世界做成一张全知指标表，也不能只剩几个没有身份的数值。

编年史：常驻最新消息，可以立即展开

用户提出“很小区域即时呈现最新事件并快速展开”作为参考。采纳方便触达、保持连续性的方向；区域尺寸、位置和显示条数仍由排版与阅读验证决定，不把参考表述当作已批准像素方案。

  • 主界面保留可见的“编年史”最新消息区。正在选祈求、人物或权能时，消息仍可看见；新消息不抢走当前选择。
  • 一条摘要写具体发生了什么、涉及谁；名字可点开对应人物/教团/世界。点击摘要展开这件事的完整内容、实际变化和已知前因；点击编年史展开全部记录。关闭后回到原操作。
  • 行动结果仍在当前回应/权能中立即展示，并进入同一份记录。消息区不会代替必要的成败反馈；查看两处不是执行两次。
  • 新祈求、教团成立、领袖死亡、人物变异、圣物易主、已知调查启动、苏醒变化等具有实际意义的事件应被看见。普通收入和同轮重复小变化可按来源合并，避免连续刷屏。
  • 一次原因造成多项变化时先给易懂摘要，例如“领袖死亡，教团停止供奉”，展开再看该人物、教团及苏醒的实际变化。不能仅列三条互不相干的数值变化。
  • 普通消息只提示；必须选择的事件遵守原事件阶段；即将到期的危险同时保留在相关人物/事项上，不因新消息挤掉而失踪。已读不等于已处理。
  • 玩家正在读旧记录时不自动滚走；新到消息给可见提示。消息未在小区内完整展示不代表可丢失，完整记录始终能查。
  • 按人物、世界、教团、回合查记录；对象详情可直接展开相关往事。只取玩家已知事实，未知前因不自动补齐。
  • 本稿线框仅示意底部较小消息区；是否改为侧边、显示几条、如何展开仍可调整。没有固定消息条数或新“消息确认”机制。

可参考的公开实践：

  1. Civilization VI官方开发者介绍：Diplomacy Gets a Major Upgrade：外交消息随玩家获得的情报而来，支持把“能收到什么消息”纳入知情规则。本稿不据这篇2016年的说明宣称已审计当前版本所有通知布局。
  2. Weather Factory：Cultist Simulator — The Renewal of Skin：2017年的开发记录明确强调情境窗口中新内容提示、可回看此前消息和文字可读性。借鉴的是让当前事情与前文保持联系，并非照搬其桌面或实时计时。

以上是对公开做法的借鉴。本作采用“常驻摘要→展开这件事→查完整往事”，并保留原回合阶段，是本轮设计判断。

持续场景中的进入与返回

场景里的实际人物、教团、圣物、世界名称和当前祈求是日常入口。展开它们增加信息深度；不以按类别切换中央整页作为默认导航。原操作与全局处境按上方分层表保留，事件作为合法时点的临时中央窗口。

全量名单、集中比较和长篇记录可用宽阅读层，菜单与结局各有实际流程。数量由需要说明的状态决定；本次只画同一主场景及逐层展开的代表情形，不声称所有稀有权能、长列表和后期布局已经完成。

鼠标/键盘都要保留当前对象、已选参数和返回位置。取消尚未执行的选择不扣费；已执行行为不能借关闭窗口撤销。不可逆行为用明确确认；对象失效时说明真实原因，不静默换目标。

跨阶段纸面走查与状态变化

以下按实际条件推演，用于检查同一套结构能否容纳不同阶段，不是要求玩家依次完成的攻略，也不是自然游玩证据。

情境 操作与信息应如何接续 必须承载的状态
已有信徒，尚无教团从人物或“尚无教团”说明查看该人的合法集会、祭仪等活动；执行时看实际费用、风险和人数变化，达到成立条件后依轮末规则形成教团教团空状态显示合法组织者、无名追随者及缺少的实际条件；没有无条件创建按钮，具名信徒不冒充无名信众；成立消息可直接打开新教团
多个世界、多个教团，正在选择祈求回应直接打开教团，按名称或世界查找；只修改需要改变的教团，其他安排沿用。查看相关人物后先返回原教团，再返回原祈求列表保留筛选、选中项与滚动位置；可比较领袖、信众、指令、预计供奉及异常；同名人物加所在世界/教团区分。查看世界不自动取得关注，也不暂停其结算
自由行动中发现追捕即将在本轮末发生在人物和请求附近查看已公布的目标、期限和后果，按当前合法回应或权能应对，或接受后果；读完消息返回原操作请求到期与追捕到期分别显示；相关危险持续保留，结束回合时可就地提醒。本轮生成的事件候选不擅自变为即时弹窗，仍按原规则最早下一轮处理；察觉下降不自动取消既有追捕
已开始降临，进入需要续付的一轮主界面直接看到进行中的降临，查看相关人物/教团，按当前规则继续或取消；第三轮续付展示并锁定最终概率，实际检定仍在轮末并核持续条件真实进行中的降临在相关人物和世界附近保持可见，总苏醒常驻。摘要显示进行到第几轮、尚未/已经续付及失效条件，局部展开看低语/信仰/人物机会与具体依赖；尚未续付不等于已经中断
已连续断联两轮，历史中仍有认识的人主界面给出实际断联计数与已知原因，相关人物说明旧记录是否仍代表有效联系；本轮确实恢复则轮末据实清零，否则按原三轮期限寂灭主界面在祈求上方保留明显风险提示，区分断联与苏醒归零。结局指向最后失效的实际联系；不泄露未来随机祈求、不编造救援，本轮低语耗尽不算断联

共有状态约定：

  • 没有祈求时明确显示“本轮暂无可回应的祈求”，合法权能和结束回合继续可用；已经回应则显示“本轮已回应”，不重复扣费或制造占位请求。
  • 没有教团、没有已知圣物、筛选无结果分别说明，提供相应的合法入口或清除筛选；不统一写成“暂无数据”。
  • 人物死亡、离开、拘禁或圣物失效等导致原选择不可用时，停止执行并说明实际原因，保留其他有效选择，不自动替换对象。资格不成立不收费、不抽随机结果。
  • 费用、人数、资格或概率改变时旧预览失效，先刷新并让玩家重新执行；不能沿用过期预览。
  • 长列表滚动与筛选不移动执行按钮；多处异常可在列表保留简短原因和到期回合，不能只藏在单个对象详情或消息流。长故事和结果可滚动/展开，费用与关键后果不能被截掉或靠缩小字号塞入。
  • 连续查看人物、教团、世界时，返回按钮说明回到哪个具体对象或哪项操作；同一详情区替换内容并保留返回记录，不无限叠加窗口。
  • 处理必须选择的事件时，可查相关对象和往事；自由行动入口遵守原阶段限制，不能借导航执行当时不合法的权能或跳过事件。
  • 常驻消息区保持全局最新消息，打开世界或人物不悄悄将它过滤为该对象消息；对象自己的往事在详情或展开编年史时明确筛选。

这些是本稿应实现的结构合同。现有线框呈现代表状态，尚未画完每个空态、长列表和稀有行动的具体排版；文字覆盖不代替对应状态的实际可读性与输入验证。
