入口与具体操作4 个入口 · 3 条链路

正常入口

  • 新局、继续、加载成功；有轮初事件时先处理事件
  • 当地“诸界”面包屑或无面板时 Esc
  • 当地近邻世界缩图
  • 世界档案详情“进入当地联系”

选世界

  1. 诸界卡片按数量平铺／叠放
  2. 左右键、滚轮或拖动浏览
  3. 确认卡片进入当地
  4. 近邻缩图切换另一世界

诸界事务

  1. 锚点与供奉责任→全局锚点
  2. 祈求摘要→祈求列表
  3. 已知反制／展开全部已知世界→世界档案

当地事务

  1. 四维／情报与反制→当地情报
  2. 人物／编年史→当地范围资料
  3. 锚点、教团、当地圣物、持续活动、祈求联系→各自功能
前提、分支与提交返回支付时机与共用界面

前提与分支

  • 世界为空显示空态；卡片由真实公开世界构建
  • 仅有已知教团时显示当地教团标记；圣物机会按实际数量提示
  • 轮初事件期间不能通过普通导航切换世界

何时写入／支付

  • 选卡与切换世界只改变查看范围，不关注、不支付、不刷新知识；各事务另行准备与提交

结果与返回

  • 当地面包屑／无面板 Esc 回诸界并恢复卡片焦点
  • 从档案明确进入当地会结束档案借阅，不返回原菜单
  • 事务关闭恢复当地及原入口

界面构成

  • 诸界卡扇及空态
  • 当地世界主体与近邻缩图
  • 四维与时点提示
  • 当地联系标记
  • 诸界事务摘要

入口与具体操作5 个入口 · 3 条链路

正常入口

  • 诸界“展开全部已知世界”或“已知反制”
  • 暂停菜单“世界档案”
  • 当地四维任一项或“情报与反制”
  • 行动已选世界“查阅资料”、中央世界联系、赐予世界查阅
  • 关注页的已关注世界条目

世界档案

  1. 搜索世界名／编号，可清除
  2. 切换全部／已关注／未关注
  3. 选行打开详情
  4. 读层级、四维、反制
  5. 进入当地，或查锚点、人物、机构、活动、圣物、历史、管理教团
  6. 关注／释放关注另进正式准备

当地情报

  1. 从指标进入时先读对应指标含义
  2. 读四维、文明背景、机构与反制
  3. 聆听当地已知记录→聆听准备→实际回执／返回情报

借阅世界资料

  1. 任务／关注页点击世界资料
  2. 读共享世界速览中的四维与反制
  3. 可查情报来源、教团成员、人物、圣物、锚点、机构、历史
  4. 机构资料可查代表人物、已有锚点，或进入锚定／活动准备
前提、分支与提交返回支付时机与共用界面

前提与分支

  • 档案无匹配、原行被筛除、仅请求线索分别显示
  • 当地情报的机构／代表是文字；共享世界资料的机构才可打开详情
  • 借阅世界资料不是档案或当地情报：仍有“情报来源→事情经过”，且没有“进入当地”
  • 无反制、无机构、背景未掌握及不同指标精度／时点均有状态

何时写入／支付

  • 查询、选择、资料及来源阅读均不提交；关注／释放、聆听、锚定和活动另走正式准备与提交

结果与返回

  • 档案详情→总览原行；总览→诸界或原暂停菜单
  • 档案关联事务→原世界详情、滚动和焦点
  • 当地情报→当地；聆听准备退出→原情报
  • 共享世界资料返回原行动／资料，保留有效草稿；连续关联共用一个原点

界面构成

  • 档案总览
  • 档案列表＋详情
  • 搜索／范围／空态
  • 当地四维情报与文明机构正文
  • 世界关联速览
  • 机构资料
  • 情报来源阅读

  3. 适用行动→可促成活动、入梦、任命或接纳／离团准备

  1. 从其他对象或行动查阅人物
  2. 连续展示人物资料各部分；依来源采用大图双栏或小图关联速览
  3. 非行动借阅可留作对照

  1. 查看本次角色、公开身份／处境／世界、正式成员能力及携带物名称

前提、分支与提交返回支付时机与共用界面

  • 人物目录无已知／无匹配／原选择失效分别处理
  • 能力仅公开正式成员属性；未接纳与请求线索有不同未知说明
  • 活动可能无事项或联系不足；正式成员可任命／离团，其他人物查接纳条件
  • 目录有五页签；独立 person 连续显示各部分
  • 祈求专用速览不能进入通用档案、教团、物品处置、行动或对照

何时写入／支付

  • 人物查阅不提交；活动、入梦、任命、接纳／离团由共享正式准备预览与执行；活动带人物适用范围

  • 活动回执先回同一事项，再退回人物；其他行动按原人物回调返回
  • 祈求专用按钮和 Esc 均返回原祈求

界面构成

  • 人物检索名单
  • 人物立绘＋五页签
  • 职责与能力未知态
  • 适用行动列表及限制
  • 独立人物大图资料
  • 人物关联小图速览
  • 祈求人物只读速览
  • 任务切换确认
