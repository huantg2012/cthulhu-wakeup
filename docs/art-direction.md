# 邪神苏醒 · 当前美术方向入口

2026-11-12，制作人明确通过「粗印画牌＋有机窥视窗口」界面母版。高维邪神在窗口这一侧观察与支配，世界、教团、人物以卡片作为共同载体；不同世界保留各自程序立绘画风，界面用稳定的灰绿颜料、粗印标题与可读正文容纳它们。

本页只做入口，不复制参数或另建一份标准：

- **直接看图：**[图文美术规范](art/visual-generation/ui-guide/index.html)，包含原生控件实物、图层与卡片图解、完整动态及引用有效范围。图册从唯一正文与示例清单生成。
- **UI 美术执行正文：**[全游戏界面美术规范](art/visual-generation/ui-art-standard.md)。包含已获准母版、组件与动效规则、全场景适配、正式接入顺序、验收及 agent 派发模板。
- **实施遇到无法决策的问题：** 按[反馈协议](art/visual-generation/ui-art-standard.md#art-feedback)记录到[问题台账](art/visual-generation/ui-art-feedback.md)，交规范维护 agent 解释、补规则或打样。
- **原版与可复现证据：**[基线清单](art/visual-generation/ui-approved-baseline.json)、[样板运行记录](art/visual-generation/ui-study/README.md)。
- **立绘生成规则与技术边界：**[system-art-generation](specs/system-art-generation.md)。图像身份绑定、异步调度和正式场景接入仍待实施，不重做现有生成器画法。
- **交互与信息合同：**[ui-interaction 当前合同](specs/ui-interaction.md#locked-interaction-production)。美术不改变已锁定的操作框架。
- **当前状态和禁令：**[UI 执行路由](progress/stage-priorities.md#game-ui-routing)；批准依据 [DEC-064](progress/decisions-log.md#dec-064)。

目前是母版审美通过，全部正式场景尚未换肤。其他场景使用同一语言按规范落地，不能自动记为通过，也无需重新抽选字体、配色和外围方向。旧 `echoes-ui` 及被否定候选仅为历史，不作为当前生产标准；`in-game-ux`、`visual-art-production` 的持续禁令未解除。
