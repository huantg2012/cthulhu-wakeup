# 世界与术语

状态：策划案工作设定，2026-10-25；机制服务于 [愿景](vision.md)，不锁定美术风格。

## 核心设定

混沌是时空诞生与湮灭留下的碎屑。碎屑偶然形成自我，玩家由此开始苏醒。它能感知凡人的祈求，却尚不能任意改写现实。教团、圣物、梦境与仪式构成干预媒介。

文明的抑制力来自其维持现实秩序与解释世界的能力，不预设科技、宗教或魔法谁更理性。屏障是这种自洽性的整体表现，调查者、仪式、制度和传播封锁是其具体行动。

神意不等于信徒的理解。一次回应可实现愿望，也可扭曲欲望；污染不必先击破屏障，屏障破口只会提高可达性与干预效率。

完全苏醒使各文明及邪神归于混沌。寂灭与苏醒都是本局终点，但前者是失败、后者是完成目标；不以结局是否存续来抹平二者的过程意义。原稿关于极少玩家见到终极真相的想法保留为创作意图，不把精确到达率写成指标。

## 空间与时间

- 时空域：一处可独立追踪的文明环境，含有限地点、机构、人物与教团。不是逐个模拟全宇宙居民。
- 文明层级：星球级、星系级、宇宙级，表示影响与反制范围；不是必须按人口逐层展开的地图。
- 回合：一次邪神注意力分配周期，局部世界可经历不同长度的历史；不强制等于一天或一年。
- 相邻时空通过少量传播通路联系，跨域影响必须有媒介或通路，不能让任意两人产生无理由关系。

## 统一术语

- 苏醒：全局进度，可增长也可回退；与权能开放关联。
- 信仰：可积累、可消耗的全局资源。
- 低语：每轮恢复的行动预算，不跨回合囤积。
- 信众：按群体计数的无名教团成员。
- 具名信徒：有持续身份、属性、经历和关系的具体人物；NPC 还包括未信仰玩家者与敌对人物。
- 圣物：具备独特媒介资格或效用的对象，身份、所在位置和持有人持续追踪。
- 屏障：文明抵御异常渗透的结构状态；有破口不等于文明已被污染或失去抵抗力。
- 污染：现实接受异质规律的程度；需要区分进入、传播、扎根和反扑。
- 察觉：文明对邪神活动的警觉程度；不同文明分别记录，不等于玩家获知的情报完整度。
- 抵抗：文明针对证据和威胁采取的行动，可能以需要决策的事件或预告后的自动后果出现。
- 祈求：具体人物在具体处境下提出的愿望，具有来源、诉求、时限和后续关系。
- 事件：由状态、历史和随机性共同筛选的局势变化，允许某回合没有事件。
- 因果记录：记住“谁因何发生了什么”的事实；面向玩家的编年史只展示其已知部分。

## 叙事约束

玩家面对的是人的具体需求与后果。神秘感来自超出人类尺度的意义，不靠隐藏支付规则。规则提示直白，叙事文字可含蓄；不能用叙事模糊掩盖代价。

同一角色可成长、变异、背叛、死亡，但身份不被随机文本重置。死人不能无解释地重新祈求；复活若以后加入，须成为有规则和代价的独立行为。

科技、魔法、宗教、群体思潮可以共存；文明必须内部自洽，不将现实群体直接套入善恶等级。文风可含冷峻幽默，但不默认网络口吻。命名、文字与图像不借用现成作品专有内容。
