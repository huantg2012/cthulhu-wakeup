# 创作愿景：克苏鲁风格邪神模拟器

状态：策划案第一版，2026-10-25。作者已确认的边界见 [决策记录](progress/decisions-log.md)；本文将其组织为工作愿景，新增的具体机制均是可修改的设计提案，不冒充作者终审。

## 核心承诺

从神的一侧回应祈求，并观看神迹怎样改变人和文明。玩家是尚未完全苏醒的邪神，通过凡人的欲望、具名信徒、教团与圣物建立现实中的立足点，在文明的察觉和抵抗中争取完全苏醒。

## 体验支柱

1. 有限的干预，持续的后果：一次回应必须进入世界状态，并可能在之后以人、制度、事件或抵抗的变化返回。
2. 强大的权能，具体的依托：力量依赖目标、条件与代价，不能靠没有媒介的直接攻击解决全部问题。
3. 所有选择都有得失：不设计不分局势的通用最优解；允许局部优势，不强求每个选项每时每刻等价。
4. 湮灭是常态：允许损失、苏醒回退与整局失败，文明不是等待收割的资源库。
5. 同一套规律，不同的文明：生成重组进入、传播与扎根条件；人物和世界记得玩家行为。

## 产品边界

- 单人、离线、回合制、卡牌承载的叙事策略经营游戏；第一版以桌面端为规划基线，平台发行尚未承诺。
- 没有动作战斗，不以传统抽牌构筑对战作为默认模型。
- 本次交付是完整策划案与技术难点验证，不是整款游戏开发；不重设被作者跳过的短体验前置阶段。
- Godot 为指定引擎。前期机制优先，使用最简单的交互表达；美术风格、最终界面品质、音频方向留待后续。
- 架构必须让规则、内容、存档、呈现分离，换美术不能重写文明与叙事系统。
- 不把实时大模型服务设为运行必需条件；具体内容生产方式由策划案说明。

## 成立与否的判断

玩家能根据局势解释选择，能追溯一次神迹的后续影响，能辨认文明的不同应对；失败能解释但不保证可挽回。可用自动检查证明规则一致和技术边界，不能用自动检查证明好玩、无通解或审美成立。
