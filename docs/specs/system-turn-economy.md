# 回合、资源与经营

## 1. 本版定位

这是可交给后续实施拆解的策划规则，不是程序接口。本文及关联 CSV 是单一设计提案，尚未经完整玩法实现、真人试玩或长期平衡验证。“所有选择有得失”是持续审查目标，不是已证明无最优策略的数学结论。

初始参数、公式系数和节奏估计的唯一数值源为 [run_parameters.csv](../../data/run_parameters.csv)。数值更改先改 CSV，再同步本文中的说明与示例。文明参数属于 [文明规则](system-civilizations.md)，不在此另设同义数值。

## 2. 玩家在管理什么

- **低语**是每轮行动预算。查看档案、比较选项、设置教团策略和预排供奉不耗低语；实际回应与权能按条目支付。未用低语不结转。
- **信仰**是全局可积累货币。来自教团供奉、明确的事件收益、献祭或解离圣物；用于回应、权能、传教与锚点供奉。没有默认利息，也没有把库存信仰直接购买苏醒的通用按钮。
- **无名信众数量**是教团基础；具名人物另有身份与能力。二者不可混作同一个可随意互换的数字。减少信众不能悄悄杀掉一个具名人物；反之，具名人物死亡也不默认再减一名无名信众。
- **圣物**是有身份、来源与位置的对象。可装备、绑定锚点或永久解离，不能在多处同时使用。
- **苏醒**是由当前世界立足点与个人经历共同决定的进度；公式见 [进度规则](system-progression.md)。它不是可重复消费、返还的普通货币。

开局参数暂定信仰十八、苏醒十、低语三。起点至少有一种合法接触和一条可执行浅触回应；这只是确保游戏能开始，不保证回应成功或整局可赢。

## 3. 一轮的固定顺序

### 阶段一：轮初整理

1. 回合编号推进，完成上一轮已排定的状态到期。先处理死亡、迁移、圣物归属与任职变化，再判断任何绑定对象的资格。
2. 用整理后的当前苏醒恢复本轮低语，清除本轮回应次数与执行机会。低语计算为“基础值 + 当前苏醒除以成长步长后向下取整”，再限制在上限；基线即 `min(6, 3 + floor(苏醒 / 30))`。
3. 展示到期计划、当前供奉预计支出、可用对象和祈求期限。既有事件的默认后果按它们的到期规则推进，不因本轮无随机事件而暂停。

轮初刷新后，本轮低语总预算不因苏醒变化再发放或收回；高阶权能资格仍随当前苏醒即时变化。这样既避免同轮跨阈值反复领取，也不让已安排的输入突然扣掉额外低语。

### 阶段二：事件处理

按 [事件规则](system-events.md)筛选并处理零至两张主要事件。可以整轮没有事件。必须处理的事件至少有一个零货币、零低语的承受或放弃分支；它可以导致严重损失，不可因资源不足阻塞结算。

选择需要调用权能的事件分支，要照常支付对应权能费用并检查对象与解锁条件。事件不额外占“本轮唯一祈求回应”，但会消耗其实际声明的资源与人物执行机会。

### 阶段三：自由行动

- 查看至多三张有效祈求，最多回应一张；允许本轮全部不回应。
- 在预算和对象资格允许的范围内使用权能，可以在祈求回应前准备，也可以在回应后利用已经产生的事实。新生成的事件候选最早下一轮才弹出。
- 调整各教团本轮策略、锚点供奉优先序和本轮明确拒付项。调整这些计划本身不扣费，结束回合前可改；已执行的权能与回应不能倒回。
- 可在尚未回应祈求、未使用任何权能和圣物操作时选择整轮“敛息”。该策略封闭本轮余下行动，用资源治疗创伤，世界仍继续演化。发生在本轮前面的事件费用不取消敛息资格，但事件中实际调用过权能则取消。

每个承担“执行任务”的具名信徒每轮只执行一次侵入、播种、锚定、掩迹、迁引或持续降临任务。接受梦境、听到神谕不算执行任务；是否仍可行动要看其受伤、拘禁、封存等具体状态。任命下轮生效，不能通过转职刷新执行机会。

### 阶段四：锁定计划并演化

1. 锁定行动结束时的世界状态与当轮计划。玩家已完成的事实保留，不以结果不利为由取消付费。
2. 先从现存信仰支付合法且启用的教团传教支出，再按玩家给出的固定优先序支付锚点供奉。玩家可以预留未来费用，但未到账的本轮信仰收入不能用于本轮支出。
3. 传教无法支付时本轮转为守持，不生成负债或免费人口；拒绝或无法支付的锚点供奉使该锚点休眠。轮初就要预览这种后果，不在结算时临时发明扣款。
4. 基于同一个快照计算教团工作、文明恢复与反制、人物状态和污染维持，再批次合并变化。相互冲突的效果由各系统预先规定的优先级处理，不能靠遍历先后猜答案。死亡与永久破坏优先于同轮普通任命或恢复。
5. 重新核验锚点的机构条件、污染、护持者、圣物与供奉。新建或修复成功的锚点此前处于休眠，只有本次实际付费且仍满足条件才转有效；本轮不会先借它解锁更多行动再拒付。批次结果落地后立即刷新当前苏醒、历史峰值与信仰容量，阶段五使用此时的新容量接收收入。

自动支付不是自动替玩家做战略选择。若某项当前无效，不能先收取它的正常费用；若在付费后被同轮已预告攻击摧毁，已付资源不返还，并在预览列明风险。每项支付与结果记录来源。上一轮有效锚点的贡献延续至本轮供奉结算；只修改“拒付计划”不提前撤销贡献，实际拒付时才休眠。媒介死亡或机构失效是已经发生的事实，仍立即停贡献。玩家可借仍有效的立足点执行最后一次合法行动后放弃供奉，这是明确允许的撤退选择。

### 阶段五：收入与期限

计算存续教团的供奉收入，处理未回应祈求的期限与到期后果、归档本轮事实。收入基数只包含轮初已经存在、轮末仍存续的信众；本轮新增或跨域迁入的人不在本轮重复产出。教团本轮才成立时，从下一轮开始产供奉。

到期后果可以再次改变人物、锚点或苏醒，必须应用完毕再判断终局。不能先发胜利再偷偷补一笔同轮损失。

### 阶段六：苏醒与终局

重新计算苏醒与断联状态，处理持续降临的本轮有效性及最后一轮判定，再执行 [进度规则](system-progression.md)的终局优先级。没有终局才进入下一轮。

## 4. 信仰与教团收入

每个可运作教团的基础收入为：

`floor(min(教团收入上限, sqrt(合资格无名信众数)) × 凝聚 / 100)`。

选择敛藏时，先再乘敛藏收入系数，最后只向下取整一次。无领袖的休眠教团不产收入。上限限制单团规模收益；凝聚使单纯增加人数不等于稳定财富。

例如八十一名合资格信众、凝聚八十的教团，按当前上限八产出六信仰。把人数继续翻倍也不会把收入翻倍；提高凝聚、保护机构或探索另一处机会可能更有价值。这是公式推导，不是试玩测得的收益。

库存上限是“基础容量 + 本局苏醒历史峰值 × 容量系数”。历史峰值只决定容量，不继续提供权能资格；苏醒回退不直接销毁已经存下的信仰。超额收入在结算时散失并明确记录，不能负数、溢出或转换为隐藏进度。

全局十二个域都可以拥有教团并持续经营；“同时展开六域”只是信息展示边界，不是经营槽或收入暂停器。按收入上限八计算，十二个满凝聚、达收入饱和人口的教团理论毛收入上界为九十六；这是极端上界，不是正常收益承诺。后期广铺是否形成压倒性的优势，必须与有限低语、文明反制、到达成本和锚点维护一起检查，不能以六团推算代替完整经济分析。

## 5. 三种教团策略

每团每轮一种策略，可沿用上轮选择；其经济效果是明确可预览的自动工作，不额外消耗邪神低语。

- **传教**：支付本轮传教费用，新增“基础招募数 + 领袖影响除以招募系数向下取整”的无名信众，并增加本域察觉。新增信众受本域可接触非信众余量限制。没有可招募对象时，选项会说明无人口收益，不能仍假装增长；玩家可改策略。有真实效果来源封锁的具体渠道不能继续使用；另一条独立真实渠道仍可检查，官方敌意本身不作封路。
- **敛藏**：收入乘敛藏系数，不主动招募，减少本域察觉。它不能抹去历史事实、撤回正在执行的反制或让公开异常消失。
- **守持**：正常收入，无额外招募和察觉修正。仍需逐个支付锚点供奉，也仍受文明与人物事件影响。

三种策略不自带“正确选择”标记。传教在有窗口时扩张，敛藏在尚有隐藏空间时换取喘息，守持在收入与维护之间保持资源。若实际模拟中某项始终占优，应修改收益关系，而非依靠文案宣称有取舍。

无名信众自然流失量为 `N × 自然流失系数 × (1 − 凝聚 / 100)`，累积小数余量，足一人再扣除一人。自然流失返回本域非信众群体，死亡或迁移另走具体后果。此机制不在凝聚满值时硬扣人；文明危机仍可造成损失。

## 6. 所有支付的共同规则

- 资格、固定费用与当次全部概率在提交前确定。无效对象、缺少媒介或资源不足时不支付，不抽随机数。
- 一旦有效行动执行，先扣明确的不可退成本，再结算结果；失败是否返还某项资源只能由条目明确声明，默认不返还。
- 卡牌预览与取消不推进时间、不刷新结果。不能通过反复打开卡牌改变骰子。
- 数量减少不低于零；数量增加不超过容量。人口与物品必须从有记录的来源转移，不能同时在两处存在。
- 信仰、低语不允许借贷。事件可以留下未来承诺，但必须是显式计划，不可偷偷把资源余额变负。
- 减少察觉不能消除已发生事实；拆除或重建锚点不能产生重复奖励；绑定或持有圣物不能复制实例。

## 7. 节奏与极端状态

不回应是一种合法选择：它保留行动预算，也放弃当轮唯一回应机会，且祈求期限继续推进。不对每张未选卡征收统一罚款；具体人物可能在到期后死亡、离开或改变立场。

空过不会冻结文明。传播窗口、调查计划、祈求与锚点维护照常前进；稳态收入有容量上限，不能以无限等待解决所有局势。仍可能存在暂时安全、适合积累的局面，不能为强迫忙碌而每轮必罚。

零信仰时可以浅触、聆听、停止供奉或承受事件；没有合格对象时可以结束回合。上述路径只保证输入能够结束，不保证局势可救。彻底失联与苏醒归零会按规则寂灭，不保留无限空回合的假存档。

## 8. 验证要求与未决假设

- 同一快照和同一行动顺序能重现结果；更换卡片排序不改变经济。
- 当轮招募、迁移、教团成立不会重复领取收入；任命不刷新执行机会。
- 无钱时事件能结算；无对象时可以结束回合；拒付不会自动借贷。
- 存续锚点付费与进度贡献对应，先毁后修及同轮新建的规则明确。
- 对比至少扩张、静默、锚点优先等策略的完整局轨迹，记录收入、进度、风险和失败原因；这属于后续平衡工作，不另设作者已否决的短体验前置阶段。
- 本版未证明收入上限、维护负担和事件密度已经平衡；尤其要检查跨域经营是否成为机械缴费，以及稳态等待是否形成通解。

## 9. 跨系统结算约定与责任

每项共享事实有唯一归属结算入口。权能、事件、人物自主行为和文明反制提交有来源的变化请求，不分别维护第二份人口、资源或进度。对应的责任索引是 [SET 约定](../implementation/traceability.json)：登记读入、写入、阶段、冲突顺序与验收编号；规则正文仍在本文件及其唯一归属 spec。它不是一份可自行覆盖规则的程序接口。

阶段四的快照指**本轮合法行动及前置支付落地后的状态**。从同一快照决定人物与机构候选；同批新发现的证据和新形成的关系最早下一次候选选择可用，不能因为执行顺序靠后而得到额外行动。每个具名人物至多执行正式行为表允许的自主行动；已承担玩家执行任务的角色不再获得自主机会。人物的具体资格、成长与暂时失能以人物 spec 为准。

批次合并先处理不可逆身份事实（死亡、永久毁灭），再验证迁移/归属、职务和媒介的合法性；普通恢复与任命不能复活死亡对象或取代本已失效的主体。数值变化按同一事实来源去重后合并、最后裁界。需要竞争同一唯一对象的动作在提交前按明确的优先级和稳定 ID 仲裁；落败动作不偷扣一半成本，也不能换一个未声明对象完成。

身份/媒介提交后，依次更新对象有效性、锚点贡献、当前苏醒与可用权能；本轮低语总预算仍保持轮初值。教团与机构继任分别沿自身规则在下一轮初处理，不把临时失能自动当作永久空位。临时失能的原护持者恢复后，锚点仍需在下一次合法供奉结算中恢复，不能借状态切换免费重启。

事实归档记录实际前提与参与者；同一结果允许多个来源，没有真实前因时记录根事实。显示顺序与真实因果分开，最近一条记录不能自动成为因果父项。玩家可知范围与后台完整事实分别保存。

这些约定需通过 `ACC-ORDER`、`ACC-DEATH`、`ACC-BUDGET`、`ACC-ATOMIC`、`ACC-CAUSES` 等跨系统场景验证。正式推演只运行其中一部分时，应报告具体范围，不以“可推进一轮演化”宣称完整六阶段游戏已接入。

## 10. 统一回合编排的实施约定

本节把既有六阶段规则收紧为可保存、可接续和可否证的结算约定，不新增玩法或数值。回合协调负责时点、权限与事务；各规则仍由本文件第 3–9 节及对应系统 spec 定义。`TASK-TURN` 完成表示这套编排与已登记的正式人物/文明核心接通，不表示全部权能、事件内容、经济经营、锚点建立或终局已制作完成。

### 10.1 唯一回合位置与输入边界

每局保存回合编号、当前阶段、该阶段已完成的结算凭据、待处理事件、当轮回应是否已消费、人物执行占用、已锁定计划及待到期后果。编号只在合法进入阶段一时推进一次；阶段六完成且未终局，才允许下一轮阶段一。角色自主演化结束不是回合结束，不能由此跳过收入、期限或终局检查。

阶段二允许处理已冻结名单中的事件；全部已处理或按合法默认分支承受后，才进入阶段三。阶段三允许当前已接入且有资格的玩家行动、调整计划或结束行动。阶段四开始锁定计划，之后不能倒回修改供奉顺序、拒付或本轮策略。阶段四至六的自动结算可以分别留下安全保存点，但任何中间点都不是新的行动窗口。终局后仅可读回顾或另开新局，不能继续提交普通行动。

协调器是正式游戏回合的唯一入口。推演核心中用于独立验证的 `begin_turn`、`evolve`、`advance` 不得成为玩家可绕过阶段的另一条通路；内部“已完成演化”的状态不能覆盖协调器的阶段位置。上游已经授权效果的 `submit`、`introduce_fact` 也不是玩家免费编辑世界的命令，必须经所属规则核验资格与费用后消费。

### 10.2 重复输入与失败的区分

一次输入带持久请求身份和固定内容。同一身份、相同内容重试，只返回原结算凭据，不再支付、投骰、推进阶段、刷新预算或重复写历史；同一身份换成另一内容则拒绝。读档继续保留这些凭据，不能因程序重开再次领取结果。错误阶段、未知操作、无效目标或资源不足，在变更状态与抽取随机数之前拒绝。

**玩法失败也是已发生的结果。** 一次合法检定得到失败或灾变，照常保留其费用、事实与请求凭据，不因结果不利回滚或换骰。只有输入无效、规则参与者未能完成约定、返回不合规或结算中出现实现错误，才属于事务未提交。

玩家单次行动是一笔事务；每个自动阶段是一笔事务。事务未提交时，世界、随机流、阶段位置、队列、占用与统计恢复到该事务开始前，不留下半笔支付或不可重现的随机消耗。阶段四失败不撤销阶段三已经成功提交的行动；阶段五失败不重新收费或再运行阶段四。恢复后重试仍执行原规则与原输入，不提供玩家撤销已结算行为的能力。

### 10.3 轮初和行动机会

阶段一先整理本轮已经到期的不可逆身份与归属事实，再处理受其影响的既存抵抗计划及继任，更新绑定资格与苏醒，最后刷新低语。多个来源同时到期时，先失效对象再重查计划目标，不能先攻击已应死亡或离开的旧对象，再补做身份清理。已预告计划的到期不占随机事件名单，也不因本轮没有主要事件而暂停。

同批到期后果按第 9 节的身份优先级合并：死亡先于普通恢复和迁移，不由队列 ID 或遍历顺序决定。因同批死亡而失效的普通恢复、迁移应显式取消，并记录死亡事实与原计划作为前因；不能把这种合法冲突当作实现错误，回滚整阶段及已经合法发生的死亡。

本轮低语总预算只在这一位置确定一次；行动、失去锚点、恢复创伤或阶段四后苏醒变化均不重新领取或收回预算。各次实际支付只减少剩余低语。事件调用权能与自由行动共享同一份余额、人物执行占用及权能使用记录；阶段切换和转职不清空这些记录。祈求回应机会则只由实际祈求回应消费，普通事件选择不冒占该机会。

### 10.4 事件名单和延迟后果

阶段二开始时依据整理后的状态确定本轮主要事件名单，记录本轮候选边界和已知前因；名单不会因重开面板、读档或处理第一张卡而重新抽取。零张合法事件可以直接进入行动，不补造内容。强制事件的承受分支必须零信仰、零低语且可结算；“无钱”不能变成无法退出的等待。

事件选择仍须执行时复核目标。目标失效时按事件原定策略处理，不随机换人继承历史。阶段二之后产生的新事件候选只能进入下一轮筛选；已产生的物件、人物状态与资格按原规则立即生效，不为防止递归弹卡而一并拖延。

每项到期后果保存自己的来源、对象、到期回合和指定阶段。轮初抵抗与轮末祈求危机分别走原时点，不把所有期限搬到同一阶段。按正式规则已经预告、且本轮阶段五尚未开始的期限，可以在本轮阶段五结算；祈求入选轮计入期限，不因加入队列而被额外延长。轮初后果只能安排到后续回合；阶段五内新产生的同类后继也必须安排到后续回合，不能在当前或已过阶段递归执行到队列为空。新主要事件仍最早进入下一轮名单，尚未预告的新危机不能借当轮期限直接执行毁灭性后果。玩家操作或表现的重复调用不会再次消费已经完成的期限。

### 10.5 支付、演化、收入与终局的接合

阶段四先用当前已有信仰处理合法计划的预付和缺资降级，再冻结人物与文明共同快照。正式人物/文明演化在此恰好执行一次；已占用的执行者不得获得额外自主行动，人物与机构均不能读取同批新产生的证据来追加一次行动。归属、媒介和进度在批次落地后更新。阶段五的预期收入不在预付可用余额中。

阶段五只执行本轮应结算的收入与期限；每笔收入保留所属教团、合资格基数、计算来源与实际入库/溢出量。编排层不能把外部随意填写的“奖励数值”当作教团正式收入。教团与人口资格由经济规则提供，编排只保证使用规定时点和只执行一次。期限引起的死亡、失锚或创伤落地并刷新状态后，阶段六才读取终局条件。

阶段六读取最新世界，按进度 spec 的次序先检查寂灭，再检查仍合法的降临；仪式失败后应用后果并再次检查寂灭。终局凭据一旦提交不得再次检定或继续世界演化。没有事件、没有合法行动或零余额仍可推进这些阶段；是否仍存续由真实终局规则判断，不由编排器捏造一条救援或把空世界默认为永续。

### 10.6 已接入能力、未接入能力与保存

各阶段使用明确登记的规则参与能力，登记其稳定身份、规则版本、可以消费的输入和可以产生的效果。缺少当前局势必需的能力、未知效果、未返回明确结果或来源不合法，必须明确拒绝该次提交，不能把空回调视作已完成。合法空集合是“本阶段没有适用事件/计划/收入”，必须与“这一能力尚未实现”区分。参与者不能从输入文本获得任意改写整个世界的权限。

保存必须同时覆盖世界及随机流、协调器位置、已提交请求、冻结名单、队列与参与能力版本。恢复先校验整体兼容性和引用，全部成立才替换当前会话；未知版本、缺必要参与能力或游标与凭据矛盾均拒绝。尤其在阶段四完成、阶段五尚未执行处恢复时，不得再次演化或预付，也不能跳过收入与期限。仅有世界快照、没有回合位置的旧验证存档，不自动升级为正式完整回合存档。

本轮必须实际接入正式 NPC 与文明演化，不用测试替身代替它们。尚在后续任务中的完整事件、权能、经济和终局可以通过受管理的验证参与者检查编排合同，但报告须逐项标明：哪些是真实正式调用，哪些是明确场景的验证适配。验证适配至少要实际产生可核对的支付、状态变化、期限与结束后果，不能仅返回“阶段已运行”的日志。它的通过支持编排行为，不替代 `ACC-INCOME`、`ACC-POWERS`、`ACC-EVENTS`、`ACC-ANCHOR-PAY` 或 `ACC-ENDING` 等完整业务验收。

### 10.7 本轮可否证验收

- `ACC-ROUND`：一次含明确事件效果、玩家行动、预付、真实人物/文明演化、收入、到期人物后果与终局检查的集成运行，顺序可追溯；付款不能预支随后收入；期限后果改变终局读取的实际状态。报告逐项披露参与者范围。
- `ACC-BUDGET`：行动中护持者失效使锚点贡献和当前资格立即下降，但本轮低语总预算不回收或重发；下一轮才按新苏醒刷新。事件已占用的执行者在阶段三及阶段四均不能再获得执行机会。
- 同一请求重送及保存后重送，不再扣费、抽随机数或推进阶段；同请求身份的异内容、越阶段输入、未注册能力及未知效果被拒绝且不改变世界。
- 阶段四预付后故意触发参与者失败，整阶段回滚到付费前且不撤销先前已提交行动；阶段五失败重试不会重跑阶段四。
- 在事件处理、自由行动以及阶段四之后分别保存恢复，再提交相同后续输入，世界、阶段、费用、因果与随机状态一致；坏回合快照整体拒绝。
- 零事件、零信仰、无合法行动仍可结束行动并推进真实演化；后继事件不进入当前冻结名单；已终局的会话拒绝普通行动与新回合。

这些是正式模块的规则验证，不构成另设的短体验前置阶段。完整游戏操作、玩家理解、策略平衡与乐趣仍由对应后续任务提供证据。

## 11. 正式经济的实施语义

本节细化 `TASK-ECONOMY` 已有的前付、收入、招募、流失与容量规则，不调整 CSV 数值。正式经济必须在统一回合中执行，不能继续由测试参与者填写收入或人口结果。已有教团与锚点可作为有来源的输入；教团自然成立、完整任职与覆灭恢复、权能、锚点建立及各蓝本独特条件的完整证明仍由其原任务实施。

### 11.1 上游对象与资格

每域至多一个玩家教团，无名信众总数以该域的人口记录为准，教团不能另存一份可独立增减的居民。经济读取教团的持久身份、所在域、成立回合与来源、状态、领袖和凝聚；成立回合不能由收入代码猜测或在读档时默认改成往年。

可运作教团须组织状态为 active、有无名信众且凝聚为正，领袖仍是本域 active 的合格信徒。领袖拘禁、失踪、死亡、迁出或不再满足信徒门槛时，教团不能传教、取得敛藏效果或产供奉；计划须显示不运作原因，不能以名义领袖 ID 尚在绕过资格。继任与正式生命周期仍由教团系统执行，经济不自行找一个替身；组织状态已是 dormant 时，也不能仅因领袖归来而由经济擅自改回 active。存续的休眠教团仍按自身凝聚承受自然流失；没有教团或已覆灭的历史对象不凭空获得一套自然流失规则。

普通传教与强化传播不共用一张通行证。普通传教只消费文明规则第9.1节由教团状态派生的招募资格；POWER_SEED另查cult_spread_conditions.csv的蓝本媒介。此处cell/channel是资格与来源记录的接口名：不模拟逐人接触、各类社会网络或渠道覆盖；普通招募以本域现有无名非信众总池为聚合口径，不能从“可接触”推导出已模拟具体目标关系。指定材料合作只改变材料可用性，不增加招募人数。正式schema2的economy_qualification仍保留rule=propagation及subject=原cult稳定键，但其allowed只是派生的本地可招募结论，必须引用实际channel、当前established_source、领袖成员/任职来源和真实population_scope；institution可为空（cell）或为实际合作渠道的机构，不强制存在官方代表。缺能力/来源是接入错误；有能力而当前渠道失效是正常不成立，不能用无来源true或唯一EVENT09许可混淆二者。

渠道记录kind=cult_contact_route，changes为{issuer,version,route_id,cult,domain,operator,via,origin,material,recipient}；cell的material/recipient为空，合作端点固定真实材料ID和接收人。route_id只取cult_spread_routes.csv，via为本地cult槽或合作者实际机构，origin为真实成团源或EVENT09A结果；parents含实际成员/关系/通路依据。Cults与Events只生产各自渠道，受管理当前资格生产者再给economy_qualification的basis={channel,established,leader,receipt}；cell的receipt为空，合作资格须指向同一channel/material/recipient的真实material_received。版本为本次schema2且绑定CSV内容；Cults在真实成团、继任等变化暂存后即原子生产当前cell，Events在同一09A事务内先记录真实合作结果，再暂存固定合作渠道（不反向引用未来回执），再实际接收材料；只有最后派生可用资格时才同时核渠道与接收回执，不能把生产拖到玩家预览。普通经济预览不mint渠道或资格。同团多条cell/合作渠道彼此独立；propagation|cult只是当前结论单头，不能让一条失效合作覆盖仍可用cell。正式事务在相关变化暂存后检查当前有效渠道索引，按稳定route_id、origin排序取第一条有效来源并更新单头，预览在只读副本做同一选择。坏头须能续查有效来源，不倒扫完整H；合作失效不撤销cell，也不要求重新购买09A。所有实际对象即时重查，原institution字段不作为官方允许。既有封锁只有引用具体真实渠道且有实际效果来源才适用，察觉档位或某机构表态不自动封住全部秘密路线。当前六类抵抗没有通用封路效果，不增加此新行动。

锚点供奉除上游机构条件成立外，仍须实查固定序号对应的维持污染门槛、当地教团人数和凝聚、合格护持者、原绑定圣物、机构与媒介的当前状态。缺失结构、被毁、需要重新绑定或更换了绑定对象的锚点不能仅靠付款恢复。原结构和绑定完整、只是停供或临时失去条件的休眠锚点，全部条件恢复且本轮实际支付后才可恢复有效。经济承担费用、拒付和支付记录；完整锚点资格与创建验收仍归 `TASK-ANCHORS`，本轮不据此提前完成 `ACC-ANCHOR-PAY`。

### 11.2 当轮信众资格与人口守恒

本轮阶段一开始、任何本轮到期人口变化执行前，记录各域当时的无名信众数量作为当轮收入资格的起点，并记录当时已经成立的教团身份。随后轮初清洗、迁移以及其他阶段的变化均走同一人口入口；不能在这些变化之后重新拍一张照片，把本轮刚迁入的人算成轮初居民。

每域同时追踪当前无名信众总数与其中仍具当轮收入资格的数量，后者只是前者的子集，不是第二份人口。规则如下：

- 招募、神迹转化、跨域迁入等新增信众增加实际人数，但当轮收入资格不增加。离开后同轮返回、脱教后同轮重新加入也不恢复资格。
- 无名信众死亡、脱教、迁出或提名为具名人物时，人口变动与资格扣减在同一事务完成。没有指定真实子群的聚合变化，先扣轮初合资格部分，再扣本轮新增部分；此顺序固定，不由调用顺序或玩家界面排序选择。
- 迁移在源域扣原群体，在目的域记为本轮迁入；源域不继续收取已迁出者收入，目的域不当轮接着收。跨域总活人保持不变，目的域容量必须事先满足。
- 提名从无名信众扣一并增加同一域具名活人，整体人口不变；从非信众提名只扣非信众。具名人物死亡或改信不再扣增无名信众；脱教返回非信众，死亡才减少总活人。
- 每次变动保留来源及两类实际变化。任何时点都须满足“收入资格不大于当前无名信众数”及“无名非信众 + 无名信众 + 具名活人 = 当地活人人口”。不允许以 `min(轮初人数, 轮末人数)` 重建资格：旧信众损失后补入同数新人，收入资格仍须下降。

本轮新成立或覆灭后重建的教团本轮收入为零，不能继承先前覆灭对象的当轮资格；沿用历史身份不等于沿用收入窗口，必须保留可核对的最近成立回合与来源。原教团只是休眠而未覆灭时，合法恢复不算新成立；收入入口已可运作的，可按本轮剩余资格收取收入，但不补发休眠期间过去回合的供奉。下一轮重新按真实存续状态登记。经济只消费带来源的成立事实，测试准备已有对象不等于本轮已实现自然建团。

### 11.3 计划、付款与缺资

每团默认守持，已有合法策略可沿用。计划调整本身不收费、不投骰；阶段三提交时就核对策略枚举、所属教团、锚点身份、重复顺序和拒付项，错误输入不得覆盖原计划，不能直到阶段四锁定后才发现坏计划而卡死回合。阶段结束时冻结的是已通过校验的计划。

多个教团的传教费用按稳定教团 ID 顺序尝试支付，之后才处理锚点供奉。锚点先依玩家明确优先序，未列出的现有对象按稳定 ID 补在末尾；明确拒付项始终跳过。省略一个锚点不等于拒付，重新排列展示不改变支付顺序。新出现对象按同样的确定规则补入，完整重复 ID 或未知 ID 不作为可忽略输入。

传教须教团可运作、至少一条当前合法的cell/合作来源资格成立、快照中本域无名非信众池仍有余量；不要求蓝本强化媒介或任何机构认可事件。资格明确不成立、无可招募人口或现有信仰不够时，本轮执行策略转守持，列明原因，不收费、不招募、不产生传教的察觉增量；保存的策略意向可以留待下一轮重查。人数不足以招满但仍有合法对象时，按原费用执行，招募量受实际余量限制，并在预览显示实际值。

预付只改变本轮真实费用、支付资格和拒付造成的锚点状态，不提前执行招募、自然流失或策略察觉变化。无资格锚点不收正常供奉；合法付款后才在同轮遭遇已预告破坏的，费用不返还。供奉不能预支阶段五收入，不能部分付款却取得完整效果。拒付或不足使锚点在实际供奉结算时休眠；修改计划时不提前撤销上一轮仍有效的贡献。

### 11.4 共同快照中的经营变化

经济、人物和文明在阶段四读取**预付及其即时资格变化完成后的同一个快照**。经济先形成变化意图，人物与机构也先完成候选选择，再统一合并。经济不能先把招募人数、察觉或新事实写入世界，让稍后选择的 NPC 或抵抗计划获得本批额外信息；经济也不能反过来读取本批刚增长的领袖属性提高招募量。

招募按快照中的领袖影响和可接触非信众余量计算。自然流失使用快照中的无名信众数及凝聚，加上该教团持久保存的小数余量后取整数，未满一人的部分继续保留。策略切换、换领袖、休眠、存取档不清空余量；已覆灭期间不继续累积，沿原身份恢复也不凭空抹去既有余量。流失返回本域非信众池，不改变总活人。

本批新招募不进入本批自然流失基数，本批自然流失释放的非信众也不反过来供本批招募再次消费。先从共同快照对应的原群体扣除合法流失，再合入本批新增；不得靠先加后减掩盖超额扣人或把新人成为旧人的替身。

策略、人物及文明对同一数值的独立增减相加后统一裁界，不能每个系统先裁一次再把偏差带给下一个系统。实际传教增长带来表中察觉增量及本轮新增暴露；该标志与人物本批的公开解释一起决定是否适用“本轮无新增暴露”的自然察觉衰减，但不反向重选已经基于共同快照确定的机构计划。传教的察觉增量不自动授权所有机构知道精确领袖或获得同一证据；具名见证及机构知情只能来自实际传播对象和有来源的见证，经济不得批量补给全域人物或机构。敛藏只施加本策略的察觉增量，不撤销其他暴露、证据或既存抵抗。

批次落地后重查教团与锚点资格、当前苏醒、历史峰值与信仰容量。经营导致人数或凝聚不再满足维持条件时，已付供奉不能豁免失效；后续人物和文明行为只在下一次候选选择时读取本批新状态。阶段四任一接入失败时，费用、人口资格、流失余量、人物/文明结果与随机状态一起回滚，之前已完成的玩家行动仍保留。

### 11.5 收入与预览

“轮末仍存续”在收入公式中指阶段五收入入口的状态，即阶段四全部变化已合并、阶段五期限后果尚未执行的时点。供奉使用此时仍可运作且非本轮成立的教团、当前凝聚与剩余合资格无名信众，按第 4 节公式计算。随后到期期限改变人物或教团时，不追扣已经合法入库的收入；其影响继续进入当前终局与下一轮资格。不得为了收钱提前执行期限，或为凑公式另改六阶段顺序。

敛藏系数在最终一次向下取整之前作用，不能先把正常收入取整再折半。容量使用阶段四结束后的真实历史峰值；按稳定教团 ID 逐笔登记应收、实际入库、散失和计算来源。收入资格、人口流水、费用、流失余量及计划均须随同世界和回合存档，不得在恢复时重新赠送本轮额度。

预览是对当前世界和待锁定计划的只读计算，至少说明各团拟执行策略、实际可招募人数、自然流失及余量、付款顺序、当前资金不足或资格不足原因、锚点预计付款/休眠、收入基数与容量。已知费用与可确定后果使用和正式结算相同的规则；还依赖世界演化或已预告破坏的结果明确标注条件，不把预计收入当作可立即支出的资金。预览、重复打开和取消不得改变信仰、人口、资格、余量、事实、计划或随机流。

### 11.6 本轮可否证场景与范围

- 轮初信众损失后再补入同数新信众，总数回到原值但本轮收入资格仍减少；提名、轮初/行动中跨域迁移、迁出后返回及自然流失均验证同一口径。
- 当轮成立的教团收入为零；领袖失能、无领袖或覆灭时不收费传教、不获得敛藏效果、不产供奉；不是因为少接了参与能力而得到伪造的“零”。
- 不足资金时先按稳定顺序尝试传教，再依锚点优先序供奉；无传播资格或没有非信众的团不收费。调换字典或展示顺序结果不变，明确拒付能改变结果并留原因。
- 同一共同快照下，传教的新增暴露不会让机构当轮借新察觉跨档选择抵抗；同轮相反察觉变化相加后一次裁界。新招募不当轮领收入，也不进入本批流失基数。
- 从 CSV 取真实策略费用、招募、流失、供奉和收入公式，验证小数余量跨轮、敛藏最后取整、容量散失及全部人口守恒；测试不得手填待验证的正式结果。
- 重复预览和坏计划不改变会话；阶段四中途失败后全部回滚，阶段五重试不重复收入，保存续接保持人口资格与小数余量。

验证应披露已有教团/锚点、秘密渠道及实际依托条件的上游场景准备。证据只支持正式经济和已接入核心的结算，不将准备这些对象的测试入口冒称为完整建团、传播证明或锚定玩法；完整策略平衡、全生命周期和玩家体验继续由对应任务验证。

## 12. 分层共同结算与注意力准入

### 12.1 三种活动预算和身份容量

F（重点域）、N（绑定成员及必要退役保护）、P（临时主体）来自 [fidelity_parameters.csv](../../data/fidelity_parameters.csv)，本地辅助 L 另限制每个重点域的非 N/P 人物。全局活具名身份上限继续在 civilization_parameters；展示展开数也仍归该表。三种预算不是货币，不能消费信仰购买，也不能因为低语刷新重新发放名额。

对于每个容量集合，准入判定使用 `已分配 ∪ 未结预留 ∪ 本轮已用待释放 ∪ 本次新增需求` 的不同 ID 数与其上限比较；同一 ID 不重复收费。未知的新身份先持有不可复用的预留键，分配 ID 时原子换键。成员已占 N 时无需再占 P/L；P→N 转换须先取得 N，然后释放同一人的 P 持有，其他候选引用转向其 N 资格。所有未来分支取最大可同时成立需求，不能先投骰再临时拒绝成功。

N 的退役保护占用与绑定身份分开，见人物规则；非自愿离团不受 P 空位阻塞。先核对象/路径/规则资格，再纯预览需求与不足原因，再在事务内原子预留，最后扣费/投骰/发布事实。重复请求返回原回执；错误阶段、缺容量或缺来源不扣费不耗随机。没有登记准入策略的入口拒绝，不能默认“无需关注”。预览与正式执行调用同一需求计算，正式提交按最新版本重查。

### 12.2 阶段中的取得、保持与释放

- 阶段一先完成既有身份/期限整理和收入资格处理，再处理上轮释放申请；已占用的必要承诺先转为准确宏观待办，无法转写则保留名额及原因。成员死亡/离团的旧占用记号在此回收；不复活或补人口。
- 阶段二的主动事件分支与阶段三的行动可以原子取得重点域；成功后立刻生效并为阶段四准备人物集合。同轮取得/使用过的 F，直到下轮轮初才可回收。阶段三可提出撤关注申请，但不立即空出名额。
- 持续降临等工程持有跨轮 F 预留；结束、取消或失效后才可安排释放。后台承诺本身若可精确结算，不强迫整域一直详细；其必要个人仍按 N/P 保留。只改变 UI 展开数没有模式效果。
- 传教计划也是主动扩张；保存计划不算执行，不付费。结束行动时先按稳定教团 ID 原子确定本轮各项 F 需求和可取得名额，再进入预付。已关注域优先沿既有占用；不足的传教项明确转守持，本轮不收费、不招募、不加传教察觉，也不暗中抢走另一域关注。预览必须列出原因和排序。供奉、正常收入、自然流失、守持与敛藏可在后台继续，不占新增 F。
- 自然建团/继任在自身规定的阶段执行 N 准入，不能回开已锁定的玩家行动窗；不足时按人物规则延期。已承诺的入团结果持有预留，不能被自动行为挤掉。

### 12.3 本轮唯一责任表

阶段四先确定准入及合法预付，随后冻结同一版本的世界视图和 [simulation_responsibilities.csv](../../data/simulation_responsibilities.csv) 所规定的责任。每个 `(轮次, 对象, 职责)` 只有一个生产者：详细人物执行有限行为，文明日常在详细/后台到期生产者间择一；机构风险始终一个共同生产者；经济始终经济生产者，绝不再由概略文明发一次信仰或招募。责任分配不是共享字段的第二个写入口，效果仍交原归属结算。

人物行为、文明日常、风险选择与经济候选读取同一预付后快照；同批新证据不能让机构重选本轮抵抗。后台当轮不做日常更新，风险和到期也照常执行。机构已选计划、NPC 查证与随机候选是不同职责，不能混成重复选计划。既有身份优先、资格重查、数值合并后裁界、人口守恒和派生刷新顺序保持第 9 节约定。

阶段四所有生产者成功后才发布；某一生产者返回无权效果或最终合并违反守恒，则整阶段回滚，包括预付、模式变更、预留、索引、ID/RNG、候选及责任表。阶段三已成功的玩家行动保持。阶段五收入后仍处理危机期限；阶段六用两种模式共同的准确状态检查终局。

### 12.4 容量并非遗忘上限

活动预算限制可接纳的新工作，不能删除已经发布的义务。风险/期限按有限活对象和实际未结承诺组织索引：抵抗每域遵守既有单计划限制，祈求/互动受固定候选与主体预留约束，人物状态恢复键按同一对象/状态归并且保留来源。承诺无法由这些边界表示时，其入口须先扩充正式预算/规则并验证，不能静默追加无限队列。到期批次必须结完，不以“本轮预算用尽”推迟必付后果。

历史总长度 H 与活动预算分开：冷档案仍增长。热索引也可能随合法活身份、有效证据和真正未结承诺增大；不宣称常数内存或 O(1) 整轮。性能验收须同时报告活动域/人物/有效来源/待办规模与 H，分别测正常操作、分页回顾、普通增量保存、完整导出与读档审计。

混合游戏从 `generate_hybrid` 建立，后台不先逐人生成再删去人生；重点本地预算按表提名，开局接触沿同一候选/人口/预留协议。阶段二/三正式参与者的主动分支须给出已登记分类，实际效果树、检定全部分支、嵌套调用和未来载荷主体共同形成上界，费用和骰在预留之后。身份新键只能由所属预留认领一次；内容不得用重复键替代新增身份预算。
