TL;DR：权能必须借助具体人物、媒介和机构条件行使。统一人物属性与四档检定让准备和牺牲可理解，教团、圣物和锚点保持持续身份，不能通过重建或随机改名重复领取收益。

**实施边界（TASK-ABSTRACT-SIM）：** 规则、事务、历史索引、分段保存及受控分配下的概略生产/候选协议已接入。SIM／TURN／ECON继续验证全详细参考路径，新概略规则另有专项证据；实际玩家注意力准入、成员转换与匿名混合开局归TASK-ATTENTION，最终混合负载归TASK-FIDELITY-VERIFY。迁移顺序与接口见 [架构](../architecture.md#分层推演的正式接口与迁移边界)。


# 权能、人物、教团与圣物

## 1. 内容与规则的分工

首批十二项权能在 [powers.csv](../../data/powers.csv)，六类圣物在 [relics.csv](../../data/relics.csv)，公共参数在 [run_parameters.csv](../../data/run_parameters.csv)。它们先作为策划数据存在，后续由 Godot 读取或构建，不在代码里重新手写另一份内容。

本文件说明共同规则、资格与例外，具体条目的结果以 CSV 为准。条目中的数字是初始提案，不是自动生成器已经验证的正式平衡。

## 2. 人物共用结构

祈求人、信徒、调查者、机构领袖及事件角色均使用同一套人物概念：持久身份、所在域、社会关系、当前身份/职业、四项属性、理智、对玩家的忠诚、已知事实和持续状态。未信仰玩家者也有这些数据，不需变成信徒才成为“真实人物”。

四项属性统一取零至五：

- **意志**：承担誓约、接受神谕与面对牺牲的精神力量。
- **洞察**：理解异常、发现弱点、处理和掩藏证据的能力。
- **影响**：动员、说服、维系组织与跨域迁移的社会能力。
- **适应**：容纳异常、承载神迹与维持异质联系的能力。

一个检定只选一项主属性，不把全部属性平均成万能战力。人物可因具体经历增加属性或形成特质；一次结果必须有对应历史，不能每轮无缘由随机漂移。

**理智**零至一百，表示维持人类自我与共享现实的稳定程度。高理智有利于社会行动，却对容纳异质规律有阻力；低理智可帮助超常行动，却妨碍沟通并产生失序事件资格。按参数表，稳固区间对社会检定加成、对超常检定轻微减成；中间区间无修正；失序区间相反。零理智不自动等于死亡、背叛或变异，必须由具体后果决定。

**忠诚**零至一百，表示该人物对玩家及其解释的投入，不等于对教团同僚的关系，也不等于理智。达到信徒门槛只是这些行为的忠诚条件；任职、接收神谕或作为主动权能代理还须有正式绑定成员身份及所属资格。忠诚自动增长不自动办理入团。低忠诚允许仍有联系的潜在信徒祈求；没有资格时按钮应解释缺少哪条条件，而不是暗中换一种难度。

关系记录具体两方与原因，例如亲属、师徒、竞争者、追查者。身份与事实不被替补人物继承。人物可以死亡、失踪、拘禁或迁移；“不可执行任务”和“永久不再存在”必须区分。

### 人物生成、提名与人口口径

首批六个属性与处境蓝本见 [npc_profiles.csv](../../data/npc_profiles.csv)。蓝本提供初值，不规定每域必须硬塞六种职业：先由文明机构与关系生成合法岗位，再从满足条件的蓝本选择，可以同蓝本不同身份。没有仪式机构时不能为了凑齐表格生成祭司，没有可达往来时不能生成无来源使者。

全局活着具名上限继续由文明参数表管理；归档不会释放这个身份容量。全详细参考基线按 `initial_named_per_domain` 为每域机构和关系初始化人物。混合模式改为重点域的有限本地辅助人物、正式绑定成员与已预留的临时主体按需提名，预算只在 fidelity_parameters 定义；后台匿名在任岗位不强制生成 NPC。迁入可使一域持久身份更多，但不能复制全局活人；可逐轮推演的人数还要受活动预算限制。

无名人口在成为互动角色时才提名，且从对应无名群体扣除一人。已达全局活着具名上限时，内容只能使用现存合法人物；没有合法者就不生成该互动候选，不临时突破上限。死亡人物保留墓碑与历史，不占活人上限；新提名者不继承死者身份和奖励资格。

同一域的活人人口恒为“无名非信众 + 无名信众 + 具名活人”。文明参数中的初始人口与容纳上限是两回事：初始活人一千，容纳上限一千二百，保留迁入空间。若初始具名六，则其余九百九十四属于无名群体；具体分组依开局状态分配，不能再额外加一千背景居民。具名人物改信仰只改变忠诚与身份标签，不另增无名信众数量。把无名信众提名为具名角色时，无名信众减一；把无名非信众提名时，从非信众池减一。

迁移把同一个人物或群体从源域转入目标域，目标按文明参数中的容纳上限检查余量；不新占一个全局具名名额。死亡按对应口径减少当地活人口一次，不既扣具名者又扣无名信众；普通脱教返回非信众池而不是死亡。传教与神迹招募只能转化现存非信众，不能因为距上限尚有空位就生成新人。人口空位不自动补满，只有明确的自然补充或移民内容才能增加总活人。

<a id="npc-agency"></a>
### 正式人物推演：能力、处境与有限主动性

本段与 [npc_behaviors.csv](../../data/npc_behaviors.csv)、[simulation_parameters.csv](../../data/simulation_parameters.csv)共同定义正式规则；后者只保存本次新增推演参数，四属性范围、理智分区、忠诚门槛仍读取原 run_parameters，不复制第二套。具体初值与行为仍是可调整实施提案，机器通过仅证明本段所验规则，不是作者对数值和人物趣味性的终审。

**人物状态结构。** 除已有字段，每个具名人物保留：`status`（active / detained / missing / dead）、`institution_id` 与名义职责、`known_facts`（其实际知晓的事实 ID）、带来源的两端关系、`need_tags`（当前关切）、本轮是否已承担执行任务、各行为冷却、已处理的“行为/来源/目标”组合、各属性的学习来源及独特重大里程碑。原型的 need_tags 提供初始关切；只有明确事实/事件效果能改变关切，不能每轮重抽性格。学习来源与献祭阶位的重大里程碑是两个集合，普通日常行为不会自动增加祭品阶位。

**知情边界。** 世界已经发生某事，不代表所有 NPC 都知道。事实登记参与者、真实见证者、公开范围与受告知者；本人经历和明确传播才把事实加入 known_facts。角色不能调查未知域、安抚不相识的陌生人，也不能只因全局察觉数值高就知道具体圣物位置。关系连接只在有来源的亲属、师徒、支持、同僚或往来事实中建立；死亡后保留关系墓碑，但死者不成为活跃行为目标。

**选择时机。** 所有候选取自回合阶段四的同一演化快照，发生在计划锁定和已声明支出之后。每名纳入详细集合的 active 人物至多做表中规定的一项自主行为；本轮已经承担玩家执行任务者不再自主执行，以保留一个人的机会成本。只接受过梦境或神谕并不算执行任务，仍按主回合规则判断。人物只使用自己的精神状态和一次行动机会，不能自行花费全局信仰/低语、献祭、任命、移动圣物、迁移或替玩家完成制度承认。

先按行为 eligibility 检查对象、知情、来源、代价和冷却，再计算 `base_score + 主属性 × attribute_weight + 关切匹配奖励`。need_tags 只要有一个交集就加一次 need_bonus，不按匹配数量叠加。选分数最高者；同分按行为 ID、目标 ID、来源事实 ID 升序裁决，不消耗骰子，不受字典或卡片排列顺序影响。没有合法候选则保持静默，不生成凑数事件。

**四种自主行为。** 数量型效果为 `effect_base + floor(主属性 / effect_divisor)`；资格是明确的有限枚举，不执行 CSV 中任意表达式。

- `NPC_RECOVER` 自我整顿使用意志。本人理智低于恢复阈值且有初始困境或导致低理智的真实来源时可选，恢复本人理智，最多到恢复阈值。代价是占用自主机会和冷却；不消耗他人资源、不产生学习来源，也不凭空消除既有危机。冷却后允许继续整顿同一困境。
- `NPC_EXAMINE` 查证见闻使用洞察。人物必须有仍能运作的本地机构归属，并实际知道指向本域有效对象的暴露事实；目标只能是该事实指明的人或圣物。支付表中理智代价，向本机构增加绑定该来源与对象的查证强度。一个人对同一来源只处理一次；同一来源的不同直接见证者可以分别提供证言。不同目标的强度不相加。确认规则与正式调查计划见文明章节。
- `NPC_COMFORT` 安抚同伴使用影响。双方必须仍在同域、具有有来源的支持性关系、均达到信徒忠诚门槛；行动者实际知道目标遭遇的伤害，目标理智低于恢复阈值。行动者支付理智代价，目标恢复理智并按表增加忠诚；目标必须是所引用伤害的受害者。同一“行动者/伤害来源/目标”只处理一次。此举不替换神迹、不复活、不释放被捕者，也不取消原伤害的期限。
- `NPC_INTERPRET` 解释神迹使用适应。本人必须既知道事实、又是该神迹的实际见证者，且忠诚尚未封顶、理智能支付代价。降低本人理智、增加其忠诚；忠诚增加量来自本行为公式。若原神迹公开，此次解释还增加表中规定的察觉并留下新的真实暴露记录；私密神迹不会因内部理解自动成为公共情报。同一“人物/神迹来源”只处理一次。

成本不足时不进入候选，不以理智负数支付。冷却为一表示执行后的下一完整回合不可再次选择同一行为；行为来源未重复也不能绕过冷却。动作不重复触发本轮事件，新记录最早进入下一轮候选。不同人物在同一快照看见的同一事实可以分别回应，但不得相互使用当轮刚产生的记录连续连锁。

**合并与失效。** 同一批次先确定死亡、永久损毁、迁出和临时失能；因此失效的人物自主意图取消并记录原因，不收取尚未执行的自主成本。已经在前面阶段执行的玩家行动不因此退款。其余合法行为合并数值后统一裁限；同一目标的理智恢复总量不超过“恢复阈值减快照理智”的非负余量，再与其他有独立来源的理智增减合并，最终裁到零至一百。目标死亡优先于恢复，普通安抚不构成复活。

**成长。** 查证、安抚、解释完成后，向其对应主属性登记真实来源。每积累 simulation_parameters 指定数量的不同来源，属性增加指定值，最多为 run_parameters 的四属性上限；使用过的来源不能再次学习。同一事实换标题、重新载入或重复调用结算不增加经验。意志可由明确的危机承受/誓约事实授予学习来源，但整顿本身不刷意志。人物死亡保留已发生的学习记录，不再成长。

本版不模拟完整欲望层级、自由自然语言计划、关系全连接、出生婚姻与社会职业全生命周期。日常行为是有事实依据的有限行动集；后续增加行为须在本表和本节扩展，不允许代码凭“像人”临时加剧情。

<a id="npc-lifecycle"></a>
### 人物生命周期、岗位与人口的一致处理

`active` 可参加合格行动；`detained` 与 `missing` 暂时失去执行、见证新事实及机构行动能力，保留名义职位、关系和护持绑定，相关锚点休眠。释放或归来回到 active 后仍需正常对象资格和阶段四实际供奉才恢复锚点，不补发期间收益。人物尚且存活，不能作为死亡从人口中扣除。

死亡立即撤销所有活跃资格、任职及护持，保留墓碑与历史，按圣物生命周期处理物件，恰好从当地活人人口扣除一次。迁移沿实际通路转移原人物 ID，扣源域具名人口并增加目的域具名人口，解除旧域职位与护持；目标必须有容量，不新占全局具名名额。合法随身圣物随原持有人移动，绑定锚点的圣物不能被当作随身行李偷带走。拘禁、失踪、死亡、迁移均让尚未执行的角色绑定候选重新检查，不能让新人物继承旧人的事件。

教团继任仍按下文既有规则在下一轮轮初处理。文明机构代表空缺或暂时失能时，该机构不执行主动调查/抵抗；其余正常机构和既有世界状态照常演化。文明机构继任是机构专用事件的显式结果，不由教团任命权能或自动补位替代。合法继任候选必须为本域 active 人物、岗位条件相容、理智不低于 simulation_parameters 的候选门槛；事件可能再要求信仰资格或见证，不能被通用入口跳过。

全详细参考初始化以及重点域展开时，优先处理解释、传播、秩序三个机构的合法代表，再在预算内生成其余人物；后台匿名岗位不执行此逐人展开。npc_profiles 的 institution_roles 约束岗位；祭司还需本域存在由秘术或信仰范式支持的仪式能力，使者还需真实通路或机构往来，幸存者先有可引用的初始灾难/损失，发声者先有具体听众关系。不能为了通过字段检查而生成没有这些事实的人物。普通人物至少有表中规定数量的本地关系；仍保持稀疏图，不把所有人连成朋友。

人物结构变化必须保持“无名非信众 + 无名信众 + 具名活人 = 当地活人人口”。提名、改信、迁移、脱教、死亡是不同操作，各自只改变对应口径；资格不合法时整项拒绝且状态不变。

## 3. 统一四档检定

只有存在不确定结果的行动投骰。聆听已可达事实、合法任命、资源转移和明确的承受分支按确定性规则执行；不能为了跑团味道给每次查看信息都加失败率。

不确定行动掷一次一至一百的整数骰。当前成功率为：

`P = clamp(基础成功率 + 属性步长 × (主体主属性 − 目标难度) + 准备修正 + 理智匹配修正 − floor(屏障 / 屏障系数) − floor(察觉 / 察觉系数), 最低成功率, 最高成功率)`。

当前基线是基础五十、每点属性差十个百分点，星球/星系/宇宙目标难度一/三/五，普通检定成功率限定十至九十。所有数值来源于参数表。屏障与察觉只使用目标域值；合法的本地组织行为如任命不需要过这套侵入检定。

准备来自一次性情报、神谕与所选圣物，修正总量限制在参数表上下界；同一来源不叠加。执行前明确指出哪些准备会在尝试后消耗。未知文明的隐藏属性不能在玩家付费后再改变已展示成功率；可以显示准确的当次综合机会而暂不揭示全部文明状态，或者先要求完成取得机会所需的情报。

四个结果区间互斥且完整：

1. **深成**：骰点不大于 `floor(P / 5)`。
2. **成功**：高于深成上界且不大于 P。
3. **灾变**：骰点大于 `100 − ceil((100 − P) / 5)`。
4. **失败**：其余骰点。

例如 P 为六十时，深成为一至十二、成功十三至六十、失败六十一至九十二、灾变九十三至一百。不能只展示“成功六成”却隐藏灾变占比。深成不自动免除条目代价，灾变也不自动等于直接判死。

入梦、赐予的主体是承受神意的人；谕言的主体是接收并理解神意的人；献祭的主体是被献祭者，意志代表其可承载的仪式意义，并非“是否逃脱”。执行类权能的主体是所选代理。降临使用预先指定的宇宙锚点护持者，不临时挑全世界最高属性替骰。

## 4. 祈求回应的共通结算

每条祈求在 [prayers.csv](../../data/prayers.csv)定义对象条件与基础收益/代价。本版每轮最多回应一条。浅触支付低语一、信仰零，深干预支付低语二、信仰四；特殊对象条件仍需满足，免费浅触不代表可以无视传播通路。

主体为祈求人或选定的合法代理，使用其适应属性作超常检定；若某条诉求明确改为社会行动，则使用影响并同时采用社会理智修正，不能只替换有利的一半。默认使用目标域难度与屏障、察觉修正。

基础数量正收益在深成时乘深成倍率并向下取整，原本大于零的结果至少保留一；成功取原值。此缩放只适用于可计数的直接数量变化，不复制人物、圣物、证据或制度承认。唯一物件仍是一件，关系事实仍是一条。

浅触/深干预成功时额外产生公共污染基础收益；若具体内容已明确写了污染增加，则使用条目值，不再叠加公共值。失败与灾变没有成功正收益，也不生成只有成功才成立的事实。所有已提示的始终代价仍执行；灾变在此基础上再降低主体理智并增加本域察觉，具体公共数值来自参数表。

某些代价须以成功的事实为前提，例如“公开先知失去匿名”只在确实成为公开先知后才成立；不能在失败时凭空生成本来没有成立的身份。内容必须标清“始终成本”与“成功后的代价”，不能将其中一类静默当成另一类。

PRAYER_08 的忠诚四十/七十表示最低值：成功时设为 `max(现有忠诚, 所选下限)`，不把原本更忠诚者降回门槛。受益对象若来自无名群体，需先迁移到具名身份口径，不复制人口。

“不回应”不投骰、不消费本轮回应次数；一旦真正回应，无论哪档结果都消费该次数。具体到期后果由事件系统管理。

## 5. 教团的自然形成与存续

每域本版最多一个属于玩家的教团，内部可以有分歧与人物关系，但不另开第二套玩家势力经营。

轮末同时满足以下条件、且能为首领完成成员准入时自发形成：本域至少一名达到忠诚门槛的活人物、本域累计实际支付的信仰达到成立门槛、无名追随者达到人数门槛。当前基线分别为忠诚四十、累计支付八、追随者六。累计支付只是从全局信仰支出中按目标域记账，不是另一种货币，也不再次收费；圣物转化得到的信仰只有实际花到该域才计入。

初代领袖在合格且能完成成员准入的人物中按影响、忠诚、持久身份依次选取，形成时给出由谁组织起来的说明。已有绑定者不重复占名额；无人可准入时仅保留成立条件，下轮重查，不生成欠账式“已经成立”。首任自动成立不支付任命费用；玩家之后可以使用任命调整。初始凝聚使用参数表，教团从下一轮开始产供奉。

教团维护无名信众、凝聚、领袖、锚点护持者与成立/覆灭历史。领袖可以兼任一个锚点的护持者，但同一人物不能护持多个锚点，也不能跨域任职。护持是持续身份，占有资格而不自动消耗其每轮执行机会；降临等主动任务仍占执行机会。

领袖死亡或离开时，立即停止其贡献并在下一次轮初尝试继任：在本域现存合格且能完成成员准入的信徒中按同一规则选择继任者并支付凝聚损失；没有合格者则教团休眠，不产收入、不传教，现有锚点也无法通过正常教团条件维持。玩家可以在限期内招募或任命新领袖；连续休眠达到期限后覆灭。休眠不是物理删除，人物与历史仍存在。

无名信众归零或凝聚归零时，教团当轮覆灭；人物按具体状态留存、逃散或被捕，不统一自动删除。恢复同域教团沿用其历史来源，重新满足成立条件，没有“首次建立”重复奖励。教团成立和覆灭本身都不自动掉落圣物。

凝聚由明确的神迹、信徒关系、任命、献祭、失序与事件改变。不要用每轮无来源漂移填充活跃感。收入和自然流失见经济规则。

## 6. 权能体系与解锁

权能按当前苏醒阈值开放。达到过阈值后说明保留可读，但当前苏醒跌回阈值以下时不能再次施放高阶权能；既有普通事实与属性改变不会倒放。进行中的降临按其持续条件另行中断。

十二项权能构成五组行为：

- 接触与准备：聆听、入梦、谕言。
- 塑造与组织：赐予、任命。
- 牺牲与转化：献祭。
- 进入与传播：穿隙、播种、掩迹、迁引。
- 扎根与终局：锚定、降临。

“开放”只表示可以尝试，仍须对象、媒介、资源与具体局势全部合法。锚定在初始苏醒阶段即开放，以免苏醒必须来自锚点却先要求高苏醒才能建锚；其真正门槛是污染、机构条件、组织、护持者与圣物。

每张权能记录本次目标、所选模式、所用媒介、费用、随机结果与后果。冷却针对该权能和主目标身份；冷却为一表示执行后的下一完整回合不能再次对同一目标使用。改名、转职或移动界面位置不刷新冷却。

## 7. 献祭的完整收益规则

献祭先确定目标与三种模式之一，再支付不可退代价：目标永久死亡、解除任职与护持、教团凝聚降低、本域察觉提高。不得先投骰，看到失败再取消献祭。

目标必须在教团中存在达到最短轮数，不能当轮从祈求生成、任命后立即出售。人物阶位是 `min(阶位上限, 1 + floor(独特里程碑数 / 每阶里程碑数))`；里程碑来自已记录的独特重大经历，不把重复入梦或同一事件反复触发计数。

- **信仰模式**：成功给基础收益加每阶收益；深成使用深成基础与每阶收益；失败得到失败固定收益；灾变无收益并增加创伤。
- **洞见模式**：只允许带有尚未消耗的独特“见证”标签者。成功或深成给对应洞见，受全局上限限制；失败没有洞见；灾变增加创伤。人物死亡使该见证来源永久消费，不因重建教团重置。
- **愈合模式**：成功、深成、失败分别减少参数表规定的创伤，最低归零；灾变反增创伤。

三种模式只能取一种，不能将同一个人同时兑换信仰、洞见与治疗。祭品身份与历史决定其价值，但没有一种特殊人物必然值得牺牲；其现有关系、能力与护持职责必须同时显示。

## 8. 圣物的生命周期

圣物来自具体祈求、文明争夺、历史回调或特定后果，按照来源事实唯一发放。首批主来源是机构首次满足蓝本制度承认条件后出现的遗物机会：可以付费回收，也可以公开换即期资源并永久放弃物件；取得媒介不要求先拥有锚点。费用与期限由 [event_parameters.csv](../../data/event_parameters.csv)管理，具体规则见 [叙事内容手册](../content/narrative-catalog.md)。因此首锚所需圣物有独立于锚点的自然获取路径。

CSV 是六类标杆；每件实际圣物另有唯一实例身份。同类型可以在不同合法来源出现，但同一来源不能通过重放事件重复领取。每域三个机构、十二个域的此类主来源至多三十六次，不代表只有六个实例，也不保证每局都能取得所有机会。

一件圣物同时只能处于一处：本域保管、具名人物携带、绑定机构锚点、敌方扣押、封存或已消耗。每人至多携带一件；没有在场合法运输通路时，不能把全局库存直接当远程传送。

携带效果只作用于表中所述的一种准备。使用时同时支付携带代价，准备加成计入总修正上限。绑定锚点后不再作为可选随身准备，不能用一件圣物同时撑三个机构。选择解绑会立即使对应锚点休眠，操作前说明当前苏醒损失。

圣物持有人死亡时，先依死亡事件规则决定被谁取得：敌方俘获则归执行机构；普通死亡且本域教团存续则进入该团保管；否则留在原地成为需要回收的对象。死亡不默认销毁，也不自动回到全局背包。

玩家可用一次圣物操作永久解离一件可控制且未绑定的圣物；普通操作消耗一点低语，四种互斥方向为：

- 化为表中信仰，受储量上限限制。
- 化为表中洞见，受洞见上限限制；来源身份记入已消费记录。
- 向本域展示后转为表中无名信众，受非信众余量限制；不凭空创造人口。
- 释放为表中低语，使用本方向不先扣一点低语，直接得到净增加值，但不超过本轮轮初已经确定的低语预算（初始阶段是三，不因硬上限为六就补到六），并承担表中察觉代价。它不刷新人物执行机会，且永久损失圣物，因此不是可循环补蓝。

解离在容量已满时应显示实际净收益；玩家可以放弃，不以“自动找用途”替其销毁物件。永久解离不投骰；风险来自放弃持续用途和具体暴露，而非再额外套一个未声明损失。

## 9. 边界与验证要求

- 同一身份的死亡、迁移、任职、携带与护持变更必须先改事实再判断后续资格。
- 同一圣物不同时装备、绑定和消耗；同一信徒不跨域同时执行任务。
- 检定四档概率覆盖一至一百，没有重叠和空洞；显示概率与实际计算相同。
- 准备不无限叠加，查看和取消不改变随机结果；每个结果的始终代价均执行一次。
- 理智不是单纯越低越强：社会与超常用途、事件后果共同约束，不能只给低理智加成而漏掉代价。
- 教团自然成立不重复扣款，自动继任不复制历史，覆灭不自动掉圣物。
- 在同一事实与同一世界快照下只改变一项属性，候选评分或对应效果按公式改变；不得所有属性最终只合成同一个万能数值。
- 未知事实不产生调查，私密神迹不自动公开；本轮新事实不被自主动作递归消费。
- 同一来源重复处理、保存重载后重试、改变角色遍历顺序，均不得重复发放成长或改变结算。
- 拘禁/失踪不扣活人口，死亡恰好扣一次，迁移总活人数守恒；恢复人物不自动恢复锚点贡献。
- 条目全部覆盖不等于系统好玩。人物是否值得记住、献祭是否产生真实取舍、权能是否有通用最优序列，都仍需后续完整系统中的实际验证。

## 10. 身份、成员和详细推演集合

以下字段分开保存：持久 `person_id`、生命/所在地/岗位、信仰忠诚、`bound_member`（与邪神的正式成员联系，可在教团成立前存在）、可空的 `cult_id`、详细激活理由。低忠诚可能使任职或行动失去资格，但不会自动抹掉成员记录；正式离团是有来源的身份效果。教团覆灭也不自动删除仍存续的绑定关系。无名信众一直是聚合群体，不逐人占成员名额。

详细人物集合为三个去重集合的并集：全局正式绑定成员及退役保护主体 N、尚未结清互动的临时主体 P、每个重点域的本地辅助人物 L。成员不论所在域是否重点都运行适格的正式属性/见闻/成长行为；受伤、拘禁、失联者占 N 但按状态暂停相应行动。P 由固定候选或承诺引用持有，不因换页面释放。L 优先保留具名在任机构代表，其后按当前有效关联职责和稳定 ID 选择；不是每轮重新随机造人。L 中的人被 P 固定或成为 N 时，从 L 去重，不能重复行动。

未在并集内的具名非成员保留身份、四属性、理智忠诚、岗位及有来源的关系/知识索引；不逐轮执行四种自主行为，不随机生成成长。明确的既有期限、人口/岗位变化、事件后果和合法宏观效果仍准确作用于他们。恢复详细时从当前态继续，不补写漏掉的人生，不清空成长消费键，不递归展开亲友。亲友只是引用；要参与本次具体互动才按准入取得 P 或本地 L。详细集合的理论人数上界为 `N_limit + P_limit + F_limit × L_limit`，失能人数包含其中，实际去重后可更少。

**准入时点。** PRAYER_08 的两种回应都表达正式献身，须在付费和投骰前为结果可能新增的成员预留 N；失败释放未用预留，成功把 P→N 原子转换。其他忠诚增长仅更新数值。建团、任命、护持绑定及自动继任同样走成员准入；权能若已要求绑定成员，就不能先以潜在信徒执行再补手续。自愿加入申请仅可对已有可达、活着且忠诚合格、有当前献身意愿事实的人办理，不是凭忠诚免费远程招募按钮。

无 N 容量时拒绝主动入团分支并解释缺少名额；自动建团/继任只在尚未承诺前延期，不扣凝聚或费用，不吞已承诺结果。承诺未来入团须持有指定人物的 N 预留，不能只写“到时再检查”。任一随机分支需要的最大新增身份/临时/成员/重点容量均在抽取前预留，成功后不会因容量不足删奖励。已归档活人仍占全局活身份上限，不能通过离团与回收反复造新人。

成员离团、死亡或 P 互动终止后，先结清其依赖、撤销或转写可准确表示的待办；成员解除不抹掉死者/离团者的历史。已使用的活动名额本轮保留占用记号，到下轮轮初再回收，防止同轮轮流招入、献祭、换人绕过活动规模。失败且没有发布任何结果的事务预留可立即撤销；与已提交行动不得混淆。

**退役保护。** 活成员离团（含 EVENT_12 默认后果）立即解除 `bound_member/cult_id` 和任职资格，不能为保名额拖延这个后果。若仍被另一未结互动/见证承诺引用且不能安全转宏观，原 N 占用转为 `retired_hold`，沿原预算保留必要详细状态，不要求满额的 P 额外接纳；它仍占 N 容量但不享有成员权限。引用结清后释放，或在轮初有 P 空位时原子 N→P；不能先释放 N 再发现转不进去。故 N/P 双满时默认离团仍可结算，其他招募也不能偷走这份保留。死亡则按真实身份取消失效分支并保留历史，不拿活人离团类推为死亡。
