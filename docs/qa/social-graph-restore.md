# TASK-SOCIAL-GRAPH-RESTORE — Social Graph Birth Provenance and Strong Restore Audit

本轮补齐人物出生来源和关系历史的保存审核。此前存在两类系统缺口：人物与关系快照可以被一起改写，内部副本仍能互相对上；人物的关系记录只检查“有正确的一条”，不能充分发现多写、重复或漏写。现在分别按实际出生配方和实际关系事实核对，不再只让两份副本互证。

实际处理：

- 正式生成和完整恢复共用同一出生配方，保留原种子、抽样顺序和人数分配。八份旧版实际开局样本逐值比较，人物和文明组合保持；原128个控制图仍为128个分支、跨机构及度数差异，117个含三角。这些是有限样本，不是自然新局可玩性证明。
- 首次展开必须对应真实关注准入、原操作及目标，并在完整回合保存中核对实际提交范围。“保存计划”或“释放关注”不能借一份位置标记伪造展开。准入的记录排序不改变真正展开顺序，旧策略的默认值按当时结果保存，不拿后来策略倒推过去。
- 完整恢复从每条关系事实推导两端应有的历史记录，核对缺失、多余、重复、反向、错对象和错来源；撤销后的历史也要保留。普通提交仅检查本次新增事实与变化条目，拒绝改写旧来源或漏掉新关系的一端，不每次扫描全部历史。
- World独立保存只核出生配方、局部来源链和关系历史；完整Turn保存另外核真实回执、原请求及授权。反例明确展示：局部链可以被World接受，但错误提交位置仍被Turn拒绝并保留当前局，两个层次没有混称。

最终166项行为检查与5项运行门槛全部通过。其中初始化原50项行为要求、关系生命周期51项在新目录实际回归，另有65项本轮检查。原工具和报告逐字保持；新目录明确适配了Graph持久格式审核、先前两处业务来源前提，以及首次关注/经营测试中改用合法提名入口的前提，不称原函数完全未变。

首轮正式运行有七项测试装配失败：旧前提调用私有提名函数，错误声称是首次展开；另有测试回调强引用造成退出资源泄漏。只在新工具中改用实际身份预留与World.submit合法提名，并清理回调，保留原行为要求；没有放宽出生校验或修改游戏代码。第二轮全部通过，首轮、各次加载检查和所有输入原档保留。

同一人物对实际累积0、16、64段已撤销关系后，再创建关系和改变状态：无历史展开、重建或复制，输出计数均288；相应树读取保持在所列有限包络内。另有0、256、2048份冷事实样本。这是有限工作量检查，不是任意规模的性能证明。

开局bootstrap的边界仍明确：真实Turn外层因Power系统未安装而拒绝并回滚；测试观察其实际产生的未提交世界片段，对真实出生链做World局部保存正负审核，没有造假系统或手写最终开局事实，也没有宣称正式开局成功。

父级组合检查采用明示测试驱动，将组件命令路由到实际关系处理者；其余提交、事务、回执、校验和恢复均为真实Turn。首次关注→关系变化→精确撤销→新关系→保存恢复→再关注/迁移→再次恢复通过。它证明组件组合和连续回执，不证明完整祈求、事件或权能业务已经全部执行。

当前格式为World4、Turn3、持久图2；关系事实及生成模型仍1。旧格式明确拒绝，不补造过去。95份来源、138份当次产物指纹通过核对；47份原CSV与全部旧QA/工具保持，原数值和选边规则未调。
