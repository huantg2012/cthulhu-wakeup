# 实施保障验收

日期：2026-10-25。范围是本游戏的实施追踪与制作人工作台；它不替代正式玩法、平衡或体验验收。

## 追踪结构

关键行为连接唯一规则来源、游戏能力与关系、作者决策、结算约定、开发责任和可观察验收。任务依赖无环；共享事实在责任登记中只有一个归属；所有能力至少有关键行为覆盖。来源或检查缺失时保留未验证，绑定文件变化时报告过期，正式任务的完成声明必须有对应交付与当前证据。

工作台按三层显示：规则登记、任务接入、验收事实。报告来源匹配与测试通过分别显示，讨论状态不提升正式状态。实际规则的行为正确性由 Godot 检查证明，静态责任登记本身不能证明代码不存在越权写入。

## 持续限制

- 自然语言要求可能仍有未登记分支，变更收尾必须做语义覆盖审查。
- 报告绑定范围内任一来源改变会保守地使相关证据过期；不尝试猜测一行改动一定无影响。
- 本地工作台单仓库保存，不是在线多人协同或自动 AI 调度。
- 没有新增短体验前置关卡。规则测试随正式实施进行；机器结果不推定乐趣、叙事或美术通过。
