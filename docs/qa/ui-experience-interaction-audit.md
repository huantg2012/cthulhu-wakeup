# 可玩原型交互专项自查 · 2026-11-02

本报告针对 Godot 原生体验原型。基线为 `621bb08`，主要文件是 `src/presentation/experience_root.gd`、`experience_actions.gd`、`experience_views.gd`，本轮新增语义与实际结果呈现 helper。前批已修正确定的 UI 偏差，原 T3 存档进入 T4 已有 1 项真实合法回应。当前扩展获得 **32 项原生短流程、15 项显式主体夹具、156 项语义/结果呈现断言及 6 张最终截图**；在下述已查范围内未发现剩余确定阻断，不等于全部成熟路线或制作人验收通过。I11 的前批 43 条供给证据限于原档、三个新局行动窗口和保存恢复；极端无合法来源时明确拒绝并回滚，未证明所有成熟局均能继续。本 QA 做独立静态、日志与截图复核，没有自行重跑测试。分批范围与历史失败均保留在下文。

最高依据为制作人本轮八组试玩反馈：原型允许粗糙视觉，交互逻辑必须能进入正式设计。当前 [交互规格](../specs/ui-interaction.md#当前可玩结构原型dec-039)、[交接](../../switch.md) 提供既有边界；本轮反馈覆盖旧版“返回原行动”堆栈和轮间展示等要求。旧 [HTML 审查](ui-experience-review.md) 仅作为同类问题线索，不作原生实现的验证证据。没有读取或使用已禁用的 in-game-ux 及其副本、附属经验。

## 审查依据与推导

- 制作人认可的 A「回声之海」、B「活体异典」、C「降视之窗」继续全部保留。沿用其名称定位、相关主体可对照、当前处境与后果关联的共同原则；双页只服务实际关联，不要求每个页面永久空出一半。
- [Microsoft Xbox XAG 112：UI navigation](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112) 要求导航一致、反复出现的组件保持相对顺序、子页能方便返回初始界面。**本项目推导**：主区采用总览加一个子页，关联查看平级替换，主区不积累浏览历史；“两层”来自制作人，不是微软规定。
- [Microsoft Xbox XAG 114：UI context](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/114) 要求玩家理解所在位置、控件用途与预期结果，输入说明在当前位置可理解，功能相同的控件命名一致。**本项目推导**：首屏先讲能否行动、对象、代价与关键后果；算法/来源凭据/完整预算字典不能直接替代玩家表达。

以上两份游戏行业资料于本轮实际打开阅读。仅使用导航与理解原则，不把其完整无障碍、控制器、平台或视觉要求扩成此批任务。

## 初次审查时的待核问题（历史）

- T3→T4 祈求为零由制作人实测提出。此静态 UI 审查不将其先归因成投影问题；生成/调度/恢复链须由正式 Session 复现，状态仍为待根因核实。
- `between` 当前由 root 的自动推进循环刻意排除，代码把它展示成需再按一次继续的阶段。是否存在必要规则选择须由回合实现确认；不能仅删除文字而保留不明的停顿。
- 表单每次选择后重建整个 workbench，尚未看到恢复具体输入焦点的逻辑。键盘焦点丢失目前为风险，需在改后实际操作验证，不算已复现故障。
- 旧 spec 中“开启新行动后返回原稿”的要求与本轮明确拒绝行为堆栈冲突。应由当前交互 spec 原地更新：普通查看保留草稿；显式切换行动替换当前行动；不要以旧 spec 判本轮浅层导航不合格。

## 最终 UI 复核与证据边界

本次独立 QA 再次读取了当前 `open_action`、祈求身份呈现与确认、事件入口、`focus_later`、PR08 效果呈现，读取主会话执行的 `.godot/ui-interaction-smoke.log`、最新 [25 项结果](../game-state/ui-experience-native-checks.json)、[43 条供给结果](../game-state/ui-prayer-supply-checks.json) 及 [供给专项报告](ui-experience-prayer-supply.md)。本 QA 没有自行重跑；供给实现另有独立审查，本报告复核其交付证据与 UI 接线边界。

- **N01 已静态修复**：跨行动草稿缓存全部删除。新行动仅从当前主体上下文与显式输入建立；普通查看保持当前唯一草稿，关闭不恢复旧行为。
- **N02 已静态修复，已有对应运行断言**：行动区持续显示具体祈求名、求告者及世界；不可逆确认也保留同一身份。新增“关联查看后当前祈求仍显示请求身份”检查通过。
- **N03 已静态修复**：顶部事件状态改为文本提醒；右下阶段按钮是恢复事件窗口的唯一操作入口。
- **N04 已修复**：PR08 的必付说明直接读取正式 always delta，成功说明读取 success 的 enroll/set_min/record/delta；浅触理智 −3 与成功忠诚至少 40 分开，深应理智 −15/察觉 +10 与成功忠诚至少 70 分开。未为匹配界面修改 CSV 或玩法效果。最终短流程新增这项渲染语义断言通过，浅触/深应截图也已核对。
