# Axiom, Network, and Manifestation Routes

本批交付六条路线的**设计与静态验收**，没有接入游戏。三张新 CSV 都是 `design_only`；原有安装阻塞仍在。任务、实施分工与展示台同步属于本批交付，完整路线父任务仍须等待另外两组。

法则型文明 CIV07 原来需要第二节点的独立材料，却没有可靠取得它的路。现在设计了两种不同做法：

- **双节点复核：** 一位现有成员实际观察并保留例外，另一连通节点的不同成员对同一现象重新观察，成功后保留自己的记录。转交第一份记录只能提供定位，不能充当第二次观察。自然祈求也补上“实际收到定位材料、具体记录者读取、重新观察、独立求告”的生产责任。
- **单节点持续使用：** 同一节点在两个不同回合实际利用这个例外完成档案操作，成功形成当地持续依赖。它不需要第二机构或通信；代价是更多付费尝试、等待与单一保管者风险。不能复制记录、改回合号或补过去的实践。

网络型文明 CIV05 也有两种材料来源：两个节点的不同成员分别真实受梦，留下各自独立神迹；或者两端实际执行一次异常往返应答，形成双方现在使用的依赖。后者不冒称两份独立证言，也不增加忠诚；两人都承担行动、理智和暴露成本。两路共同保留真实通信与两端承载。

终局原稿曾把“已有资格直接开始”和“先恢复创伤再开始”算作两路，独立 QA 将其退回。修订后，直接开始保留为共同入口，两条计数路线分别产生真实的苏醒变化：

- 恢复一座真实停供、材料和绑定仍完整的**额外非仪式锚点**，实际付款、资格重查后恢复贡献。
- 通过原有敛息恢复真实创伤，同时明确拒付那座额外锚，避免默认供奉混入结果。

二者使用同一个静态起点：苏醒 87、真实创伤 6，两座仪式锚已有效；单独恢复星球锚贡献 4 可到 91，单独恢复创伤 3 可到 90。计算引用原 CSV；十位护持者的必要容量检查不等于已经构造合法游戏存档。保存供奉计划不算恢复，付款的 `paid_pending_final_check` 也不算；必须经过实际经济结算和当前资格重查，最早下一轮行动时再判断降临。原门槛、两座仪式锚、费用、三轮持续、最终检定和失败风险均保留。

六条设计路线都提供安装后可用的主动步骤。表中的 `direct_action,0` 只表示**当前输入齐备的单步不用等待随机卡片或展示队列**，不表示新局零轮完成，也不保证检定成功。真实成员、材料、关注、费用和行动机会仍须具备；自然来源的完整交付上界尚未证明。新操作不补人物、旧关系、旧知识或独立见证。

五个新增操作的执行、费用、封闭输入、准备目标、知识、材料与保存责任已明确；观测内核和操作头由不同的唯一入口管理。Progression Route Operations 按共享核心、法则试验、网络试验、独立界面设计及界面接线五批落实。自然源、材料判定、锚点生命周期、机会协调、完整存档与自然验证各有实际下游任务，代码仍等待 Critical Progression Routes and Opportunity Guarantees 的完整设计。

独立静态审查核对了六条路线的因果差异、禁一路后的替代、知识与实际保管、费用和阶段、原共同条件与实施归属。机器检查只核正式表、实际任务引用及上述代数/必要预算；不执行生产者、支付、材料、存档或自然新局。完整结果见 `tools/axiom-network-routes/results.json` 和 `docs/qa/axiom-network-routes-results.json`。
