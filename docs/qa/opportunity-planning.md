# 关键进展多路径与机会保障：本轮规划交付

制作人的要求已登记为DEC-022：重要事件应有替代触发方式，游戏流程必要机会需要概率修正和兜底，不能长期只靠一次随机抽中。

本轮完成的是规划和任务同步。没有修改游戏源码或CSV，没有宣称新机制已能运行。具体路线和等待数字仍需下一项设计交付。

## 会怎样落实

1. TASK-PROGRESSION-ROUTES（下一项）：盘点首次建团、八文明扎根、终极降临的关键机会。每个目标明确共同条件及至少两条不同触发路线，包含玩家可促成方式；一条关闭后，另一条不能仍卡在同一个指定事件、人物或随机结果上。参数与理由落正式CSV。法则型文明的同一异常第二节点复核/独立求告及主动替代是必验案例，双节点是否必须是唯一扎根条件也要重新审视。
2. 原SOURCE/ANCHOR任务：实现各自的真实来源和替代路径。需要新操作时明确唯一实施任务及玩家可知入口，超预算先拆任务。
3. TASK-OPPORTUNITY-SCHEDULER：落实等待补偿、有限等待兜底和多目标公平。实际看得见且有时间行动才算机会已提供；生成原根或固定卡片还不算。重点/后台、重试、读档不能清掉等待。资格或容量不足有真实原因和合法处理，不能靠无限暂停掩盖缺口。
4. CULT-SAVE-COMPAT验证完整会话续存保留等待/阻塞原因和服务回执；SOURCE-CLOSURE逐目标关掉一路、实跑另一路；NATURAL-VERIFY分别核自然新局和受控最坏随机；STARTUP-BALANCE/BALANCE校准等待、成本和拖延套利。

每批1–3小时，完整差异设计/实现超预算则开工前拆真实task；不把所有新玩法塞进调度任务。

## 保障边界

保障合法且可行动的推进机会，保留回应成功率、资源决策和世界反制。无合法前提时，设计必须给出可促成前提的替代路径或明确的失败原因；不凭空补人、往事和材料，不延原危机、不挤已承诺候选，不直接赠送胜利。

旧的“不能为凑锚点保证PR07/12必出”限制已撤回一刀切表述；仍不要求每局十二类祈求全出现。新方向写入原事件/进度spec，详细路线仍待设计。

## 证据与当前限制

规划由主会话静态核对并经独立只读复核通过：修正节号歧义、设计与实现状态措辞、完整存档等待状态承接和三类验收方式。制作追踪检查退出0；工作台按本地/HTTP/离线三份数据一致性核查。此报告不提供游戏行为、自然到达率或体验通过结论。

本轮改变规则/计划文档，9项关联旧任务的证据指纹过期，追踪状态回到implemented；旧报告与源代码保留。K/A/B/C行为证据按原任务实际重跑，四项设计/规划/文案证据按各自范围静态复核后才恢复verified，不重签报告。本轮未把任何历史失败改为通过。原两项阻塞继续保留，完整Session/continue仍由CULT兼容链处理。
