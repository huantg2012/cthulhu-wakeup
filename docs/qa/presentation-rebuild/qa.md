## 发现与处理

1. **关键后果藏在局部滚动末尾（合同 §6.5）**：初稿把成功、深刻成功、失败和灾变顺次放入较短滚动区。已交 code 在固定区补来自真实语义的失败/灾变与成功摘要、请求期限；三卡固定不利后果的存在和边界已通过独立输入检查。完整后果/可选准备仍可展开。
2. **世界关联返回丢失原任务（F5.2/F5.4）**：初稿从回应准备查看世界后固定返回总览。已改为保存本次来源；独立鼠标验证从深应进入世界再返回原准备，模式/预览与 `WorldInfo` 焦点恢复。
3. **B/C暗面焦点对比不足（合同 §6.7）**：初稿 accent 对 surface 的静态对比分别约 1.31:1、1.43:1。code 已改用按钮实际前景色建立焦点边，保留原色系；不以旧比值评价修订后版本。最终实景焦点状态仍由主执行者与美术复看。
4. **B场景人物头脸被身份底板及裁切遮挡（R0.2/合同 §6.6）**：实际填图后发现，已交 art/code 调整裁切、移动身份到纸面并移除重复人物插图。新 B 深应图已能见头脸，新增 `FaceSafeArea` 闸门由 code 维护；这不是候选审美通过。
5. **A/C新增成功摘要与期限文字相交（合同 §6.5）**：定点行高证据显示摘要绘制估计 y156–210、期限 y193–215。已将期限移至同区域右上；新估计期限 y128–150、摘要 y156–210，二者分开，A最新截图也已复看。源版本与几何值保存在独立证据中。
