## 实际交付

- 11类玩家决策、35组玩家信息、对象关系表、7类场景和共用交互层；事实、已执行事项、可改计划、条件预览与未知分开。
- 10张1280×720线框，包含局外/局内会话、首团前、事件、行动预览、多团经营、多域浏览、持续降临、因果回顾、轮末与终局。
- 4项基于现有数值的纸面情境，说明同轮机会成本、维护挤占、迁引与岗位/反制依赖、降临跨轮资金；它们是条件推演，不是自然游玩样本。
- 8项当前公开接口/接线缺口G01–G08。主动路线已在业务入口存在但被旧页面筛选遗漏；不据此误报业务机制不存在。玩家知情投影不足时不以直接读取内部World补洞。

## 独立静态核查

Design和Code先分别核决策与公开接口，QA再独立对结构稿、当前规则/CSV及必要源码作定向核对。没有用旧美术方向、视觉skill或旧布局约束本稿。

| 检查 | 发现及处置 |
| --- | --- |
| W1首团与回应 | 费用、唯一回应、具名/无名人口及新团收入时序支持推导；忠诚由固定40改为至少40，保留max规则 |
| W2锚定与供奉 | 先付12后余1，不能同时维持新旧锚；27→24/20分别注明成功/普通失败条件，不用后到账收入回补 |
| W3迁引与反制 | 固定证据人物离域可使原清洗失效；原职责/护持解除、绑定圣物不自动同行，风险依实际结果 |
| W4持续降临 | 20+8+8+22×3=102，第三次付款前条件收入48，故该情境初始至少54；非通用门槛或成功保证 |
| 共同状态栏 | 初稿部分场景丢失回合和共同资源；已补各游玩场景统一字段，不靠换页记忆预算 |
| 会话完整性 | 补S0局外/局内两态，明确返回、保存、选档、新局和自弃；覆盖/放弃确认沿原规则 |
| 管理规模 | 把“团丁至辛”的合并占位展开为8条实际行；分别属于8个域，保每域唯一教团；本轮拟供奉/拒付与已付款分开 |
| 结果术语/终局 | 撤回新造的“狂喜”，使用深刻成功；即时终局连线明确为确认自弃，不把苏醒归零改为即时终结 |
| 知情边界 | 部分请求线索不当完整已知域；未公开域值不填零，屏障注明最近来源/回合；历史前因逐条过滤 |

QA复核确认最初6项修订已到位，后续指出八团列表的同域重复与付款时态，两项已继续修正。L2详情与L4确认目前主要为文字合同，不能据此声称其具体容纳或输入已验。

## 材料检查及证据边界

生成及`--check`通过：7场景/10线框/78区域/16关系，9条双向关系具双端箭头；节点与编号标签无重叠，124个内部链接无悬空。区域正文静态容纳于16px、标题18px，八团比较区约308.6/368px；不靠截字通过。实际导航脚本的默认总图、10帧、7场景、22正文锚点和16关系跳转通过内存DOM核查，重复ID/未知引用/越界等有限负例被拒绝。结果只证明材料的结构完整性和脚本逻辑，不代替真实浏览器渲染或真人阅读。

浏览器工具拒绝访问`file:`协议，并明确禁止改用其他浏览器表面或间接执行绕过；因此停止该路径，没有浏览器截图或真实字体/页面视觉通过结论。HTML为自包含本地材料，无CDN或网络请求；此限制不等于判定生成文件损坏。

本轮不运行Godot，不复签旧运行报告。`tools/implementation/check.py`整体退出1：74项错误均为原证据stale或前置连带状态；没有其他结构错误。追踪总60要求/24合同/82任务/143场景，15份正式方案全部绑定；本批只按实际差分复核并更新GDD及UI规格的计划绑定。旧报告绑定整文件哈希，该现象在前次规划登记已出现；不以重签或降低验收消除提示。离线制作工作台已同步当前任务与证据状态。
