# 完整正式新局策略审计

运行 `python -X utf8 tools/balance/verify.py --godot <Godot路径>`。单线依次执行种子19、42、7919 × baseline、aggressive、conceal、expansion，每局最多60轮或真实终局。`--explore`仅单局诊断，绝不混入正式分布。

策略在首轮冻结，不在运行中调参数：baseline不干预、事件走默认；aggressive优先深应并使用当前可用梦境/弱点/传播权能、事件偏B；conceal偏低暴露浅触和A事件、教团敛藏；expansion优先同域成员与PR05深应，保留未来祭仪费用，经营传教。前三种主动策略在尚无教团时释放重点，允许真实后台处境产生；有教团时按策略保留/释放。扩张/激进遇到本域PR05且已有成员与8信仰时，尝试ORACLE准备未来DREAM，随后回应；这沿原费用累计本域支出，未改数值。

`policy.gd`没有世界或Turn引用，仅接收Session的公开投影、展示选项和明确已知来源。隐藏人口/风险/支出只由run.gd诊断写出，不反馈策略。动作均通过正式Session预览/执行，阶段推进有硬上限。失败命令、重复请求及完整恢复同世界比较独立记录。无新增免费资源、人物、成功骰或资格。

每条命令与每轮都立即写入`runs/<seed>-<strategy>/trace.jsonl`并flush。逐条保留参数、公开预览、接受/拒绝、已知事实与费用；逐轮保留事实数、活动规模、全部域人口/风险、团体及终局。每次阶段推进记录Session总耗时，含该步自动保存；最终保存和完整恢复单列。相同引擎与来源下，重跑固定策略即为语义命令轨迹复演；campaign/存档路径的时钟身份不作为玩法随机种子。

包装器绑定UI与其上游来源指纹和本工具指纹；只读取来源，不改写旧报告或伪造旧回归。报告写tools/balance/results.json，Director负责正式报告及追踪归档。即使审计全部执行完，首团缺口等验收可以fail，负面证据仍落盘。JSONL保留已知视图与完整行动回执，存档仅本工具隔离目录。`censored`仅表示到达上限仍存续。
