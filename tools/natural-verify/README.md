# Bounded natural continuation

This tool continues only the immutable M1 seed-1 formal Session at
`tools/startup-balance/runs/calibration-02/natural-1/1793428397-2120124.json`.
The driver copies its original bytes; it never edits that save or its manifest.
The current production rules must accept it without migration or re-signing.
The automatic save is T8/between; original public progression reaches the
T9/actions observation retained in the prior core report before sampling.

At T9, T10 and T11, the public Session action catalog and preview choose at
most one oldest offered, legal and affordable shallow prayer response. No legal
choice means an empty window. Original RNG, event defaults, costs, deadlines
and qualifications remain. The due-T9 recovery request may expire unseen;
that is evidence, not an engine failure or a promise of rescue.

After the first actual action, a real new save is loaded into an independent
Session. Complete Turn snapshot, campaign, sequence, durable inputs and player
knowledge must agree. Replaying the same durable action must change nothing.
Both Sessions then execute the same next `progress(true)` and must agree again.
Filesystem slot paths are excluded from simulation equality. If no action is
legal, replay is explicitly unexecuted rather than reported as passing.

Run once with the approved host Godot executable:

```powershell
python tools/natural-verify/verify.py --godot 'E:/Program Files/Godot/Godot_v4.7.2-stable_win64.exe' --output tools/natural-verify/runs/formal-01
```

Parse, bounded core and native startup share 60 seconds. The first actual
failure stops the batch; raw stdout/stderr and input hashes remain. Exit zero
with `SCRIPT ERROR` or `ERROR:` fails. No full game or regression matrix runs.
Passing these checks leaves TASK-NATURAL-VERIFY partial/in-progress: it proves
no natural anchor/ending, overall balance, human experience or old 36-task
reacceptance.
