# Startup resource and pacing sample

This finite tool runs one controlled functionality regression for the private-devotion source fix, then six separately seeded fresh formal Sessions. The controlled regression is never included in natural success or waiting statistics. It obtains actual perceived dreams, loyalty and identity knowledge before requesting a new voluntary dedication through the same public selector/prepare/action used by the player. It injects no population, resources or membership.

The fixed natural list is seeds 1–4 gathering preferred and 5–6 calendar rite preferred, at most eight actual action windows each. Missing lawful known ritual operators fall back to gathering and are recorded. Every world retains its original RNG streams; no roll override or seed search occurs on the natural path. All success, failure, disaster, role/opportunity waits, resource/terminal/horizon censoring and timings are retained. Censoring is sample data, not a verifier failure. The raw scope is six descriptive trajectories, not a population success-rate estimate.

The simple policy first uses an actually offered same-domain shallow PR08 if it still needs a member; then lawful known private devotion or dream admission; an actually offered shallow PR01 is used only while same-domain followers are missing. It tries the preferred lawful organization, with actual public preview and original payments/actor windows. A current cash block with no action is censored, not represented as passive faith recovery. Default original event decisions and all ordinary production/expiry/resistance remain enabled.

The original 18 faith, three whispers, six followers and eight local spend are read from CSV. No balancing result or convergence is claimed by the executable. Design owns targets and any single-line CSV calibration (at most three rounds). No UI, new social process, or historical migration is included.

After narrow QA GO, run on the approved host:

`python tools/startup-balance/verify.py --godot "E:/Program Files/Godot/Godot_v4.7.2-stable_win64.exe" --output tools/startup-balance/runs/<new-run>`

Parse, core and native startup share a fixed 300-second total budget. First unexpected failure stops the batch and preserves inputs/raw logs. Two unexpected failures stop this implementation. No npm/TypeScript pipeline exists in this approved Godot project; native parsing/runtime are the applicable gates.
