# 历史索引独立验证

运行 `python3 tools/history-index/verify.py`，可传 `--godot` 指定引擎。需本地 Git 对象 `528e3e4871ae783f8bed84e265d2720041d89289`。

包装器把同一份 `tools/incremental-tx/replay.gd` 交给真实旧版与当前生产代码运行，比较 292 个逐请求检查点，并用新版实际载入旧版阶段四存档再继续。不是两份新实现自比。内部历史表示通过生产 `World.canonical/snapshot` 展开为完整旧语义，不剔除人物记忆、已消费来源、事实或回执。

`run.gd` 使用正式 CSV 和生产规则，构造无关历史与有效历史分开的反例。2000 条无关旧消息/见闻及 300 个墓碑、死者关系/伤害、已确认旧证据、已失效例外及载体已死的旧公开异常、300 个已耗圣物及其旧异常，1000 份旧回执/完成工作在完整初始审计和索引构建后才清零测量。普通操作不得重新遍历或深复制无关历史；持久树路径操作和原生历史根浅复制/身份核对单列；树路径长度仍可能随档案增长，不冒充总成本完全无增长或后续归档已完成。

仍有效的旧来源、完整多因果、消费去重、迁移暂时失效与恢复、分页 complete/version/policy、事务失败和坏存档另有独立断言。多条真正有效的父因果需要输出时允许 O(K)；分页不是丢弃合法候选的许可证。

持久树另做 400 次确定随机增删对照、平衡/计数/排序和浅只读嵌套输入别名检查；公开查询 reader 在回调后失效，回调清空自己的投影与改写权威索引分别验证。

坏查询策略的恢复/生成/重建拒绝测试运行在包装器独占的临时项目中，绝不临时写坏正式 CSV；失败必须保留现有世界、上下文、随机和索引。

机器报告 `docs/qa/history-index-results.json` 绑定实际执行源码 SHA-256。源文件执行期间变化、引擎错误、重复编号、差分或专项失败均退出非零。报告对应全详细参考模式，概略模拟/注意力/分段档案仍为下游任务。
