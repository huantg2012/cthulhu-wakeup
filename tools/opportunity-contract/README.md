# 关键机会合同静态分析

本工具属于 `TASK-OPPORTUNITY-CONTRACT-DESIGN`，只读取正式设计数据，不载入或运行游戏，不修改 CSV、源码、追踪或旧报告。

```powershell
python tools/opportunity-contract/verify.py
```

静态阶段校验六项机会参数的封闭字段、唯一 ID、正整数、单位和理由；十目标的有限枚举及文明蓝本引用；正式世界域数、每域机构数和共享 B 槽参数；三项后续路线设计任务的 Slice14 声明及追踪中的实际任务对象、设计归属、交付和验收。父路线任务不得标为已验证，全部目标必须为 `design_only`。

输入及工具的 SHA256 写入同目录 `results.json` 的 `sourceHashes`，结果本身不属于来源。执行结束核对输入未变化；任一检查失败退出 1，成功退出 0。只输出简短结论和失败原因。该结果仅绑定本次字节，不自动刷新旧证据。

数学部分实现事件§14.8与进度§12的抽象合同，不解析中文作规则，也不复制完整生产调度器。域数 `D` 读 `civilization_parameters.domains_total` 并核三个层级之和；每域机构数 `J` 读同表 `institutions_per_domain`；间隔 `I` 读 `fidelity_parameters.background_tick_interval`。两个 run 目标各只绑定一个 host，锚点目标每真实机构槽只匹配一个 profile 行，同目标各路线合为一个竞争项，且每目标只保留一个当前 step。因此：

- 全局实例上界 `D*J+2 = 12*3+2 = 38`；每域至多 `Q=J+2=5` 个当前 step。八蓝本不是每槽八个实例。
- `M=forced_after_missed_slots=2`。普通 B 槽可全 miss；进入强制 FIFO 后，已有目标最多排第 Q 位。含首槽相位偏差，纯 B 选择界 `I*(M+Q)=4*(2+5)=28`。
- 有限模型穷举 Q 个排位及 I 个首槽偏移；每次给前驱 B grant，再将新来/重新申请者追加尾部，以相同有限队列容量检查不插队。输出最坏见证和精确计数。B grant 仅指已提交的选源派发，不是游戏的 `opportunity_served`。
- 两个负控制分别允许新来者插队首、移除强制队列并令普通槽全 miss；在超过原界的有限前缀内目标仍等待。它们只证实抽象公式依赖上述条件，不是对生产调度器作故障注入。

另有专门队票反例：X 在 Y 前，X 获得已提交 B grant 后其假设管线立即失败且可合法重试。正确模型消费旧票，保留未服务债，发新序号排尾；Y 仍在 `M+Q` 槽内获得 grant，之后 X 可继续多次失败重试。在途 Y 不再占 B。错误对照让 X 用原队票重新排序，X 可反复排到 Y 前，超过原界后 Y 仍无 grant；队列容量未扩大。此例分开“派发票已消费”和“实际服务债未清”，不模拟真实管线。正式回执应写 `opportunity_dispatched/last_dispatch_source` 并将 `queue_seq=0`；未提交的事务须回滚队票且不计已消耗槽，这些实际保存/事务行为留给实施验证。

28 仅适用于同 host、持续有已验证可服务合同、无真实阻塞且玩家不更改的 step；普通未轮到、随机 miss、分页未达不算暂停。此工具没有实现或证明这些资格、计时、管线和保存行为。`pipelineLatencyL` 与 `actualServiceBound` 明确输出 null；只有后续真实路由另证 L，才可条件化使用 `service_bound <= B_bound + L`。不假造“当前 L=2”，不将最早展示时点当保证。权重增长无法替代最坏序列的强制服务。

可选 `--tables-only` 只跑表/任务引用检查，报告为 `static_tables_only`；默认报告为 `abstract_contract_only`。所有目标仍须 `design_only`，父路线任务未完成。追踪、正文或工具字节更新后，原结果只能说明原来源时点，须在明确的新一次运行后生成新结果；本工具不更新旧报告哈希。

此分析不验证真实等待、阻塞、拒绝、失败、保存转换或服务回执，不证明具体替代路线、真实资格/容量、A 后继、固定、展示或行动阶段的延迟 `L`，不证明可行动机会已经服务、自然新局可达、回应成功或胜利。所有实际生产、完整管线与自然运行证据仍归后续任务。

提交前源资格变化的有界重查/跳过仍是正式Scheduler的证明义务：本工具FIFO仅处理当前合法票，没有执行实际source_changed、handler事务、同槽重查或回滚行为。未生产的失格候选不得独占并推进持续合法目标的B槽；正式实施须另设该行为反例。
